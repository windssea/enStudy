# 英语探险岛可点击界面概念稿

打开 [index.html](index.html) 即可离线查看，无需安装依赖。桌面与平板均可打开，全部字体、图形和脚本在本地，不调用外部服务。

可体验：探险地图切年级、词块拼句、检查答案、专题特训（语法场景判断、时态时间切换、词形输入、固定句框辨析）、查看复习策略、查看家长AI设置、切换安静模式。键盘Tab/Enter同样可完成练习。

页面明确使用示例数据。AI 设置不接收真实密钥、不会联网；家长区在概念稿中直接可预览，生产系统必须按安全文档实现真实成人验证。地图采用自绘 SVG 展示视觉方向，不是已实现 Three.js 场景；R3F 的帧率、镜头与资产需要后续技术样片验证。

句子工坊演示一题，专题中心另演示语法、时态、词形和固定句式四种练习，不代表至少3,312道计划题目、60专题或72条句式已经编写完成；P1–P6切换展示入口变化，真实内容依赖课程生产。
