# 家庭资料导出

继承MASTER的系统字体、软圆角、蓝色主操作和52px控件。此处位于家长空间的折叠区，不新增儿童导航或装饰性3D；资料范围、家庭和保存状态比动效更重要。ui-ux-pro-max的`form submission feedback`检索命中Submit Feedback、Form Labels和Loading Buttons，分别用于生成状态、可见字段标签和防止重复点击。

入口仅对当前家庭管理家长显示，默认折叠。展开后先读取当前登录的数据包列表，列表未确认前不开放生成。显示家庭名称与家长账号，确认框明确包含本家庭所有儿童；密码为原生password输入，支持密码管理器和粘贴，显示/隐藏按钮有可见标签与状态。验证成功生成后清空密码，不提供验证码或便捷PIN替代成人认证。

一个当前登录只保留一个当前家庭数据包。生成、未知结果、已确认生成、准备分卷、交给浏览器和失败分别用文字说明。停止等待不会谎称已取消数据库事务；下载准备中断则不交付部分文件。遇到未知生成结果，可刷新列表恢复，不能自动创建另一份副本。

正文16px、辅助文字14px，所有操作至少52px，确认框的整行label可点击。操作区自动换行；资料数量使用宽屏两列、720px以下单列的定义列表，较大资料按约8MiB正文分卷。只显示范围和数量，不把作品正文、密钥或答题详情摊在家长设置页面；文件名使用随机数据包ID，不包含儿童昵称。原生summary、输入与按钮保留可见焦点。

10分钟有效期使用服务端时间，前端不声称自己的倒计时能延长授权。删除包只删除服务端快照，不删除学习记录。已交给浏览器不等于已写入磁盘，文件保存位置与本机副本由用户确认。当前不提供一键导入，界面明确说明。

请求取消、组件离开、账号/家庭变化均使迟到响应失效，分卷末尾再次请求服务端确认。组件不把目录、密码或下载内容写入localStorage/IndexedDB；只在当前内存组装一个分卷。关闭折叠区会卸载组件并取消等待。
