# 学习场景动效覆盖

沿用 [Master](../MASTER.md) 的玩具岛屿、蓝/黄/薄荷色、系统教学字体与原生操作。

每页一个主要场景，伙伴加一个道具，按钮触发短动作。教学信息在 DOM 中提供，3D 用于情境和回应。

场景宽 280–320px、画面高 228px，控件与说明另占约 100px；760px 及以下放在标题下方，画面高 200px。答题场景宽 220–240px、高 136px，留出跳跃和帽子空间。

相机固定，滚轮与拖动不抢占页面滚动。页入场 320ms 且位移不超过 12px；家长页关闭入场。作答文字区域保持稳定，伙伴只在保存后的结果窗口移动，彩纸不覆盖答案与下一步。

安静、系统减少动效、后台、离屏与朗读暂停相应动态。SVG 为加载、2D 和 WebGL 错误提供有完整轮廓的替代。按钮在安静与 2D 模式仍更新可读文案。

实现与检查见 [v0.10 记录](../../../docs/29-motion-and-3d.md)。真实浏览器与 iPad 视觉验收尚未完成。

v0.20在16个时态/词形专题的可展开区域加入48个演示。实验台打开时卸载头部伙伴Canvas，关闭时卸载实验台；每页仍只有一个主要场景。时间线显示事件、进行区间、重复与现在联系，词形台显示原形、拆分/换形、结果。常规接词尾用加号，不规则映射用箭头，和DOM文字、SVG替代保持一致。

场景高280px，620px以下240px；1100px以下观察说明放到图下方。所有选择、上/下一步和重放使用普通按钮，触控至少52px，不要求拖动或点中3D网格。文字与中文例句在DOM；Canvas仅示意，不能作为唯一教学信息。单次主动过渡700ms，结束后停止渲染循环；安静、降低动效、离屏、隐藏和朗读时直接呈现终态，恢复后不补播。

完整案例需先确认示范记录再显示。实验台不加星星和课程进度；同日已披露词形的练习记作辅助，不把玩动画当成已经掌握。静态SVG/过渡计算与真实D1流程已检查，GPU、PC/iPad视觉/触控仍待验，见[v0.20记录](../../../docs/39-time-and-word-form-labs.md)。
