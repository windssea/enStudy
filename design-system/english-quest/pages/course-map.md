# 六站粘土课程地图

继承 MASTER 的超轻粘土、中文教学、鲜明玩具色和52px操作规范。每学期六个站点对应目录中的六个真实单元；小屋、图书、兔子花园、写作桌、望远镜、灯塔是导览装饰，不冒充本单元教学实物或知识点。编号、下方标题和单元目标共同建立对应关系。

点3D实物或原生站点按钮，先切换中文目标及课程入口。打开课程是单独明确的操作；与下一节推荐课程的主按钮保持不同层级。站点使用 aria-pressed、可见焦点及完整文字，进度同时显示“已练过 n / 4 课”，不能只用色环或旗帜表示。只有服务端已完成课程的记录可以生成旗帜。

伙伴沿实际连接的前侧桥路短暂跳步，可以中途改选；镜头保持固定。动作不阻止打开课程，不依赖结束事件提交任何学习记录。停止、离屏、隐藏、听音或安静模式直接保留当前目标的静态位置，恢复后不补播。2D保留同样六个编号、选中位置和全部DOM操作；选择伙伴不改变学习成绩。

ui-ux-pro-max 针对“stop continuous animation”的 ux 查询命中 Continuous Animation 和 Reduced Motion，采用操作触发、有限时长及尊重减少动效的规则；Loading States结果不用于增加无关加载效果。threejs 的“demand render interaction”命中 requestAnimationFrame Loop Only 与 Explicit Position and lookAt，复用现有30fps受限按需循环，明确相机位置和目标。Touch Events建议不直接复制：已有R3F指针事件和原生按钮提供点击路径，Canvas保留pan-y，不能为点击全屏禁止滚动。

站点列表按容器宽度排列为三、二或一列，不用强制截断中文标题；选中目标区普通文字18px、按钮至少52px。画面边界已用真实模型包围盒在300、540、900px宽度测量，不能据此声称平板触摸、帧率或200%缩放已通过。

同一页面内，按儿童、年级和学期保留刚才选看的站点，打开课程再返回不会跳回第一个单元。刷新后重新根据当前课程建议选择；此偏好不写入学习进度或设备授权。浏览器代表性检查及剩余门槛见仓库阶段记录64。
