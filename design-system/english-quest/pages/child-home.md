# 儿童小屋与看图操作（v0.45）

本页覆盖 MASTER 中旧的文字侧栏、蓝色开始按钮和多列教学卡规则。依据 2026-10-19 用户反馈：儿童可能尚未识字，先用图画和声音引导，再用短文字补充。

- 空网址进入小屋；旧课程、专题和练习深链接继续有效。一个绿色大三角表示开始或接续，保存用对勾，推进用大箭头。保留原生按钮和完整可访问名称。
- 五个稳定入口使用房子、苹果词卡、积木、对话气泡、小花园。绘制同一套圆润彩色 SVG；装饰图不重复播报。主按钮 80–104px，选择答案至少 100px，旁边朗读按钮至少 68px；普通返回至少 64px。
- 首页保留三张图片目的地；其他玩法按需展开。家长登录、AI、报告、筛选、显示设置放在家长入口或折叠区。答题和例句页隐藏主导航，保留返回。
- 课程一次一张例句，箭头翻页；可分别听英语和中文意思。中文题目说明、中文选项、保存反馈和分类说明提供主动朗读，不自动播放，不朗读听力隐含原文。
- 22 段本地合成中文操作指令仅说明怎样点按；声音、AI 与学习评分相互独立。听过例句的已有辅助证据规则继续生效。音频失败有文字和重试提示。
- 768px 平板使用底部五入口，1024px 使用侧栏；底部安全区和内容预留空间一起生效。375px 首页纵向排列，避免标题和开始文字断成单字。真实 Pad 触摸、声音清晰度和性能仍须实机验收。
- 继续沿用粘土伙伴、减弱动效和 2D 降级。播放声音时暂停场景动作，切页和隐藏页面时停止声音。

技能查询选择：`education children playful` 的 Claymorphism 与目标相符；Trust & Authority、Contact Sales 页面结构与儿童学习不符，不采纳。识别优先于回忆的两次 UX 搜索没有可核实匹配，本页采用已读基础规则及游戏 UI 的清晰主操作原则；不是将空搜索结果当作依据。既有系统字体继续用于教学，未采用装饰 Comic 字体。

绿色开始底色 #58D19B、深色文字 #123F31；图片以黄、天蓝、薄荷、紫分组，同时提供形状与名称，不能只靠颜色识别。尚未通过儿童可用性研究，不能声称不识字儿童已经可以独立完成全部英语题型。
