# 英语探险岛 · NS运动系界面规范

版本：sports-interface-v2 / v0.59.2（学习引导修订）。适用范围：全站儿童与家长页面。

当前唯一方向是明亮、清爽的运动游戏界面：白色立体面板、青绿色主操作、深蓝灰正文，配少量天蓝、珊瑚橙和浅紫。参考 Nintendo Switch Sports 的清晰菜单与轻盈材质，使用原创图像和已有语义图标，不复制游戏标志、角色或UI素材。

过去的玩具岛、粗颗粒粘土、成人后台和大幅欢迎横幅规则已撤销，保留在 [HISTORY.md](HISTORY.md) 供查阅，不作为实现依据。

## 唯一运行时入口

`src/main.tsx` 只导入 `src/interface.css`，后者显式声明 `legacy → components → sports` 层级。

- `legacy`：历史功能的结构与兼容布局。保留已有交互，不继续添加视觉覆盖。
- `components`：`product-interface.css` 中的具体功能几何布局。
- `sports`：`visual-theme.css` 是当前唯一配色、字体、材质、按钮状态和公共响应式规则来源。禁止再加第八个样式覆盖入口。

页面不得自行决定主色、按钮造型、阴影或图标风格。新增功能优先使用现有语义类和变量。页面专有的布局、数据语义仍由对应组件负责。

## 色彩与材质

| 变量 | 值 | 用途 |
| --- | --- | --- |
| `--playground` | `#EFF8F7` | 极浅青绿页面底色 |
| `--surface` | `#FFFFFF` | 白色学习卡、家长表单 |
| `--ink` | `#193747` | 正文与标题 |
| `--muted` | `#506977` | 次要信息 |
| `--primary` | `#087D77` | 主操作、选中状态 |
| `--primary-soft` | `#E3F5F1` | 轻强调面板 |
| `--blue` | `#2369B8` | 键盘焦点、教学强调 |
| `--control-border` | `#739198` | 可操作输入边界 |
| `--border` | `#D4E4E5` | 非交互装饰分隔 |
| `--sport-accent` / `--sport-soft` | 按稳定类别取值 | 课程、单词、专题、句式卡的色标与徽章 |

正文与白底对比12.51:1；次要字5.79:1；主色对白字最浅端4.99:1；输入边界对白底3.37:1。黄色和浅珊瑚色配深色文字，不作为白字主按钮。

卡片22px圆角，菜单卡20px。按钮14px圆角、2–3px浅底座，按压仅位移2px。图标徽章是统一圆角轮廓与宽柔光，不采用粗糙粘土、强镜面、黑描边或糖果色渐变。选中状态同时具有边框、底色与ARIA状态；结果同时给文字，不能只靠颜色。

## 导航与布局

电脑（≥1024px）顶部横向五项导航；平板采用五项底部导航，保留安全区与128px底部余量。课程与答题进入专注视图，用页面自身返回控件退出，避免答题时重复导航。

全站最大内容宽1240px，桌面侧边距28px，平板24px，小屏16px。身份条只显示当前档案、年级、星数和家长入口，不重复整页标题与“你在这里”。

首页使用一个紧凑接续条和六个核心入口：课程、单词、专题、句式、复习、自然拼读；其他练习收在“更多练习”。桌面三列、平板两列。不要重新添加大欢迎区、角色、小岛或营销横幅。

课程以单元选择和课程卡为核心；大屏侧列单元、较窄屏用下拉。插图只在已绑定真实课程的卡中展示，不为缺图课程随便填一张装饰图。窄屏课程卡保持图文横排，教学正文保持清楚的英文与翻译层级。

单词页保持小学/KET两个独立范围，推荐训练为紧凑条，主题默认展开。删除重复“想一想、看解释、记得复习”、三步确认条和无意义的鼓励说明；安全、保存错误、辅助登记和AI发送确认必须保留。

专题、句式、KET分组采用同一家族白色菜单卡、稳定类别色标和统一箭头。家长页使用同样的控件与分段选择，降低装饰密度，密码、账号、权限和密钥处理逻辑不受样式影响。

## 字体与操作

学习指导只展示当前任务、具体知识、明确动作与真实状态。选课页不插入写作、对话、专题和复习宣传卡，不显示泛化课程介绍；例句页直接给出例句、翻译与对应规则，用“开始练习”明确下一步。删除重复元信息、口号与帮助小字，不以新提示区替代。词汇和拓展按需展开；保存失败、权限、题目要求、示范登记及AI同意保持明确。

使用本机 Segoe UI / PingFang SC / Microsoft YaHei，英文教学不使用装饰斜体或手写字。页面标题28–36px，题干25–32px，选项22px，正文16–18px，次要信息14px以上。

按钮至少52px，主操作56px，答案选项68px。操作间距至少8px。焦点3px蓝色外框。实际学习内容允许换行与浏览器缩放，不截断题干、密码校验或重要错误。

悬停150ms轻抬3px，按压2px；系统减少动效与家长减少动效关闭这些位移和动画。答题不添加持续漂浮、闪烁或自动朗读，不恢复“听提示/听选项”。

## 插画与教学示意

图像继续遵循 [ILLUSTRATION_STYLE.md](ILLUSTRATION_STYLE.md) 中 `sports-clean-3d-v1` 的同一人物、材质与灯光锚点。人物为现代运动服、利落成束发型、简洁图形五官；场景采用清爽柔光3D。不得重新引入旧狐狸、熊、岛屿或随机图库图。

新素材通过imagegen生成，必须先看已有参照图，并登记出处、尺寸、透明通道和例句绑定。教学图继续保留精确SVG时间线、数量、位置关系和真实英文文本。图片不承担按钮文字，不影响答案准确性或学习证据。

## 验收

覆盖桌面1280、平板768×1024、横屏1024×768与375px窄屏，检查首页、课程、单词/KET、专题/句式、答题、复习与家长页。检查真实控件边界、焦点、选中、禁用、返回、展开和保存反馈；页面不横向溢出，底部导航不挡最终操作。

旧规范不代表当前功能均已替换素材。v0.59统一公共界面与控件，沿用已审核的课程场景；现存单词教学图片仍按内容版本管理，新增与替换须独立审核，不能通过CSS变更宣称全部重画。
