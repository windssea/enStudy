# 英语探险岛界面设计系统

## 设计方向

采用明亮的玩具岛屿、柔和体积感和厚实可按按钮。儿童区有探索感，家长区用同一色彩和字体但降低装饰密度。P1–P2 强图片与声音，P5–P6 使用更简洁的探险日志，避免所有年级同样幼儿化。

ui-ux-pro-max 的两次设计系统查询均命中 Claymorphism，适用于儿童教育应用，保留该风格与蓝/黄配色方向。查询同时返回销售转化型页面结构，和学习产品不匹配，已排除；本系统的页面结构由学习任务推导。Baloo/Comic 类字体不用于关键英文教学正文，避免装饰性字形影响识读。此文件为经过筛选的设计决策，不是直接持久化无关搜索结果。

## 颜色变量

| Token | 值 | 用途 |
| --- | --- | --- |
| `--bg` | `#F4F8FF` | 页面底色 |
| `--surface` | `#FFFFFF` | 题目、卡片 |
| `--ink` | `#172B4D` | 主要文字 |
| `--muted` | `#51627B` | 次要文字 |
| `--primary` | `#2557D6` | 主按钮，配白字 |
| `--primary-soft` | `#E8EFFF` | 当前导航、弱强调 |
| `--sun` | `#FFD166` | 奖励、任务标记，配深色文字 |
| `--mint` | `#D9F4E8` | 复习与完成背景 |
| `--success` | `#146A4B` | 成功文字，配浅色底 |
| `--coral` | `#F28D79` | 装饰与角色，不作白字按钮底 |

| `--control-border` | `#62768F` | 有意义的输入边界 |
| `--border` | `#DAE4F2` | 装饰分隔，不独立表示控件边界 |

普通文字目标 4.5:1，大字及必要非文本元素目标 3:1；透明叠加后重新测量。黄色与珊瑚色均配深字。成功与失败同时用文案或图形，不能只变颜色。

## 字体与版式

英文教学正文优先采用字形清楚的系统 sans-serif，逐一核查 a/g/I/l/1；可后续对比 Andika 并核查字体许可。中文采用系统中文 sans-serif；标题圆润但不用装饰手写体教授拼写。生产可自托管经过裁剪的授权字体，首版概念稿使用系统字体，不依赖第三方字体网络。

儿童题干 24–32 px，英文单词 28–40 px，正文 18–20 px，辅助文字最低 14 px；家长正文 16–18 px。行高 1.5–1.65。内容随 200% 缩放换行，长词块也允许合理换行，不压缩至难读。

间距：4/8/12/16/24/32/48/64；卡片圆角 24，按钮 16，题目容器 32。按钮最小高度 52 CSS px，词块最小 56，触控间距至少 8 px。投影统一为软投影和约 4 px 按钮底座，按压用 transform 不推动布局。

## 组件规则

- 每屏一个最明显主操作；选项、确认按钮和返回各司其职。
- 导航使用统一 SVG 图标；有文字时图标 `aria-hidden`，纯图标按钮要有可访问名称。
- 词块拖动同时支持点击添加、点击移除、可见撤销和键盘操作。拖动时只在局部交互面板禁用原生滚动，页面其他区域保持滚动和缩放。
- Modal 使用语义 dialog、标题、关闭按钮、焦点管理、Esc 和触发点恢复。简单反馈用非阻塞 `role=status`。
- 麦克风状态同时用文字“正在录音”、图形和计时，不能只画波形。
- AI 密钥输入默认隐藏；保存后只显示末四位；不提供明文回显。

## 动效规范

| 层次 | 时长/行为 | 约束 |
| --- | --- | --- |
| 按压 | 80–120 ms，位移 2 px 或缩放 0.98 | 立即反馈且可中断 |
| 状态切换 | 160–220 ms 透明度与位置 | 不依赖动画结束事件保存业务状态 |
| 词块吸附 | 180–260 ms 弹性收敛 | 不触发整页镜头动作 |
| 页面进入 | 240–360 ms，最多 16 px 位移 | 焦点顺序稳定 |
| 完成奖励 | 600–900 ms，可立即跳过 | 不延迟退出，不自动无限播放 |
| 地图/角色 | 空闲小动作，离屏与隐藏时暂停 | 同时最多两个明显运动主体 |

`prefers-reduced-motion` 或手动“安静模式”关闭漂浮、视差、粒子、镜头过渡，改静态状态或短淡入。答题时停止环境持续运动；播放听力时角色静止。不得闪烁或用强镜头旋转。

## 设备与性能

断点：375/768/1024/1440 CSS px。平板 768–1023 单栏或窄两栏、底部导航；1024 以上视可用高度使用侧导航。竖屏不能要求旋转。遵守安全区域和软键盘，保留浏览器放大能力。

Three.js 地图使用低多边形 glTF、烘焙光照、复用材质，首版不加后处理和实时阴影。DPR 初始 1–1.5，按真实测量调节；无交互按需渲染，角色动作时短期开循环。Canvas 对辅助技术为装饰，单元列表提供同等导航；Canvas 错误边界自动显示 2D。

## 页面覆盖

专题中心采用分类卡片和可点击层级路径，显示“诊断/练习/迁移/复测”的语义状态。时态时间线必须可点选，不依赖精确拖动；词形工厂展示实际拼写变化，不只变色；高年级可减少装饰。专题任务仍遵守单主操作、键盘/触摸替代与安静模式。

地图突出“继续当前任务”；学习页弱化装饰；复习页用“照顾记忆”而非“清理欠债”；家长页使用信息表、能力趋势和可操作建议。详见 [页面与流程](../../docs/04-experience.md)。
