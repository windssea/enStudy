# 儿童数据与多家庭安全设计

系统将儿童学习、成人管理和内容运营分为不同权限域。家长控制账号和第三方服务，孩子不需要邮箱，也不能管理密钥。以下是产品和工程控制要求，具体市场的法律适用、同意方式及供应商年龄政策需在上线地区确定后完成专项评审。

## 权限与账号

| 角色 | 可访问 | 不能访问 |
| --- | --- | --- |
| owner 家长 | 家庭全部档案、邀请、预算、导出、删除 | 其他家庭 |
| guardian 监护人 | 授予的家庭教学管理 | 移除最后一个 owner、未经授予的密钥管理 |
| child 设备会话 | 当前孩子的课件、答题、复习和获准 AI | 兄弟姐妹数据、家长邮箱、密钥、成人设置 |
| editor | 内容编审 | 私人学习记录、家庭密钥 |
| operator | 运行指标与必要审计 | 默认读取儿童原音或完整对话 |

家长使用认证库支持的安全登录、邮箱验证和恢复；首发优先标准成人登录，验证后可加入 passkey。不能依赖秘密问题、算术家长门或头像选择保护成人权限。Cookie 设 HttpOnly、Secure、SameSite，并校验状态变更的 Origin/CSRF。

儿童档案通过成人创建 grant 授权到设备，grant 只绑定一名孩子与有限操作。授权有到期与撤销；共享平板切换孩子由成人授权选择对应 grant，不能让已泄露的一个 childId 扩展到全家。进入成人敏感设置要求最近 10 分钟重新验证；密钥管理和家庭删除不可仅凭儿童页的 PIN。

## 威胁与控制

| 风险 | 控制 | 必测攻击 |
| --- | --- | --- |
| 跨家庭越权 IDOR | 服务端范围、复合外键、禁止裸 ID 查询 | 替换 child/session/attempt/export/connection ID |
| 密钥泄露 | 服务端加密、掩码响应、日志去敏、CSP | 构建包、浏览器缓存、错误栈、服务端日志扫描 |
| 出站 SSRF | 精确主机名单、固定端点、无重定向、限制大小 | localhost、IPv6、userinfo、重绑定、编码绕过 |
| prompt injection | 用户文本隔离、无工具权限、结构化结果校验 | 要求忽略规则、索取 key、注入恶意题干 |
| XSS 与远程内容 | AI 文本按纯文本渲染，Markdown 严格白名单 | HTML、脚本、危险链接、SVG 事件处理 |
| 计费滥用 | 家庭精确预算、会话/设备限流、请求幂等 | 双击、并发、取消重发、录音洪泛 |
| 伪造正确率 | 服务端答案、assignment 与提示证据、离线证据降级 | 直接提交 correct=true、重放答案、删 hint 字段 |
| 泄露家庭缓存 | 缓存键含家庭孩子、切换取消请求、登出清理 | A→B 快速切换后迟到响应写入 B |

内容安全对儿童呈现采用任务范围和积极引导，避免开放式社交。遇到不适合儿童的内容不展示生成文本，回到标准素材。内容策略不得因供应商声称有审核就省略本产品限制。

## 数据最小化与同意

默认只采集昵称、头像、年级、学习证据、设备授权和必要性能指标。家长开启第三方 AI 前，展示供应商、出站字段、可能处理地区、保留政策链接与预算；语音另行开启。关闭 AI 后立即停止新调用，当前录音销毁。

原音默认仅转发处理，不写 R2；转写默认用于当前回合，结束即销毁。若家长选择保存作品，采用独立同意、明确时限和可删除入口，不能把“使用麦克风”视为“永久保存录音”的同意。供应商自行保留的数据需按其实际政策说明和删除能力处理，产品不能承诺代替供应商即时删除。

## 导出与删除

导出采用后台任务、家庭校验、一次或短期下载授权，下载对象私有。导出包含学习事件、课程进度与设置，不包含明文密钥。通知不通过自动外发消息完成，首发在家长面板显示状态。

删除孩子先停用 grant 和在途 AI，再清理私有记录、R2 作品、缓存引用与日汇总。删除家庭同时撤销所有成员、连接和 token；共享公共原创内容保留。目标主存储 7 日内完成，备份最多 30 日滚动到期，为拟定服务政策，正式发布前需确认可实现。

备份恢复前必须重放删除 tombstone，避免把已删除档案重新恢复。删除回执区分“产品已清理”“备份待到期”“已向供应商提交请求/供应商不支持”，不笼统显示“一切已抹除”。审计保留匿名请求号及状态，避免以审计名义保留完整儿童档案。

## 上线门槛

完成跨家庭对抗测试、真实设备授权与撤销、密钥轮换、内容安全样例、备份恢复与删除演练。目标地区、商业模式和数据处理者确定后，由适当人员核对儿童隐私与跨境处理要求；若选择的 AI 供应商政策不允许拟定场景，该连接不能向儿童开放。
