# 看图与声音引导的儿童界面 v0.45.0

用户反馈是操作仍像成人工具，孩子需要直观的大按钮，且可能尚未识字。本阶段首先改造首页、常用导航、例句和答题主流程；保留现有课程、家庭隔离、独立/辅助证据、复习与接续规则。

## 实现

新增儿童小屋作为无 hash 首页。绿色大三角打开当前年级下一课或接续自己的任务；未选档案时进入家长空间。三张图片进入单词、小岛和复习花园，其他玩法展开显示。五个主导航使用统一彩色 SVG，主操作明显放大；答题和例句页移除旁侧入口，保留返回。

课程改为逐张观察卡，左右箭头翻页，英语与中文解释分别主动朗读；单词、可选活动和课程元数据收在更多发现内。听过示范仍按原有辅助规则计入，不作为独立作答。答题按钮采用灯泡求助、绿色对勾保存和大箭头继续；已选答案用中性圆点，避免把选中误画成答对。中文题目提示、中文选项与回执可以朗读，英文答案不因新增中文按钮而泄露。家长区保留记录规则说明。

专题与固定句式入口使用大图分类、中文分类说明朗读和“带我玩”；筛选收进“大人帮我挑”。单词、专题、句式和拼读的主开始按钮统一大三角。画面设置仅在家长区显示；已保存 2D/安静偏好继续生效。

22 段中文操作音频在开发机离线合成，部署时直接提供本地 MP3，不调用 AI、不发送儿童数据、不申请麦克风。源脚本在 content/child-guides.v1.json，音频清单有完整 SHA256、字节数、时长和固定路径；scripts/render-child-guides.ps1 记录使用已安装的 System.Speech 与 FFmpeg 生成 v1 的步骤，检测已有清单后拒绝覆盖；未来重生成须另建版本并调整清单路径。合计 1,325,142 字节，单段不超过 20 秒；完整离线壳 62 项、5,803,730 字节，低于既有 100 项/8MB 上限。

本地音频可以停止，切页、隐藏页面、换声音或卸载都会清理；设备朗读的中文长讲解使用按文本长度计算且最高 90 秒的保护时限，避免旧的 15 秒一刀切。设备缺少中文/英文声音时显示帮助，不冒充已完成听力。既有自然拼读严格 WAV 路径保持独立。
