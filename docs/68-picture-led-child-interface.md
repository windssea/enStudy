# 看图与声音引导的儿童界面 v0.45.0

用户反馈是操作仍像成人工具，孩子需要直观的大按钮，且可能尚未识字。本阶段首先改造首页、常用导航、例句和答题主流程；保留现有课程、家庭隔离、独立/辅助证据、复习与接续规则。

## 实现

新增儿童小屋作为无 hash 首页。绿色大三角打开当前年级下一课或接续自己的任务；未选档案时进入家长空间。三张图片进入单词、小岛和复习花园，其他玩法展开显示。五个主导航使用统一彩色 SVG，主操作明显放大；答题和例句页移除旁侧入口，保留返回。

课程改为逐张观察卡，左右箭头翻页，英语与中文解释分别主动朗读；单词、可选活动和课程元数据收在更多发现内。听过示范仍按原有辅助规则计入，不作为独立作答。答题按钮采用灯泡求助、绿色对勾保存和大箭头继续；已选答案用中性圆点，避免把选中误画成答对。中文题目提示、中文选项与回执可以朗读，英文答案不因新增中文按钮而泄露。家长区保留记录规则说明。

专题与固定句式入口使用大图分类、中文分类说明朗读和“带我玩”；筛选收进“大人帮我挑”。单词、专题、句式和拼读的主开始按钮统一大三角。画面设置仅在家长区显示；已保存 2D/安静偏好继续生效。

22 段中文操作音频在开发机离线合成，部署时直接提供本地 MP3，不调用 AI、不发送儿童数据、不申请麦克风。源脚本在 content/child-guides.v1.json，音频清单有完整 SHA256、字节数、时长和固定路径；scripts/render-child-guides.ps1 记录使用已安装的 System.Speech 与 FFmpeg 生成 v1 的步骤，检测已有清单后拒绝覆盖；未来重生成须另建版本并调整清单路径。合计 1,325,142 字节，单段不超过 20 秒；完整离线壳 62 项、5,803,730 字节，低于既有 100 项/8MB 上限。

本地音频可以停止，切页、隐藏页面、换声音或卸载都会清理；设备朗读的中文长讲解使用按文本长度计算且最高 90 秒的保护时限，避免旧的 15 秒一刀切。设备缺少中文/英文声音时显示帮助，不冒充已完成听力。既有自然拼读严格 WAV 路径保持独立。

## 验证与边界

58 文件 467 项单元检查通过，类型、生产构建、Functions 编译和格式检查通过。新增测试覆盖操作音频清单、哈希、播放切换/隐藏/超时、路由默认值与离线音频缓存；保留私有 API 不进入离线缓存的检查。原课程测试改为验证一次一张和翻页入口，写作的草稿与九题进度分离说明保留。

完整本地运行回归退出 0：48 项基础与 1342 行 PASS，共 1390 项；包括原有七题型、保存接续、学习证据、家庭隔离、复习、离线、AI 模拟服务、错题与专用材料。没有调用真实 AI 供应商。日志 artifacts/runtime-v045.log 与 .exit；最终单元 artifacts/check-v045-freeze.log，构建 artifacts/build-v045-final.log，格式 artifacts/format-v045-final.log。

在仅内存数据库的独立浏览器夹具中，以临时儿童走通：首页出发→P3A-U01-L1→第二张例句→英文朗读→中文讲解→练习→选 are→绿色对勾保存→刷新恢复原答→大箭头进入第二题；最终包另验中文题目朗读、本地操作音频播放/停止、专题一键入口。未向真实家庭写入这些验收成绩。

同源 iframe 的实际 CSS 视口分别为 768×1024、1024×768 和 375×812，检查首页图画、导航和窄屏文字排布；这是浏览器响应式验收，不是 Pad 实机、触摸或性能结论。截图存于忽略目录 artifacts/v045-pad-portrait.png、v045-pad-landscape.png、v045-phone-narrow.png 和 v045-child-player.png。声音按钮的状态响应已验，完整听审、真实儿童识图研究和不识字儿童独立学习测试仍待完成。写作、阅读和语法任务本身仍需要相应语言能力，不能把图画导航等同于全部内容适合零识字使用。

本阶段不增加数据库迁移，不修改 0001–0044，不改变管理员和注册设置。按阶段规则正常推送 main，经 GitHub Actions 顺序发布 Preview 与 Production；云端真实结果另行补记，尚未完成的发布不能写成已上线。
