## 课程内容

每个年级新增下学期第三单元四节课，原A学期144课与B前两单元48课保持原内容及迁移。每课含中文规则、三组双语例句、四个词汇，以及两项听辨、两项原文依据阅读、选择、分类、改句、填空和拼句共九项任务。所有新任务家族与原课程不重复，示范卡片与本课测验句分离。

| 年级 | 单元 | 教学重点 |
| --- | --- | --- |
| P1 | 我的教室 | in/on/under、Where is、摆放指令与描述位置的区别 |
| P2 | 社区散步 | next to/near、询问地点、未知方向不猜测 |
| P3 | 去哪里玩 | there is/are、否定与疑问、between…and… |
| P4 | 问路小帮手 | 祈使句原形、along/past、礼貌问路与顺序 |
| P5 | 绿色行动 | because/so/although、自然替代表达、记录与原因的边界 |
| P6 | 规划精彩旅程 | 时刻与时长、单价与总额、将来条件句及多约束选择 |

面向中国儿童，明确解释because和so、although和but不能照中文成对机械叠用；next to与near含义可重叠，不把near误教成“绝不相邻”。because题接受已声明的since/as，although受控填空接受though，否定词接受完整写法。需要固定形式的任务在中文说明中先限定要求。听力可明确使用文字辅助；阅读仍须同时选支持原句和答案。

路线、设施、时刻、费用及环保记录均为原创虚构资料。无出处的数据不当真实事实；真实出行提醒与可信成人同行。朗文仍采用可配置知识点映射，未绑定具体版本，也未复制教材课文。

## 3D位置小实验

新增第17个实验台，提供in/on/under三个场景，教学示范总数54。P1四课均有可选入口，时间与地点介词专题亦能打开。默认不加载场景，展开后先选择例子，依次找参照物、看摆放和读完整句子；复用已有中文步骤、朗读和示范保存协议，不新增评分机制。

从同一Three.js模型源码构建圆角桌子、开口蓝盒与珊瑚色小球。球在on状态接触桌面，在under状态位于桌下，in状态位于有内部空间的开口盒子。前壁较低，避免球被完全遮住。13个闭合网格、8,504三角面，复用粘土细颗粒、PMREM棚灯和预算软阴影。空间场景底座顶面与家具底面齐平。

球进出盒子经上方开口，进出桌下经前方通道，避免直线穿家具。端点切换与中途打断有连续位置计算；安静、减少动效、朗读、后台和离屏立即呈现目标状态。依旧700ms主动过渡，30fps上限；并未做实机性能承诺。2D图与DOM说明保留同样的关系，不靠拖动或Canvas点击才能学习。

本会话无Blender MCP工具，实际使用本机Blender 5.2.1 LTS后台CLI检查和渲染从同一运行源码导出的四种状态。检查副本焊接UV/法线重复顶点后，每个实体均无开口、非流形、退化面或非法坐标，体积为正；检查不会修改网页模型以掩盖问题。保留可编辑`design-assets/clay-position-classroom.blend`、四张真实渲染及绑定源码摘要的QA文件。建模源码为`src/scene/spatialModel.ts`，Blender文件是检查与灯光场景，网页模型不依赖它导出的替代几何。

Tabbit重新探测仍退出69，PC/iPad的实际浏览器视觉、触控、缩放、帧率和发热尚未验证。Blender实渲与SVG静态检查不等于网页GPU验收。
