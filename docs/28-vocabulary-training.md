# v0.9 独立单词特训

2026-10-17，新增“单词特训”独立学习区，不再只依赖专题中心的词汇分类。推荐年级一至六年级，每年级3个生活主题，每主题20词条，共18主题、360个按词义区分的词条和1080个练习。同形多义词分别建条，例如square的正方形和广场；360词条不表示360种不同拼写，也不代表全小学词汇生产计划完成。年级为建议起点，未声称与任何朗文版次精准对应。

## 使用流程

进入单词特训，选择年级与主题，可以先打开词卡查看中文释义和英文例句，主动点按朗读。选择词义辨认、单词拼写、语境选词或混合挑战，再随机开始5/10/20题。词卡是学习材料，允许公开阅读；测评答案与题目数据留在服务端。

词义以英文和例句选择中文，拼写按词表与中文提示输入英文，语境根据中文词义及英文句子选择词语。为限定本词表的目标，部分拼写题提供字母数，常见英美地区拼写在相应词条接受。任务是受约束文字练习，不是自由翻译或完整词汇能力评测。

本轮每个词条只出现一次；跨模式也优先避开最近400个分配中的词条，耗尽后较早分配优先。单词模式、主题与题量一起绑定幂等请求编号。题目和选择项存入D1，刷新后继续原题；退出练习返回单词区时提供继续入口。

页面显示当前孩子“练过词条”和“到期复习词条”。统计读取已有提交形成的复习卡，只分配未作答不增加数量；读取失败显示失败状态，不将未知显示为0或已掌握。每个词义单独记录词义辨认、拼写和语境识别证据；语境选择不计成自由表达证据。完成一轮不增加课程完成数。单词复习接入现有统一复习选择器，长期掌握与延迟测验仍按总体计划完善。

PC保留侧导航。平板和窄屏底部为地图、单词、专题、句式、复习五入口，家长空间由顶部档案按钮进入，避免六个入口挤成两行。词卡为原生details，模式为原生radio，筛选为原生select/input，支持键盘操作。单词区按需加载约7.35kB JS（gzip约2.89kB）。

## 内容与接口

- 原创源`content/vocabulary-v1.mjs`；构建器核对每主题20条、每年级3主题、唯一正确选项和单空例句，生成私有`content/vocabulary-release.v1.json`与不可变`0009_vocabulary_bank_v1.sql`。
- 0009在本机执行30条语句，新release同时引用原16064题的版本成员，支持混合复习；已应用迁移不覆写，后续修订另发release与迁移。
- `/lessons`提供18个主题的摘要；`/vocabulary/:themeId`公开20张教学词卡；`/learning/vocabulary`必须有有效儿童授权，返回本孩子的词条统计。
- `/sessions`增加`wordThemeId`和`wordMode`，与课程、句式、专题和单题选择器互斥；来源为vocabulary，题量与模式均由服务端校验。
- Vite阻断单词题库源和私有JSON，静态构建不包含答案。教学词卡的英文、中文和例句有意公开，不等同于公开私有试题文件。

## 验证与限制

61项单元检查通过。真实本机workerd/D1通过33项基础、24项账号、25项课程、12项专题、14项句式和16项单词检查。单词检查覆盖公开词卡、匿名拒绝、四模式、幂等、刷新、连续词义与拼写轮次避重、提交后准确计数、20题轮次、六年级段开题和仅本机测试档案到期复习。结束时清理临时档案及级联数据。

生产构建、Functions编译和格式检查通过。Functions本机编译体约15.8MB（gzip约674kB），Three.js模块仍约916kB（gzip约243kB）；性能与加载优化继续推进。Tabbit诊断仍exit1且无输出，未取得本轮实际视觉、触控、屏幕阅读器或设备声音验收证据。朗读使用设备Web Speech，提供停止和不可用反馈，不等同于AI语音对话，也不记录口语能力。

词义、搭配与年级仍需后续教研逐条复核，更多主题、构词、听写、图词、近义辨析及教材映射继续按总体范围实施。远程发布证据在实际成功后补录。
