# v0.61 艾宾浩斯启发式间隔复习

状态：本地实现、595项单元测试、17项服务端专项和隔离浏览器验收通过，等待同步发布。

## 研究依据与产品取舍

遗忘曲线启发我们在学习后安排回忆，并逐步增加间隔；它不等于一张适用于所有孩子的精确时间表。原始研究与2015年复现实验都基于单个被试，使用无意义音节与再学习节省量，不能直接解释成儿童英语的实际遗忘百分比。[Murre与Dros，2015](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0120644)

较大规模的间隔学习研究发现，最佳间隔随最终测试的保留时间变化。[Cepeda等，2008](https://pubmed.ncbi.nlm.nih.gov/19076480/) 因此本版本采用可解释的初始间隔和真实作答调整，不宣称已拟合个人遗忘曲线，也不展示“已经忘记多少”的伪精确百分比。

## 统一策略

课程、专题、固定句式、单词、小学及KET词汇、拼读和其他客观题，共用已有的“孩子 × 知识点/单词 × 练习维度”复习卡。认词、拼写、听力等分别记录，不把认对词义当成会拼写。AI对话、语音转写或仅看过讲解，不自动生成独立掌握成绩。

- 首次独立答对：约24小时后复习。
- 到期后独立回想成功：间隔依次为1、3、7、14、30、60天，最多推进一级。这里是相邻两次复习的间隔，非从初学日固定累加的日历表。
- 在线答错：重回巩固阶段，约10分钟后再练。
- 借助提示、示范或文字辅助答对：约20分钟后再练，不增加独立记忆确认。完成一次短时辅助复练后转到次日，避免当天不断循环同一目标。
- 在短时再练到期后独立回想成功：先安排次日确认，再逐渐拉长间隔。
- 提前练习始终允许，但不会提前消除短时再练，也不会推迟原计划或反复升级。一次本地日最多增加一次记忆确认；逾期回来只根据这次表现推进，不罚分或虚构已完成复习。
- 离线数据保持未验证状态，不增加独立阶段或奖励，不用设备时间倒推真实回忆日期；既有更早的到期时间保留。

10/20分钟与上述天数是本产品可审计的启发式默认值，不是研究给出的普遍最佳值。未来有充分真实跨日数据后，才评估校准模型；本阶段不使用答题速度、儿童外观或未经验证的AI判断估算记忆。

## 页面与选题

有未完成任务时首页优先接续；没有未完成任务时，同一主操作推荐到期复习。课程和其他入口始终开放。复习页显示实际下一次时间，没有到期内容时可直接继续学习，不出现等待卡、强制路线或科学概念讲解墙。

到期目标优先选需要短时再练的知识，再按到期时间处理；尽量更换题目家族，保持最多8题的小轮次。所有时间由服务端确定，按家庭时区显示；长间隔按实际24小时天数计算，不能在午夜学习后几分钟就当成隔天记住。首页与复习页在回到前台、进入页面及下一项到期时刷新，不在后台持续轮询。
