# v0.8 固定句式独立随机练习

2026-10-17，落实固定句式也要大量练习并随机抽取。句式工坊的72张卡片现在各自关联独立题库，按`patternId`开题，不再将邀请建议的卡片统一指向`sample.pattern.about`。

每条句式包含40组文字情境，每组提供选择、填写、词块组句三种形式，共120个练习变体；72条合计新增8640变体。情境来自受约束的原创句框与词汇组合。每条按等价缩写合并后有20～40个目标句子家族，同轮以句子家族去重，避免同一句话的不同情境/题型连续出现。40组情境和120变体不等同于40道或120道独立迁移测验。

## 可见功能与规则

- 句式卡片显示实际120变体、40情境、3种练法。每轮5/10/20题，默认10题；每条单独抽取，不能混入另一条句式。
- 复用专题的服务端随机、近期400个分配避重、耗尽后最早曝光优先。选项和词块顺序也随机，写入D1后固定；刷新和请求重试不重新抽题。
- 本轮题目只能属于一个选择器，`patternId`不能与`topicId`、课程或单题混用。请求编号同时绑定句式和题量，变更返回409。
- 接受合法的`start to do / start doing`、`help somebody (to) do`、对应缩写及相关英美拼写；不会把这些合法接续当作错误选项。`like V-ing`本轮练指定动名词句框，不全局否定`like to do`。
- 组句按给定词块和任务要求作答；较固定的问候、询问句配有不同角色或问答情景，先问后答。语义自由改写仍不在当前评分范围。
- 每条句式有自己的技能标识，接入当前复习调度。完成句式轮次保存总数、正确和独立数量，不伪装为完成了一节课程。

## 内容与发布

`content/patterns-v1.mjs`逐条实现72句式的构造器。`scripts/build-patterns.mjs`核对40情境、120变体、20个以上可抽句子家族、唯一正确选项、题型与不可变清单，生成私有`content/pattern-release.v1.json`及`0008_pattern_bank_v1.sql`。新release收录原7424题的成员关系，保证跨入口复习选到混合内容时仍对应完整发布快照。

0008已在本机执行119条语句，应用后不覆写。内容修改要新增release与迁移。新增生成文件相同内容时不重复写入，减少本机开发服务不必要的重载与文件句柄争用；不改变既有发布内容或迁移哈希。

题库源、答案和迁移不进入静态dist；Vite同时阻断对应私有路径。前端主JS约264kB（gzip约83kB）；Functions本机编译体约14.9MB（gzip约600kB），线上可用性仍以部署及请求核验为准。持续优化服务端内容读取和3D包体仍在待办。
