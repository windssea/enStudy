# 听音找图片与图卡学习 v0.46.0

本阶段延续用户“儿童可能还不认字”的要求，把看图与声音引导从入口落实到单词任务。首批覆盖现有一年级三个主题的全部60个词：动物20、校园20、颜色形状20；不是声称其余300词和全部课程已经配齐媒体。

## 学习与交互

一年级快速开始默认听音找图片；所有年级也能通过三张大图进入对应主题。原有词义、拼写、语境、文字听辨和混合模式保留，混合入口不会悄悄加入图片任务。每词3组选项组合，共180道任务、60个词义家族；同一轮按原随机策略抽5/10/20个不重复家族，不把180道变体称为180个独立知识点。

孩子点大喇叭完整播放英语整词，再主动点绿色小勾确认听到，然后选图片、点大勾保存。声音中途停止、切后台或失败均不冒充听到。答题前没有可见的中文选项或英文词，图画按钮仍有中文可访问名称；文字辅助须明确开启并另记。使用本地音频文件，不要求安装英语系统声线或配置AI。

图卡学习一次一张，提供单词录音、中文意思朗读和左右大箭头；受支持的书、铅笔、鱼等仍能展开原有交互粘土物。选择图卡学习时，先由服务端保存当前儿童的示范标记，再揭示图片与词义；切卡、关卡或换档案清理旧请求与声音。首页主题图只有图画和中文类别，不把未登记的英语词义映射作为装饰。

保存答案后由服务端回执提供正确图片、英语词与录音。图片反馈的示范记录与答案、奖励、复习卡在同一D1 batch内受已保存事件和授权条件约束，防止当天换一组选项便被称为独立回忆。错误答案刷新仍恢复原选择；错题小本和离线已确认记录用图片/中文显示，不暴露技术编号给儿童。

## 内容与兼容

采用40张原创粘土插画和20张矢量颜色/形状图。图集按逐张裁切坐标显示，已纠正相邻物品边缘串入。颜色义orange使用色块；鸟/鸭、熊/熊猫、圆/椭圆、正方形/长方形等上位或近似概念不互为目标干扰项；书桌、教室、教师等多对象场景不放入会产生包含歧义的干扰池。两张错误选项彼此相关不等于目标存在多个正确答案，正式教研和儿童识图仍待完成。

新增不可变迁移0045，发布3个非核心课程容器与180项图片任务；0001–0044不改。词条仍为360个、18主题，词汇任务总数从1440增至1620；P1每主题140项，其余每主题80项。模态listening-picture与原listening-choice分别记录，但共享真实词义技能、同日示范和复习策略。到期图片卡进入共用复习；复习预告采用通用名称，避免提前展示目标英语词义。

播放器版本升至5；旧版本访问图片任务会明确要求更新，避免显示裸编号；原有题型继续支持既有兼容版本。题目公开投影只含各候选图信息，候选元数据按固定ID排序，与正确答案位置无关；正确图只在接受答案后的回执内提供。题目、听音状态、回执、档案与租约仍由原服务端校验。

## 媒体与离线

60段英式整词MP3和新增中文指令均在本机合成，用户词语/答案不发送给外部服务。保留22段旧中文指令，新增图片玩法后当前清单为v2、23段；v1不改。素材与生产说明见[素材记录](../design-assets/picture-words/README.md)。录音是合成整词，不宣称纯音素教学或发音评分。

公开离线壳增加哈希限定的word MP3及两张PNG，继续拒绝私有API和任意路径。图片校验MIME、PNG头和单文件2.5MB上限；音频单文件200KB上限。资源数上限从100调整为160，整体从8MiB调整为12MiB，用于受控增加的公共媒体；准备完成前不宣称可离线。最终本地构建为127个文件、9,900,683字节，离线壳eq-shell-v1-85facb3feab01ea2。真实Pad缓存、飞行模式和长期保留仍待实机验收。
