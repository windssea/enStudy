# 小学全学段英语课程体系

首发覆盖 P1–P6，以语言任务组织自主课程，教材按独立映射层接入。参考香港教育局已发布的 2025 年小学英语课程文件作为课程规划依据之一，具体教学内容与顺序仍需教研审核。[教育局课程文件入口](https://www.edb.gov.hk/en/curriculum-development/kla/eng-edu/curriculum-documents.html)

## 六个阶段

| 阶段 | 核心沟通能力 | 语言系统重点 | 阅读与表达目标 |
| --- | --- | --- | --- |
| P1 萌芽 | 问候、介绍、辨认常见事物、简单需求 | 字母与常见音、CVC、人称与 be、a/an、简单复数 | 图词对应；听读短句；口头与描写式表达 |
| P2 探索 | 描述人和地点、谈日常与喜好 | 常见字母组合、have/has、can、there be、方位与数量 | 简短对话与说明；词组到连贯短句 |
| P3 成长 | 询问作息、购物、给简单建议 | 词族、一般现在时、现在进行时、do/does、频率 | 短篇故事、便条、简单程序；3–5 句引导表达 |
| P4 远航 | 回顾经历、比较事物、描述计划 | 常见不规则词、一般过去时、比较级、数量表达 | 信息提取、因果与顺序；短段落和邮件 |
| P5 发现 | 解释原因、提出建议、组织未来安排 | 词缀、过去与进行对比、将来表达、情态与连接词 | 非虚构短文、观点雏形；有结构的段落 |
| P6 创造 | 整合信息、表达意见、完成协作任务 | 词义策略、时态综合、现在完成时入门、条件与关系表达入门 | 多文本线索、论据与总结；多段引导写作 |

高年级复杂结构以理解和实际表达为主，不将成人语法术语直接压给儿童。上表中的年级归属是原创课程建议，并非朗文逐单元顺序或 CEFR 等级认证。

## 每学期的组织

每个年级 12 个主题单元，分 A/B 两学期各 6 单元；每单元 4 节 10–15 分钟微课。每节都有“理解输入 → 示范 → 引导练习 → 独立应用 → 回顾”的结构，游戏是练习的形式。

| 微课 | 内容 | 可观察证据 |
| --- | --- | --- |
| A 听见与发现 | 目标词、听图、语音或词形规律 | 未显示文字时听懂词或意图 |
| B 句子工坊 | 一个主要语法目标，复用词汇 | 通过新词和新场景正确造句 |
| C 故事任务 | 分级短阅读或听力，信息提取 | 找出谁、哪里、何时、为什么 |
| D 表达与迁移 | 引导口语或写作、单元检查 | 换角色或换情景仍能表达目标意义 |

每学期有一套起点诊断和一套阶段检查。诊断不以年级锁题，而是先测先修节点再给推荐起点。中高年级语法不足者可回补，不必重走所有低年级游戏。

## 内容规模与覆盖矩阵

[P1–P6 单元矩阵](curriculum/p1-p6-scope.csv) 列出全部 72 个主题、语法、词汇、拼读/词形重点和综合任务。每行均为原创设计草案；它用于内容生产排期，并不代表课件和题库已经编写完成。

生产指标：288 微课、至少 2,592 个单元练习、约 240 拼读练习、目标约 1,440 个去重词条。每学期所有语法与词汇标签都要至少连接一个原创教学片段、一个独立提取练习、一个应用题和一个后续复习变式。不能只给高年级列目录而没有可学内容。

每个年级维持以下覆盖审查：听与读各不少于一个独立目标/单元；说与写按年龄有引导式输出；语法显性讲解与情景应用结合；自然拼读逐渐过渡到不规则词、词缀、上下文猜义。具体篇幅、词频和难度由试教修订，不能只以字数判断。

## 知识图谱

知识点使用稳定 ID，例如 `grammar.be.present`、`grammar.present-simple.third-person`、`lexeme.apple`、`phonics.cvc.a`。内容由图谱标注，展示顺序与图谱分开。

依赖示例：`pronouns.subject` → `be.present` → `be.questions`；`nouns.plural` 与 `be.present` → `there-be.present`；`present-simple.base` 与 `pronouns.third-person` → `present-simple.third-person` → `do-does.questions`。

词汇按“听辨 / 识义 / 拼写 / 语境使用”分别记录；语法按“识别 / 受控产出 / 新情景迁移”分别记录。听懂 apple 不等于拼写已掌握。图谱先修有硬依赖与建议依赖，家长可覆盖推荐路径，系统明确指出缺失先修。

## 示例教学目标

原创示范课“野餐伙伴”：孩子能够为不同伙伴选择 `am/is/are`，用 `I am... / She is... / They are...` 描述状态。已知词只选 happy、hungry、ready，避免同时测陌生词和新语法。

先观察三个人物和对应句子，再完成可点击或可拖动的积木。提示先问“主语是一个人还是多个人？”；错因区分主语识别、be 对应和词义。课末换新图片做独立题；次日用新角色提取。JSON 示例见 [lesson.schema-example.json](examples/lesson.schema-example.json)。

## 教材接入

课程体系另提供横向的 [专题特训](17-topic-training.md)：8类60专题打通不同年级与单元的同一知识点，含 [固定句式馆](18-sentence-patterns.md) 的12主题72条表达。基础课程的2,832题之外，计划新增至少480道专题练习，总计至少3,312道；专题中的其余题目引用原课程题，不重复计算题库规模。词形作为独立知识维度连接词条和语法，例如词条go的过去式与一般过去时句型分别记录。

教材绑定由 `series + edition + book + unit` 唯一定位，同一单元可映射多个自主技能，一个技能也可来自多个教材单元。映射应包括依据页码或目录来源、审核者、日期和状态。

版次未确认时，界面展示“自主路线；教材尚未绑定”。公开映射不能使用虚构的朗文单元名。首发自主课程不依赖教材账户或教材商业 API；若用户要求首发就精确同步特定朗文版本，该版目录核实与授权边界成为发布依赖。
