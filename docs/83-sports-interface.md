# v0.59 全站 NS运动系界面

当前阶段：本地实现与浏览器验收完成，等待GitHub Actions同步发布。发布成功后将补齐准确提交、运行、部署和线上校验结果。

## 解决的问题

已有运动系课程插图与旧后台导航、低龄玩具按钮、分散覆盖样式混用。推荐单词训练和按年级选主题被重复图片入口、步骤口号及重复标题挤到下方。

本阶段统一公共界面：电脑顶部横向导航，平板五项底部入口，轻量身份条；首页紧凑接续与六个核心学习入口；课程、单词、专题、句式、复习、拼读、写作和家长区沿用同一组青绿/白色面板、稳定分类色标、徽章、按钮、输入及反馈状态。例句和答题采用专注视图。题干25–32px，选项22px；所有按钮至少52px，主操作56px，答案68px。家长档案压缩为头像、年级、当前状态与编辑的紧凑排列。

单词的图片题仍可从相应主题进入，将重复导航图片并入同一个主题选择流；默认展开年级主题，删去三步口号、冗余确认条和无意义鼓励文字。小学与KET入口并排置于页标题旁，KET检索、附录、分页和原有训练方式保持。

本阶段保留当前课程/教学素材，没有声称全站图片已重画。教学时间线、原例句绑定、辅助登记、随机抽题、学习进度、账号权限和AI配置逻辑保持。未加入中文语音提示或自动朗读。

## 风格约束

[MASTER](../design-system/english-quest/MASTER.md)为现行唯一规则，历史相互冲突的方向归档为[HISTORY](../design-system/english-quest/HISTORY.md)。[插画规则](../design-system/english-quest/ILLUSTRATION_STYLE.md)与当前界面主色、14px按钮倒角、按压深度同步。

参考[官方NS运动介绍](https://www.nintendo.com/my/switch/as8s/about/index.html)的清爽运动菜单与原创3D人物方向，不复制品牌资产。ui-ux-pro-max设计系统查询返回的运动营销大Hero、红色主调和窄体标题不适合本产品，已排除；采用与学习任务匹配的导航、焦点和触控规则。

`main.tsx → interface.css`为唯一CSS入口。`legacy / components / sports`三个明确层级将历史功能布局放在当前视觉规则之下，`visual-theme.css`统一颜色、材质、字形、控件状态和公共断点。没有再追加一个不受控的覆盖文件。

主要文字对白底12.51:1，次要文字5.79:1，最浅主按钮对白字4.99:1，输入边界3.37:1。只用颜色区分状态的做法不被接受；保留选中ARIA、文本反馈、边框和可见键盘焦点。减少动效关闭持续/进入动画、悬停和按压位移。
