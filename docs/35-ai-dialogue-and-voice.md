# v0.16：角色短对话与轮流语音

2026-10-17，本地实现记录。延续ui-ux-pro-max与现有设计系统；默认关闭注册、AI和录音，不改默认管理员凭据。今天仅本地开发，保持Cloudflare免费；云端仍为v0.8，沿用10月18日08:05的最新main重试计划。

## 孩子与家长的实际流程

地图新增“英语小剧场”，提供P1–P6六个原创角色场景：水果、能力、日常、过去、计划、经历。示范句、设备朗读和打字可独立使用。家长开启后，孩子可以开始每段最多6轮的AI短对话，录0.25–20秒、自己试听、主动交给识别服务、确认或修改文字，再发送给对话服务。回复有英文、中文意思和一条短建议，可主动生成AI声音或选择设备朗读。不会自动上传、自动重试、评分或增加掌握度。

家长在原AI连接区域保存各服务的根地址、Key和政策链接；文本模型仅在需要文本能力时填写。对话、ASR、TTS分别选择连接，ASR模型、TTS模型和声音ID由家长按服务商文档填写，不猜模型可用性。先关闭开关保存，再主动做识别与固定短句合成测试，最后分别确认文字/录音的数据处理并开启。纯音频连接无需通过文本测试。修改连接会使其旧能力测试失效；仅改变开关或额度不要求重测相同音频协议。

测试会调用所选服务并可能收费；最小协议成功不代表识别准确、声音合适、教学正确或已通过iPad验证。原生实时通话继续报告false，没有用设备朗读冒充AI语音。

## 接口与协议

所有路径相对于`/api/v1`，同源JSON和现有HttpOnly成人/儿童Cookie，儿童请求继续带`X-EQ-Child-ID`防止旧档案页面误写。

| 接口 | 权限与行为 |
| --- | --- |
| GET `/ai/voice/settings` | 家庭所有者；配置、已验证能力和家庭当天用量，无Key |
| POST `/ai/voice/settings` | 当前密码、配置version、额度和独立同意；版本CAS保存 |
| POST `/ai/voice/test/asr`或`tts` | 所有者主动测试；请求UUID、version、当前密码；ASR附录音 |
| GET `/learning/conversation-options` | 当前孩子；可用能力、六场景、本设备未结束会话 |
| POST `/learning/conversations` | 当前孩子；场景和请求UUID；本设备同场景幂等恢复 |
| GET `/learning/conversations/:id` | 只返回同家庭、同孩子、同设备grant的有效短对话 |
| POST `.../:id/turn` | 确认文字、expectedTurn、请求UUID；每轮只允许一个待处理请求 |
| POST `.../:id/transcribe` | 主动发送本页WAV的base64，返回文字，不自动发送对话 |
| POST `.../:id/speech` | 只能合成该对话已保存的AI回复ID，不能代理任意文字 |
| POST `.../:id/close` | 仅原设备清除本段历史及其结果缓存 |

文本沿用已审核主机的Chat Completions适配器；识别固定请求`/audio/transcriptions`，multipart含file/model/response_format=json/language=en。合成固定请求`/audio/speech`，JSON含model/voice/input/response_format=mp3。服务商需要分别兼容这些协议，不能从“文本可用”推断语音能力。协议依据：[官方转写文档](https://developers.openai.com/api/reference/resources/audio/subresources/transcriptions/methods/create)、[官方合成文档](https://developers.openai.com/api/reference/resources/audio/subresources/speech/methods/create)。

录音采用AudioWorklet采集单声道PCM，在浏览器限20秒、重采样为16kHz/16bit WAV。服务器严格检查44字节规范头、数据长度、声道、采样率与时长，再计入额度；不相信浏览器声称的秒数，也无需在Worker转码。这个首版选择收窄了格式范围，替代原设计中的多MediaRecorder容器协商。[AudioWorklet需要安全上下文](https://developer.mozilla.org/en-US/docs/Web/API/AudioWorklet)，麦克风能力运行时检查，无支持或拒绝权限时保留打字/示范句。

麦克风只在点击录音后申请。停止、取消、切后台、卸载或迟到的授权结果均停止tracks并关闭AudioContext。worklet输出静音，原始声音不回放到采集回路；只有主动试听时播放Blob。录音/播放和设备朗读互斥，沿用全局speech状态暂停3D。CSP允许同源和blob媒体，Permissions-Policy仅允许同源麦克风，摄像头与定位仍关闭。实际设备权限与播放仍待测试。

## 隔离、保存与额度

`0017_ai_voice.sql`新增家庭配置、能力哈希、音频额度和短会话表。主密钥沿用服务端AES-GCM与家庭/用途AAD；Key不进入React。对话最多6轮，加密暂存30分钟；ASR文本、TTS音频和单轮结果加密缓存5分钟。到期不再返回；后续访问时惰性清理，不能宣称到秒物理删除。原始录音不写数据库，页面Blob卸载后释放。供应商自身的数据保留按其政策处理。

会话属于孩子与设备grant，多设备可独立对话但共享孩子的当天额度。文本轮数、WAV实际毫秒、TTS英文字符分别受孩子与家庭预算控制，并与已有家庭总次数和用量单位一起原子预留。测试计家庭额度；默认每孩子6轮/180秒/2000字符，家庭600秒/6000字符。每次音频先保守预留600用量单位，文本按有界提示大小预留；不是供应商token账单或精确费用。

未知、取消、协议失败等尝试保留额度，不自动退回或重发。相同文字轮次、录音内容或已保存回复的合成请求复用请求记录，换请求UUID也不能重复收费。缓存到期返回不可读，不静默再调用；文字历史仍可通过会话快照恢复。取消浏览器请求不能保证供应商停止计费。配置/账号/连接或设备权限变化后，服务端再次检查授权，阻止返回失效结果。

出站限精确主机、固定路径、禁止重定向、20秒超时；ASR响应最多8KiB，TTS最多256KiB。MP3仅做类型/长度/魔数与已知Key回显检查，不能据此保证可播放或音频内容与文字一致；主动试听、可信供应商与后续质量审核仍必要。文本严格解析三个字段，限制长度、语言与场景词，过滤常见链接、隐私及危险词；此过滤并非完整内容安全或隐私保证。

AI英文回复写入现有教学暴露指纹，不把刚看过的示范当作独立证据。孩子原话不会写进该暴露表。AI对话只用于练表达，标准判题、SRS和掌握结果仍由确定性题库处理。
