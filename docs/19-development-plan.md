## 本地开始开发

要求Node.js 22.12以上，当前验证版本24.19.0；使用仓库的npm锁文件。

```powershell
npm ci
npm run setup:local
npm run dev
```

本地页面为 [http://127.0.0.1:5173](http://127.0.0.1:5173)，本地Pages API为 [http://127.0.0.1:8788/api/v1/health](http://127.0.0.1:8788/api/v1/health)。先在家长空间选虚构开发档案，再体验语法、时态、词形或句式样题。D1保存在被忽略的`.wrangler/state`，重复setup不会清空已有答题。

`setup:local`只运行`--local`迁移与虚构种子，不登录Cloudflare、不创建云数据库。`.dev.vars`由示例生成且不进入Git；其中的本地身份开关不能上传为远程变量。

## 近期开发顺序

### M0 工程和免费部署基线

出口：锁定依赖，可构建；本地D1真实运行；开发样题保存/复习/隔离/幂等通过；CLI计划可预览；远程部署须在本人账号登录后单独验证。当前本地与免费开发/正式发布出口均已验证；真实设备及完整运营门槛另行验收。

### M1 正式家庭身份和进度生命周期

优先实现成人注册/验证/恢复与撤销、家庭邀请、儿童grant、设备接管、活动会话恢复。先验证Better Auth与D1/Pages组合，若不通过再评估兼容方案；不自行实现密码学。接着实现hint/reveal统一协议、完整事件收据与跨设备恢复。

免费路线还须验证认证CPU预算和恢复成本：先评估成人可访问的OAuth或passkey路径，不能默认强制接入收费邮件服务；若采用密码认证，必须实测哈希对免费Worker预算的影响。供应商、注册与恢复策略确定后才能宣布M1认证完成。

出口：两个真实测试家庭互相越权读写均失败；儿童不能进入成人设置；重载恢复当前题和收据；撤销立即生效。通过后才开放云端进度写入；M0开发身份永久不用于线上认证。

### M2 学习播放器与内容生产流水线

将8道代码样题切换为经过审核的不可变内容release，建立choice/input/order以外的听音、分类、纠错、阅读、引导表达题型。支持slot、合法变体、题目家族隔离、撤题和版本兼容；搭建编辑/审核/发布校验。

六年级并行制作代表课并持续扩展全部72单元；每年级都有真实内容和验收，不能只在界面列出P1–P6即声称覆盖完成。自然拼读、词汇、句式与综合任务共用知识点标注。

### M3 专题诊断与复习闭环

实现60专题的诊断/分层/对比/迁移/复测、72条句式的槽位与变体、词形规则与例外。建立统一的复习选题、积压保护、独立证据、日报/周报、离线待同步与冲突处理。

出口：同一孩子跨课程/特训/复习每天不重复晋级；提示与示范后不误计独立掌握；第7/30天使用未暴露题目家族；离线证据等待在线确认。当前M0只实现其中的存储和规则调度。

### M4 BYOK与轮流语音

v0.16已在本地实现六场景短对话、确认文字、AudioWorklet规范WAV、独立识别/合成协议和预算，144项单元与356项运行检查通过。M4仍为partial；真实供应商、PC/iPad麦克风/播放、实时通话与出题审核待验，见[轮流语音记录](35-ai-dialogue-and-voice.md)。

成人设置密钥、服务端加密与轮换、精确预算、供应商能力探测和出站主机名单。基础课程继续不依赖AI。轮流语音按ASR→受限对话→TTS逐供应商验证，明确格式、取消、转写确认和数据处理；原生实时语音按原方案后续提供。

不用Workers AI免费试额代替BYOK产品要求；不以浏览器speechSynthesis伪装真实语音对话。此阶段需要用户选定并提供供应商配置到安全设置或Secret，不在聊天中收集密钥。

### M5 全学段、实机和发布门槛

完成288课、至少3,312道独立基础题及全专题生产目标；教材精确映射须先确认系列和版次。完成iPad Safari/Android平板/PC测试、降低动效与2D、删除恢复、密钥和预算演练。正式发布前满足 [验收计划](12-validation.md) 的全部门槛。


`verify:local`要求dev服务运行，只访问硬编码本机地址，写入虚构测试档案并验证隔离与幂等。单元测试不需要Cloudflare账号。SQL迁移一旦应用不覆写，新增`0002_...sql`；公开目录只由CSV生成，私有答案留在服务端目录，不能从React直接导入。

开发中每个切片交付可运行代码、相关检查、验收证据和剩余范围；不以文档中的“已计划”替代实现完成。当前验证记录见 [M0验证](21-m0-verification.md)。
