# v0.6 课程、专题练习与复习闭环

日期：2026-10-17。当前是分阶段开发版本，继续通过同一个GitHub Actions流程同步发布Preview和Production。注册保持关闭，账号与两个环境的数据隔离沿用M1实现。

## 实际可用的范围

本次新增24节原创语法与表达微课，一至六年级各4节，位于各年级上学期第一单元。每课包含中文规则、3组英文例句与中文意思、3个词汇、生活应用建议，以及9步练习。练习使用选词、输入、词块组句三种形式，共216个练习变体，来自71个不同句子家族；这216个变体不能按216道独立诊断题计算。

基础内容涉及问候介绍、人称与be、have/has、日常习惯、频率、一般疑问句、一般过去时、规则与不规则过去式、时态对比、计划和建议。只有有实际题库的17个专题开放练习，其余显示准备状态；当前每轮最多6个不同句子家族，完整诊断、迁移、复测分层仍未完成。教材版次未明确，所有新内容为独立原创，尚未与朗文具体册别完成映射。

学习地图进入小讲堂，再进入连续练习。服务端冻结本轮题目与顺序，保存当前游标、提示和回执；刷新恢复到当前步骤。答题后才能进入下一步，重复点击不会跳过题目。完成记录分别显示总题数、答对数和独立完成数；家长空间显示当前孩子最近10轮学习足迹。完成一课不等同于掌握该知识点。

例句和词汇可主动点击朗读，使用设备的Web Speech英语声音，支持停止及不可用提示，不自动播放。该能力是文本朗读；AI语音对话、录音和口语评测仍待M4。

复习从D1中读取已到期的技能与题型卡片，最早到期优先，每轮最多8题；优先换用不同于最近一次的句子家族，同轮不重复家族。新学内容未到期时不强行建立复习任务。现有独立证据、提示不晋级、同日不重复晋级和幂等保护保持。第7/30天未暴露家族测验和完整积压策略仍需后续实现，不能把当前选择器等同于全部复习验收完成。

## 内容版本与数据迁移

- `0004_learning_flow.sql`增加课程游标、来源、完成记录和release题目成员表。
- `0005_course_foundations_v1.sql`发布不可变的`course-foundations-v1`，含24课与216变体，并收录原8题的版本成员关系。
- `content/courses-v1.mjs`是原创源，`scripts/build-course.mjs`生成公开教学元数据和私有服务端题库；`npm run content:build`核对不可变迁移。已应用迁移不能覆写，改内容须新增release和迁移。
- SHA256清单覆盖课件、题目与原题库摘要。开课核对发布状态和题目成员关系。完整编辑审核、撤题及旧会话兼容流水线仍未完成。
- 浏览器静态包只包含公开课件与目录，私有答案、源题库与迁移不进入dist；本机Vite也阻断这些私有路径。

本机`npm run check`共42项通过，含课程覆盖、合法变体、同句家族、时态错误拒绝与复习选择器。`node scripts/verify-runtime.mjs --existing`使用真实workerd与本地D1，分别通过27项基础学习检查、24项账号检查、25项课程流程检查。课程检查包含并发建课、双击下一步、旧步骤重试、提示恢复、9步完成、独立计数、完成幂等、过期lease拒绝、专题任务，以及仅修改测试孩子到期时间后验证真实复习任务。专用测试儿童档案与记录在结束时清理。
