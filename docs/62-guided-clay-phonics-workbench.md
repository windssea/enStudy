# v0.40 分步拼读与可操作的粘土词块

在现有六站拼读小路内，将示范整理成“听整词 → 看字母搭档 → 合起来读”。词义块站使用“看词义块”。孩子可直接选择步骤、点任意字母块或使用上一个/下一个按钮，既能点3D实物，也能用原生按钮和键盘。没有自动翻页、计时压力或新的导航层级；开始实际练习仍在示范之后。

## 教学与记录

继续先由服务端确认原示范记录，再展示英文及观察台。a_e、i_e、o_e的两个位置一起选中，中间辅音仍留在原位；合拢只改变间距，不重排字母。sh等单块内的多个字母也明确说明本词的对应关系，复合词使用词义块说明，不把它们当作音素数。

整词声音继续由孩子主动点按。只有真实播放器ended才显示“整词已播放完”；停止、失败和离开不触发这个反馈。无需打开声音也能走完观察步骤。该反馈仅保留在当前示范组件内，不增加答题、奖励、听音认证或复习晋级，不声称儿童已会读或发音正确。逐音素声音、完整自然拼读教学和人工听审仍待补齐。

## 3D与2D

本阶段复用已有Blender狐狸/皮卡丘资产和ClayStudio棚灯，没有声称新增角色建模。重做圆角双层演示台，伙伴与词块分区放置；词块按文字长度增加物理宽度及纹理画布，字面加大，保留清楚的系统字体。相同音标记的分组关系沿用已发布内容，不修改不可变题库。

分开观察时选中词块抬起，合拢时回到同一基线；连接标记跟随词块的实际横向位置和高度。快速切换从当前姿态继续收敛，不等待旧动画结束。镜头依据完整展开范围取景，合拢期间保持镜头稳定。使用闭合圆角挤出体、球体及现有角色，没有叠加实时后处理或新外部字体、HDR依赖。

保留650ms的有限动作、按需帧、30fps动作上限、1–1.5 DPR与现有10fps阴影刷新预算。安静、2D、离屏、后台或整词播放时停止连续帧。2D替代改为实际分组的平面词块，展示同样的选择及合拢关系；窄屏可换行并自动增高，避免文字落在固定画框外。可访问名称、按下状态、步骤和说明由DOM提供，Canvas为装饰，键盘不依赖三维射线。
