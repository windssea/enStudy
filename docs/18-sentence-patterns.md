# 固定句式与常用表达体系

固定句式纳入首发语法体系，并在专题中心提供“固定句式馆”。首批规划12个句式主题、72条核心表达，与词汇、语法规则、时态和词形关联；不是把零散例句贴到语法讲解后面。完整结构化清单见 [句式目录](curriculum/sentence-patterns.csv)。这些是待教研审核的原创规划，不是朗文教材的逐课目录。

## 内容分层

| 类型 | 学习目标 | 示例 |
| --- | --- | --- |
| 常用整句与对话语块 | 理解场景、得体回应，先整体认识 | Nice to meet you. / You're welcome. |
| 可替换句框 | 保留结构，替换人物、事物或动作 | I'd like to + 动词原形；It's time for + 名词短语 |
| 搭配与语法构式 | 掌握限定条件、词形和语义关系 | be good at + 名词/动名词；too + 形容词 + to do |

“固定”不等于每个单词都不可变，也不意味着同一意思只有一种表达。每个句式必须标注固定部分、可替换槽位、接受变体、使用场景与限制；不能将所有表达简化成中文翻译配一个唯一英文答案。

## 首批12个主题

| 主题 | 句式举例 | 训练重点 |
| --- | --- | --- |
| 问候与礼貌 | Nice to meet you. / Thank you for... | 场景、语气、问答配对 |
| 介绍与个人信息 | My name is... / Where are you from? | 人称、姓名年龄、问答对应 |
| 描述与存在 | There is/are... / What colour is...? | 数、指代、物品和位置 |
| 喜好与愿望 | like doing / would like to do | 名词、动名词、不定式的区别 |
| 能力、建议与规则 | can do / should do / mustn't do | 情态动词后的原形及意义 |
| 请求与许可 | Can I...? / Could you...? | 谁提出请求、谁执行动作、礼貌表达 |
| 邀请与建议 | Let's do / How about doing? / Why don't we do? | 不同句框的词形限制和回应 |
| 动词接续 | want/need/hope to do / help somebody do | 动词后接续形式与合法变体 |
| 介词与常用搭配 | good at doing / interested in... / look forward to doing | 介词后形式、固定介词和语境 |
| 时间与频率 | It's time to do / It's time for... / How often...? | 时间功能、句框转换与回答 |
| 比较与程度 | as...as / too...to / ...enough to | 词序、比较对象与合理语义 |
| 原因、条件与衔接 | because / so / if...will / when... | 分句关系、逻辑与适用时态 |

按P1–P6建议年级渐进学习，不要求低年级背全部句式。look forward to doing、one of the...等作为高年级进阶内容，须有先修和教研审核。正式覆盖范围以课程目标和教材版次核对结果修订。

## 训练流程

先听/读一个完整场景，理解句式解决什么沟通问题；再用颜色和分隔线识别固定部分与可替换词块；接着进行替换练习、易混辨析，最后在新场景主动使用。各环节都接入现有分层特训与延迟复测。

1. 情景选择：想邀请朋友一起游泳时，选择合适的说法；不是只根据中文词序猜答案。
2. 槽位搭建：固定`How about`，放入`swimming`；固定`Let's`，放入`swim`。
3. 易混对照：`would like + 名词`与`would like to + 动词原形`；`time for + 名词短语`与`time to + 动词原形`。
4. 纠错说明：看到`Let's to play.`时移除多余to，理解Let's后接动词原形。
5. 问答衔接：`Would you like some juice?`接`Yes, please.`等适当回应，同时接受语境中其他合理表达。
6. 迁移表达：换活动、人物和场景，尝试口头或书面表达；看过的例句不能再当成独立迁移证据。

## 示例对比课

目标是用不同方式建议周末活动：

- `Let's play football.`：Let's + 动词原形。
- `How about playing football?`：How about + 动名词短语。
- `Why don't we play football?`：Why don't we + 动词原形。

同一活动换三种框架时，分别更新句框选择、槽位词形和情景应用的证据。孩子知道该说建议，却把playing放到Let's后面，归为接续词形问题；只会跟读原句、不理解邀请情景，则继续理解与匹配练习。

## 结构化内容与判定

每个pattern有稳定ID和不可变版本，关联功能、建议年级、主技能、先修、规范句框、正例、反例、槽位schema、可接受变体及错因标签。槽位类型包括名词短语、动词原形、动名词短语、形容词和完整分句；语义限制也要明确，例如比较双方须可比较。

训练题使用人工审核的答案集合或已校验词块，而非对任意文本套一个正则。like既可接动名词也可接不定式的常见语境，不得把合法的`I like to read.`一概判错；help后有带to与不带to的合法形式。自由表达由rubric给建议，不由AI的单一答案决定晋级。

数据库增加`sentence_patterns`与`topic_patterns`，复用skill、item和review_card，不新增独立能力分数。公共句式卡可展示教学例句；诊断与结测必须选择未暴露的词块/题目家族，避免读卡后立即测同一句却标成长期掌握。

`GET /sentence-patterns`按主题、功能和建议年级筛选已发布条目，`GET /sentence-patterns/:id`读取教学卡；句式练习从已有`POST /training/runs`创建，答题仍用`POST /attempts`。AI出题需指定pattern版本和槽位限制，生成例句经过语言与确定性校验后才使用。

## 首发规模和验收

本次增加12个句式主题，专题总数由48增至60，仍归于原8个大类中的“句型”类；语法入口与固定句式馆交叉索引。72条表达是内容条目数量，不等于72道练习，也不重复算成词汇数量。

12主题每个至少24条题目引用，新增288条映射；每主题至少8道新增独立练习，共96道。全专题共1,440条引用、480道新增独立练习，总基础题生产目标至少3,312道；若无法覆盖每条句式的理解、替换和迁移，应补题，不以最低数字代替教学覆盖。

验收要求：72条均有场景和正例、槽位与限制明确、合法变体不误判、低年级与高年级分层、情景使用与死记原句分开展示、错因与词形/时态互通、课程与特训不重复推进记忆阶段。
