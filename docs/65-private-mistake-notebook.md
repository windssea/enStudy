# v0.43 个人错题小本与辅助重做

复习花园增加“错题小本”，把已经保存的答错记录和提示/示范后答对记录变成可主动查看的学习线索。包括语法、时态、词形、句式、单词、拼读与阅读的既有题目，覆盖选择、输入、排序、分类、修正、听音和原文依据七种题型。历史记录按作答事件排列，同一道题可能多次出现；不是尚未完成任务的计数，也不据此计算掌握率或推断唯一错因。

## 阅读与教学

列表默认只显示标题、类别、时间和保存结果。可以按两类结果与学习内容筛选，每页最多20条，后续页沿用第一次读取的序列上界，避免正常翻页混入刚追加的记录。筛选与重新读取回到第一页；刷新页面不把旧答案留作新的未辅助材料。记录时间按本机显示。

孩子主动打开一题，先在服务端记录当天的示范证据，再返回题目、保存答案和标准解释。界面分为回到原题、对照那次答案、找一个线索三步。原题来自原来的不可变版本；保存文字可能已统一大小写和空格，因此不声称还原原始按键。分类、修正及依据题使用原回执中的人类可读明细，避免显示内部答案编码。参考句只是一种有效表达，不代表其他合法表达错误。

听音回看可以显示那次材料的听音文字，会同时写入相应示范键。该页不调用AI、语音供应商或浏览器录音，不伪造口语/听力认证。查看讲解不增加作答、完成、星星或掌握；以后从其他入口遇到相同材料，也会受已有的当天示范规则保护。完整专题诊断专用材料、错误归因及教学审核仍待完成，本功能不替代它们。

## 辅助重做

历史对照保持当时的题目与回执；新的辅助练习使用当前已发布版本，避免把已经修订的旧判法重新用于教学。版本不同时，打开记录会同时登记新旧材料的示范证据，界面明确提示“这题后来有调整”，给出新版题目与讲解，并提供“跟着新版讲解练习”。客户端提交看过的mistakeVersion，若又有更新则要求重新打开；当前版本撤下时，历史仍可读，但不能回退到旧判法重做。

新任务从创建时hint_level=1，source_ref保留原事件来源与练习版本；LearningSession的guidedRetry在刷新、接续和客户端重载后继续返回。答对仍为hinted，independentEvidence=false，回执与reward_ledger.delta都为0；会保存辅助练习并使用原有复习调度，不增加独立成功计数。原来的作答与回执不修改。查看新版讲解只经显式POST披露，普通任务快照不会自动带出新的私有讲解。

入口不绕过设备接续：另一设备有活动任务时仍须明确接续。一次未知创建响应可使用同一clientRequestId恢复，不能将该编号改用于另一记录。新页面重新打开可以开始另一次明确的辅助重做，始终没有独立证据或额外星星。完成后返回错题小本，复习花园仍保留正常的到期新材料练习。

## 接口与隐私

| 接口 | 行为 |
| --- | --- |
| GET /learning/mistakes | 当前儿童的摘要分页；kind、category、snapshot与before限定查询，最多返回20条 |
| POST /learning/mistakes/:eventId/open | 验证历史作答属于当前儿童并记录示范，返回历史对照；修订时另给新版讲解与retryVersion |
| POST /sessions，exerciseId + mistakeEventId + mistakeVersion | 验证原记录与当前题目版本，创建有显式辅助标记的任务 |

分页游标不是授权凭据，所有请求均按真实家庭、儿童、grant与当前成人上下文检查。延迟的前端结果也要符合原儿童和事件，切档案、换页或卸载会取消等待并关闭旧内容。接口沿用private/no-store，答案不写入URL、localStorage、应用壳缓存或新资料表；离线时提示重新连接，不把本小本当作离线题包。

打开与重做同时复验原记录、当前材料的发布状态、成员资格、密码状态和登录撤销。披露写入失败或最终授权检查失败时不返回答案。创建重做时用既有D1断言表，将原记录存在、原版与当前版本发布状态检查、暂停旧任务和创建新任务放入同一个batch；发生竞态则整体回滚。移除儿童沿用现有外键级联，家庭导出继续包含原始作答/回执与会话来源。本阶段没有新增迁移、密钥、供应商连接、云资源或新保留期，所有已应用SQL保持不变。
