# v0.11 受管理家庭账号

2026-10-17。已完成本地实现与回归，尚未发布到云端。公开注册保持关闭，默认管理员账号与指定密码未修改。管理员可以给不同家庭创建独立账号，每个家庭管理自己的孩子和学习记录。

## 使用流程

管理员登录家长空间，在“家庭账号管理”填写登录账号、家庭昵称、临时密码，再输入当前管理员密码验证。系统不要求邮箱、手机号、学校或儿童实名，不自动发送账号消息；管理员通过自己信任的渠道交给家长。

新家长首次登录只能进入改密页，不能读取、创建儿童档案或开始学习。设置自己的密码后，所有原有登录退出，使用新密码重新登录，即可添加孩子。普通家长在“账号与密码”自行改密，同样退出所有设备，学习记录保留。

管理员可以停用、恢复账号或重设临时密码。停用立即撤销家长会话与儿童授权；恢复需要重新登录，不复活旧令牌。重设会撤销原登录并重新要求首次改密，且不会自动恢复已停用账号。管理员自身不能从列表停用或重设，可用本人改密表单。

账号为3～40位字母、数字及 `._-`，以字母开头，服务端统一转为小写。家庭昵称1～40字；新密码12～128位，可用长短语，不要求强制符号组合，允许粘贴和密码管理器。密码输入可主动显示，保存后清空；列表与响应不回显密码或哈希。

## 接口与一致性

| 接口 | 权限和行为 |
| --- | --- |
| `POST /auth/register` | 继续返回403，未开放自助注册 |
| `GET /admin/accounts` | 明确的站点管理员角色；每页50项，时间与ID游标；仅账号、家庭名称、儿童数量、状态、版本等元数据 |
| `POST /admin/accounts` | 管理员重新验证密码；一个事务创建成人、家庭、owner成员、加盐凭据及审计记录；用户名冲突整批回滚 |
| `POST /admin/accounts/:id` | 停用、恢复、重设；重新验证当前管理员密码并提交列表版本；旧版本409，保护管理员账号 |
| `POST /auth/password` | 家长验证当前密码，原子更新凭据并撤销所有登录与儿童授权；清除当前浏览器Cookie |
| `GET /me` | 增加 `adult.isAdmin` 和 `adult.mustChangePassword`，不暴露凭据 |

迁移 `0010_managed_accounts.sql` 增加停用、首次改密、凭据版本、`site_admins` 与 `account_audit`，本机已应用，不覆写历史迁移。管理员身份来源是角色表，不依赖用户名或前端标志；创建请求中的 `isAdmin`/`role` 不能提权。普通学习接口仍按家庭授权，管理员不能通过学习接口选择其他家庭的孩子。

密码用随机盐与100000次PBKDF2-SHA256保存，登录和再次验证有限流。敏感写入的事务首句重新检查当前会话、过期、撤销、角色、凭据版本及目标版本，再以审计记录作为该事务的后续写入条件，防止校验与提交之间权限变化。审计不保存密码、令牌或儿童答题明细。儿童档案写入和登录会话创建也重新检查提交时的授权或凭据版本。

停用和改密均撤销有效会话、儿童授权，不删除家庭和学习记录。并发修改同一版本只有一次成功；恢复不会令旧会话再次有效。管理界面发现版本冲突会刷新并取消旧操作，要求重新选择当前账号状态。
