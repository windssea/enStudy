# v0.59.2 直接学习指导

状态：本地实现、573项单元测试及隔离浏览器验收通过，等待同步发布。

## 调整

按“选择单元 → 选择课程 → 阅读例句和规则 → 开始练习”组织学习流程。截图中的写作、对话、专题与复习宣传卡在v0.56已从课程页移除；本阶段继续删除课卡副标题，以及例句页重复的年级、学期、课次和泛化任务介绍，不增加替代推荐区。

例句、翻译和对应规则直接展示。规则不再折叠在“语法说明”内；例句位置只出现一次。按钮显示“上一例句”“下一例句”“开始练习”，完成过的课程显示“重新练习”。词汇和拓展保留在紧凑、带展开箭头的折叠行。

教学内容、已保存进度、课程完成记录、示范登记与评分不变。保留有意义的课程路径、练习状态、错误提示、登录要求与AI同意。未新增素材或中文提示音，没有数据库变更。

## 验证

573项单元测试、格式检查、前端与Worker构建通过。原下学期课程测试更新为验证规则直接展示，同时保留学期身份、例句和开始练习入口断言；独立使用例句组件时仍有真实年级/学期路径。

隔离内存D1应用0001–0050后，通过内置浏览器检查1280px桌面、768px平板和375px窄屏。翻页同步例句、返回恢复所属单元；课程列表只显示当前单元4课，无课卡副标题与旧推荐区。窄屏无横向溢出，翻页和开始按钮均56px高；拓展可主动展开，访客开始练习仍需家长登录。浏览器尺寸验收不等同真实Pad或儿童试用。
