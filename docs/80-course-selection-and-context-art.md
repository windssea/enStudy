# v0.56 课程选择与统一情境插画

2026-10-20，按用户要求取消课程岛屿与固定陪伴角色，直接选择课程。当前为待发布记录；提交和本地通过不代表云端部署。

## 最终界面

年级/学期 → 六个真实单元 → 当前单元四课。PC单元列表在左、课卡在右；平板与窄屏改为单元下拉，平板课卡双列、窄屏课卡单列横排。课程返回保留当前单元；72单元、288核心课都保留，完成状态仍来自已完成练习记录。移除重复的全学期课程区、岛屿/路线标题、写作和口语推荐侧栏、数量宣传和无关操作提示。课程页只显示课内练习接续，其余任务继续由首页接续。

例句页压缩旧样式的多重留白、恢复行内返回按钮，图片、句子、语法说明与56px练习操作保持清楚层级。不加中文操作语音和提示按钮。

## 素材与范围

首批为P3A-U01四课：同学与课本、蓝色书包与文具、老师与两张课桌、图书馆小帮手。最终人物遵照用户修订，采用浅肤色东亚/欧洲外观、栗棕马尾/浅金短发、薄荷外套/拼色运动装。人物仅是教学情境中的学生和老师，不作为固定陪伴角色或换装功能。

模式为内置imagegen；完整提示与编辑参考链见[ART_PROMPTS](../design-system/english-quest/ART_PROMPTS.md)。PNG源件在设计目录，生产WebP保持原尺寸与alpha，四图合计731278字节，单图141476–241648字节。统一遵守[插画风格](../design-system/english-quest/ILLUSTRATION_STYLE.md)，页面细则见[课程选择](../design-system/english-quest/pages/course-selection.md)。

`public/content/learning-art.v1.json`登记素材哈希/尺寸/替代文字，`course-scenes.v1.json`按真实课程ID与例句原文绑定。封面表达课程情境；例句页只在明确匹配时显示图片（四课共六个例句）。不对疑问、否定、人名或未配图课程猜测图片，不用校园图冒充其他课程。其余284课仍有完整文字入口，本阶段不宣称全部绘图完成。

新增四个精确公共WebP路径进入离线白名单，保留容器/MIME/长度与16MiB预算验证。课程绑定JSON被编译进前端，不缓存私人资料和API。当前129资源、15081196字节，发布前以最终构建重核。

## 验收与发布

本地类型检查和557项单元测试、构建、Worker打包及格式检查通过。课程用例遍历12学期72个单元，核对每次只呈现所选单元四课、实际完成状态和精确图文绑定；离线用例覆盖四张新图与拒绝未登记路径。内置浏览器在独立的内存D1验了1280×900、768×1024、375×812课程、单元切换、未配图课程可进入、返回保留选择、例句前后翻页和第三句不误配图片；无控制台错误/警告。1024×768中间布局检查后，平板统一收紧为下拉单元选择，最终768竖屏再验通过。GitHub Actions与Preview/Production同版本核验发布后补记。

现有题目、课程版本、示范登记、练习评分、D1迁移及密钥配置均不改变。真实Pad和儿童使用研究仍待进行。
