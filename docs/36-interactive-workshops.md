## 本阶段交付

专题中心新增“互动工坊”，也可进入`/#workshops`。12组内容建议覆盖P1–P6，允许回补较低年级。每组有24个分类组合与8句原创修正，可随机抽5/10/20题，近期分配过的题目家族优先避开，轮内交替选取两种题型。

| 建议起点 | 工坊 |
| --- | --- |
| P1 | a/an、复数变化、主语与be |
| P2 | there is/there are |
| P3 | 第三人称单数、ing变化、习惯与此刻 |
| P4 | 规则过去式、不规则过去式 |
| P5 | 比较级、能力/建议/规则 |
| P6 | 到现在的经历与明确过去时间 |

共384项任务：288组卡片组合和96句修正。组合会复用相同目标词，不能算384个独立词条或独立语言事实。工坊不增加课程完成数，现有课程仍为48/288，剩余240课与完整媒体内容待制作。它们属于原创受控练习，未宣称与某版朗文教材精确对齐，也不等于自由表达或教学质量已验收。

分类操作为“点卡片→点篮子”，可改放或取回全部。支持Tab/Enter，不强制拖拽；52px触控目标、已选状态和文字播报沿用ui-ux-pro-max及现有设计系统。只显示放置状态，提交前不标对错。整组全部正确才算本题正确，不把四张卡当成四次独立晋级；提交后逐张核对。

修正操作为“点选一个词块→输入新词或短语→查看自己的预览→检查”。必须选对位置并写对替换，不能用任意整句绕过题型。情境限定表达目标，例如长期习惯与临时安排的区别。提交后展示对应词块、合法替换与完整正确句；不向孩子声称所有脱离情境的原句都绝对不合语法。

## 判题与历史兼容

公开`Exercise.type`新增`sort`和`repair`。`sorting`只含卡片和分组ID/文字，`editing`只含句子词块；私有分类映射、可接受修改、正确句和教学指纹目标不进入公开题目。Vite额外拒绝新内容源和私有JSON访问。

`POST /sessions`新增`workshopId`，与其他入口互斥，source为workshop。继续冻结题目ID/版本、release来源、卡片与篮子顺序；刷新和接续不重新抽题。单项练习、随机工坊和共享复习使用同一服务端判题。

| 作答 | 格式与验证 |
| --- | --- |
| 分类 | `Answer`仍为字符串数组，每项为`cardId=groupId`；必须覆盖全部卡片且无重复、无未知卡片或篮子 |
| 修正 | `[partId, replacement]`；只选存在的词块，替换1–60字符，无HTML或控制字符，按私有接受集合评分 |
| 重试 | 分类按卡片ID规范排序，因此数组顺序变化仍复用同一回执；修正规范化空白、大小写和兼容撇号 |

不完整结构返回422且不写尝试、奖励或复习卡；完整但放错/改错则记录incorrect。已保存后更改答案返回冲突，保持原回执；旧选择/输入/拼句的规范化与回执格式保持兼容。

新网页通过`X-EQ-Player-Version: 2`声明能呈现结构化题型。未声明的旧标签页仍能学习原有题型；若要开始、恢复或复习新题型，服务端返回`PLAYER_UPDATE_REQUIRED`并提示刷新。新建任务前先检查兼容性，失败不会暂停/替换旧任务；刷新后仍读取同一份冻结卡片和篮子顺序。此声明只用于显示兼容性，不是授权凭证。

内容用追加迁移0018发布，只有新成员，不复制原有题库。复核时根据[Cambridge Dictionary的bus条目](https://dictionary.cambridge.org/dictionary/english/bus)确认美式也有busses变体；0019只追加该修正题v2接受集合，不改v1、旧任务或旧回执。当前目录聚合384个最新ID，历史版本可单独解析，D1逐项校验原始release成员资格。

## 复习与反馈

分类记录`rule-classification`，修正记录`sentence-editing`，不与原有辨认、受控表达或拼写混为一项能力。`/progress`现在返回modality，复习花园按知识点加能力类型标识卡片，修复同技能多种能力显示同一键的问题。

分类的一组目标和修正的单个目标共用相应教学暴露指纹。同天见过其中目标的正确答案、提示或示范，再完成相关任务按辅助证据保守处理；隔天未新看示范时才可能独立提取。重复组合的熟悉度不应制造新的掌握证据。规则文字本身不作为具体答案曝光，具体范例/答案仍按已有指纹机制记录。

分类与修正都返回已保存的逐项反馈；整题结果、奖励与复习调度仍原子保存。它们能进入正常到期复习和跨设备显式接续，旧设备不能写入新答案，未保存草稿换题时保留可读的词句说明而非内部ID。

## 动效与边界

工坊页新增程序化双篮与落卡Three.js演示，以及配套SVG替代图；按钮文案明确它只是演示，不判题或增加进度。实际卡片放置使用短入场动效，提交后才显示对错。继续共用懒加载Canvas，后台、离屏、设备朗读时暂停；2D、安静模式和系统减少动效保留。
