# v0.42 六站粘土课程地图

地图从三个装饰岛屿改为对应当前学期六个单元的真实导览，继续使用已有狐狸和皮卡丘v2粘土模型、PMREM棚灯、细颗粒材质与软阴影。新增写作桌、望远镜和灯塔几何，连同小屋、图书和兔子花园组成六种站点；编号、蓝色选中环和下方中文目标同步。装饰物只作为站点记号，不将望远镜等物件误称为每个年级的课程内容。此前观察中“四个单元”的判断已用实际目录修正为每学期六单元。

## 课程与进度

CourseIslandMap读取当前目录、当前年级/学期的课程及已练过记录。courseMapStations按真实单元序号排列，计数去重，选中站点打开本单元第一节未练课程；全部练过时可从第一节回看。无课的站点不会产生课程入口。浏览地图、挥手、转身、选站点均不发送作答、奖励或课程完成请求。

每个站点有完整中文标题、已练过计数和“正在看”文字；点小岛或按钮只切换浏览目标，再由明确按钮打开课程。原有下一课推荐和全部课程卡继续可用。当前页面内按儿童/年级/学期保留刚才的站点，进课程再返回能继续看同一单元；刷新时重新使用当前课程建议。该浏览选择仅在页面内存中，不进入D1、localStorage或离线学习证据。

## 三维互动

六岛按蛇形排列，桥路沿各岛前侧连接，避免伙伴直接穿过岛后方的小屋与摆件。伙伴响应选择在2200ms内短暂跳步，快速改选从实际显示的中间位置重新计算；到达后停止循环。挥手和看背面沿用现有模型姿态。热气球只在主动招呼后短动，不持续漂浮。

桥板为圆角实例网格，共用几何与材质。六个站点使用确定性的粘土颗粒和现有棚灯，不引入网络HDR、实时后处理或新模型下载；继续懒加载3D与各儿童已选GLB。环境、几何、材质与纹理按所有权释放。每岛网格少于65、三角面少于26000的现有预算检查延伸至六种布局；未据此声称场景总帧率达标。

按需渲染仍由requestAnimationFrame驱动，最多请求30fps，阴影最多更新10fps；中途改选保留当前横向路径位置与抬起高度，避免突然落地。有限计时器只结束活动状态，不驱动逐帧绘制或保存业务状态。安静、2D、网页隐藏、离屏和听音时取消持续活动并采用目标静态位置，恢复后不补播。WebGL丢失或加载失败切换2D；原生按钮仍可完成导航。预留固定画面高度，相机同时按宽高取景，不锁定滚动/缩放。

FlatMap改为同编号与同选中位置的六站SVG。将来目录数量变化时保留全部DOM入口，并用文字导航降级，避免只画六个岛却隐藏其他真实单元。
