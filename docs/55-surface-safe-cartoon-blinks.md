# v0.34 贴面闭眼与安全眨眼

## 本阶段解决的问题

v0.33已避免伸展时压扁眼睛，但旧学习场景的闲置眨眼仍缩放整组眼珠。贴合曲面的网格缩小后，部分表面会陷进脸部，出现裁切和不连贯的眼部形状。本阶段在两位伙伴、实际GLB与程序加载备用模型中统一替换这条路径：睁眼网格保持原尺寸，闭眼时隐藏睁眼组，显示独立、贴合脸面的闭眼弧线。

`closedEyes.ts`按实际承载曲面逐顶点投射：狐狸对应两块浅色面部，皮卡丘对应头部。每位伙伴两条有封口的细管，每条272三角面、155个顶点，共310次构建期表面探测。全部顶点与承载面间距在约0.0005–0.0125模型单位内，曲线随同一头部层级转动，不靠缩放眼珠伪造闭合。首轮拓扑测试发现端盖朝向与侧面不一致，已修正；封闭、正体积和一致绕序均继续严格检查。

实渲还发现原眼珠已参与顶点AO烘焙。只隐藏眼珠会留下眼窝阴影，因此为每个实例复制受影响的面部几何与颜色缓冲，闭眼时在正面眼部局部渐变清除旧遮蔽，睁眼精确恢复原颜色。背面颜色、位置、法线和缓存原模保持不变。自动与手动表情统一决定一次睁闭状态，只有状态变化才复制颜色并标记上传，连续闭眼不逐帧重传。销毁时释放自己拥有的面部和弧线资源，不释放其他场景的借用几何。

## 动作与界面

伙伴试选舞台新增原生“眨眨眼”按钮，保留挥手、转身、点头、伸展与摇尾。按钮沿用52px高度、12px间隔和中文文字，仍只位于展开的伙伴选择区。一次动作0.65秒，在0.12–0.34秒显示闭眼；结束恢复睁眼。其他场景的闲置眨眼沿用约4.6秒间隔、约0.13秒闭合窗口，改为同一套安全网格切换。

普通安静/后台/离屏/朗读暂停不会自动眨眼；主动选择“眨眨眼”时，安静模式展示固定闭眼造型，2D/SVG也有对应弧线。恢复、改做其他动作或回到普通反馈时恢复正确可见性和颜色，不重新播放已结束动作。所有表情仅为装饰，不调用学习API，不判题、不增加星星或进度，不更改已保存的伙伴。
