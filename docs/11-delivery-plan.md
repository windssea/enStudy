# 完整首发实施计划与成本评估

## 团队与时间假设

估算前提：3 名全职开发，1 名设计师（前半程较密集），2 名英语教研/编辑，QA 从中期投入；一名儿童使用体验负责人可由产品/设计兼任。完整首发覆盖 P1–P6及8类60专题，含12主题72条固定句式，预计 30–40 周。估算含整合与修订余量，不构成固定工期报价；本版替代v0.2的28–38周估算。

| 阶段 | 参考周次 | 软件交付 | 内容并行任务与出口 |
| --- | --- | --- | --- |
| S0 验证 | 1–2 | Pages/D1/认证、原子并发、R3F 平板、音频兼容样片 | 确定课程范围、词汇分级、教材识别；验证可行再锁依赖 |
| S1 基础 | 3–6 | 家庭、档案、授权、内容发布、学习播放器 | 六年级各一节代表课，用于检验不同年龄交互 |
| S2 闭环与特训 | 7–14 | 六类题型、复习、幂等同步、报告、专题诊断、句式馆与分层 | 72单元与60专题细纲、72句式槽位和变体、分批审核 |
| S3 AI 与语音 | 15–18 | BYOK、预算、解释、轮流语音、可用性降级 | 词汇与拼读音频、听说读写材料和专题新增题生产 |
| S4 全覆盖集成 | 19–24 | 所有年级和专题导入、教材映射、性能和安全修订 | 全学段与特训审核、迁移与复测题家族检查 |
| S5 试用与发布 | 25–30 | 真实设备、恢复/删除演练、部署与运营手册 | 每年级观察试用、专题补弱与句式迁移、内容覆盖验收 |
| 余量 | 31–40 | 供应商兼容、问题修复、审计与发布缓冲 | 教学与媒体返工，缺口补齐 |

内部先实现一课用于验证，不向外标称完整首发。公开发布门槛是完整覆盖与验收，不因工程样片可运行就提前宣称“全小学内容已完成”。实时 WebRTC 语音与开放任意域名出站列 R2，首发按受支持供应商与轮流语音提供。

## 工作量

| 工作项 | 估算 |
| --- | ---: |
| 产品架构与技术验证 | 6 人周 |
| 身份、家庭、存储、权限 | 12–15 人周 |
| 学习引擎、题型和 3D | 18–22 人周 |
| 复习、报告、多设备 | 12–16 人周 |
| AI/语音与预算 | 10–13 人周 |
| 部署、安全、性能、QA 修复 | 12–18 人周 |
| 专题中心、错因推荐、时间线/词形交互与复测 | 新增8–12 人周 |
| 固定句式库、槽位约束、变体与练习适配 | 新增2–4 人周 |
| 工程合计 | 80–106 人周 |
| 设计与研究 | 15–22 人周 |
| 内容教学、音频校对与审核 | 约 2,600 人时 |

内容估算模型：288 课×3 小时 =864；2,832 题×0.1 小时复核≈283；1,440 词条×0.12 小时≈173；媒体校对约180；图谱与教材映射约120；上述 1,620 加30%返工≈2,106 小时。每课3小时含题目起草，逐题时间仅为复核，避免重复计算。正式授权、专业配音采购和大规模教材变更不包含其中。

专题增量估算：48×2.5小时策略与示范=120；384新增题×0.25小时编写及审核=96；1,152条映射×0.05小时复核≈58；加30%返工≈356小时。总内容约2,462小时，排期预留约2,500小时。专题复用既有题不重复算成新增独立题。

固定句式增量：72条×0.3小时=约22；12主题×2.5小时=30；96新增题×0.25小时=24；288条映射×0.05小时≈14；加30%返工≈117小时。总内容约2,579小时，预留约2,600小时。句式条目、练习数量和复用引用分开计数。

按两名教研每周各35有效小时，内容约37周；因此内容可能是关键路径。单人开发若每周35小时且承担大量内容工作，总工作量估计约18–27个月，仍需第二人进行教学复核。若实际投入仅晚间兼职，按可用有效工时同比拉长。

## 基础设施费用

实施起步按 [免费部署手册](20-cloudflare-free-deployment.md) 执行，当前不选择付费套餐，也不启用R2等附加服务。以下付费金额是后续超额/扩容的参考预算，不是当前必须支出。

核验日期 2026-10-17。Cloudflare Workers 付费标准方案以每月最低 5 美元为基础，实际随请求与 CPU 用量变化。[Workers 价格](https://developers.cloudflare.com/workers/platform/pricing/)

D1 免费额度当前为每天 500 万行读、10 万行写、账户总存储 5 GB；但单个免费数据库最大为500 MB，不能把账户额度当成单库容量。付费单库上限10 GB。费用根据扫描/写入行数而不是 SQL 请求数计算。[D1 价格](https://developers.cloudflare.com/d1/platform/pricing/)、[D1 限制](https://developers.cloudflare.com/d1/platform/limits/)

| 场景假设 | 活动量 | 风险与预算方向 |
| --- | --- | --- |
| 100 名每日活跃孩子 | 每人10题、20 API 请求；约6万 API/月 | 约1,000答题/日，若含索引每答8–14写，则8千–1.4万写/日；小规模可能在免费额度内 |
| 1,000 名每日活跃孩子 | 每人10题、20 API 请求；约60万 API/月 | 同假设8万–14万写/日，可能超过免费D1写额；应使用付费并监测 |

8–14行写是估计，需要按最终 schema 和 D1 返回 meta 实测；内容导入、日志、预算与索引额外计入。基础云服务预留每月约5–30美元用于早期付费部署是规划额度，不是厂商报价；媒体、认证邮件、域名、监控、可选出站代理、AI 另计。未承诺永久免费。

## AI 费用模型

`文本费用 = 输入token/1M×输入单价 + 输出token/1M×输出单价`；语音按实际供应商的音频秒、字符或 token 计价，不把不同供应商的单位直接相加。

例如100名日活孩子、每人每天2次文本解释、30天，共6,000次；假设每次输入800 token、输出200，则月输入约480万、输出约120万。费用为 `4.8×输入每百万价格 + 1.2×输出每百万价格`。单价未知则只报告用量。每日人均2分钟语音对应约6,000分钟/月，需要额外 ASR/TTS 或实时音频费用。

BYOK 的供应商账单由家长账户承担，但平台仍支付代理请求与存储费用；本产品预算估计不能替代供应商账单。客户端断连也可能已经产生收费。

## 风险评估

| 风险 | 概率/影响 | 控制与触发条件 |
| --- | --- | --- |
| 全学段内容不齐 | 高/高 | 建立逐课状态，任何年级缺关键能力则不通过完整发布门槛 |
| 教材版次未知 | 高/中 | 自主课程可继续；准确教材同步需版次和审核，不能虚构 |
| AI 错误讲解/答案 | 中/高 | 审核题库兜底，确定性校验，撤回可重算 |
| 跨家庭泄露 | 中/极高 | 复合范围与对抗测试，任一高危缺陷阻断发布 |
| 平板发热卡顿 | 中/高 | 3D 独立加载，30fps门槛，2D可用，实机测 |
| 语音协议分裂 | 高/中 | 分能力 adapter 和格式矩阵，轮流语音先行 |
| 任意 endpoint 代理风险 | 中/高 | 首发审查主机名单；开放域名须受控出站验证 |
| 地区可达性 | 中/高 | 目标网络真实测量，AI不同供应商独立熔断 |
| 单库增长 | 中/中 | 索引、事件归档、容量预警；后续按家庭分片或迁移 |

## 发布决策

先投入 S0 与代表课，不购买未经验证的大量资产或一次性生成全题库。S0 通过后按完整范围执行；若资源预算不足，应延长交付时间或增加内容团队，不能默认删去 P1/P2/P5/P6。对首发教材精确同步的额外要求，以版次确定后的差异评估进入排期。
