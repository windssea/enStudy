# v0.24 第五单元情景课与课内规律演示

本阶段在已有96节课上追加24节原创课，当前开放120/288节、30/72单元。各年级第五单元4课，课程顺序17–20；仍有168课以及完整媒体、自然拼读、开放表达和教研审核待完成。具体香港朗文书名、版次及页码未确定，教材映射保持`not_bound`，不宣称教材认证或全学段已经完成。

## 学什么、怎么练

| 年级 | 第五单元 | 情景与重点 |
| --- | --- | --- |
| P1 | 开心的一天 | 心情、操场休息、午餐、睡前状态；按人物搭配am/is/are |
| P2 | 去动物园 | 象鼻、鸟翼、花纹与观察本；动物单复数和has/have |
| P3 | 寻找朋友 | 操场、图书馆、公园、礼堂；现在进行时一般疑问、What/Where/Who及短答 |
| P4 | 更高更快更好 | 身高、速度、尺寸与装备；-er、以e结尾、双写、y变i及better/worse |
| P5 | 城市与乡村 | 虚构社区、三个公园、居住环境与路线建议；比较级最高级、more/most及资料依据 |
| P6 | 如果我们一起行动 | 雨天预案、节水、安全出行、回收行动；真实if条件、一般现在时与will＋原形 |

24课各有3句示范和4个词条，72句示范各不相同。每课9任务：听句、阅读依据、选择、听句、阅读依据、修正、分类、填写、组句。新增48个听句任务、48个阅读依据任务及其余五种各24项，共216个不同任务家族；与前四单元的课程家族也无重复。这不代表216个全新知识点，分类卡片、词形与能力标签会复用。

低年级使用中文问题与短情景；高年级提供身高、长度、面积、价格及行动方案等资料。两处城镇和价格资料为课堂虚构内容，不代表真实地区或费用。比较题需要依据同一种指标，阅读题同时选择支持答案的原句和答案。听句需主动播放并确认，听不到可选择文字辅助，设备朗读不做口语评分。

拼句使用最多16个词块，按题目明确的顺序组织。条件句任务明确要求条件在前或在后，避免将开放语序当成自由写作评分；带now的任务接受已列出的多种正常位置。修正任务接受quiet的`quieter`及`more quiet`两种比较形式。比较词形放在forms类别，真实条件句放在grammar类别，不按年级机械归入时态。

## 课内3D与示范证据

P3–P5共12节课增加可选的“想看规律动起来？”入口，分别连接既有现在进行时时间线和比较词形实验台。默认折叠，展开后才加载实验组件；选择具体案例时，登录儿童必须先成功保存示范记录再显示案例。切换课程或儿童档案会重建该入口，关闭时中止尚未完成的示范请求。

沿用真实Three.js场景、SVG/2D替代、错误边界、安静/减少动效、离屏/隐藏/朗读暂停。这里复用了现有16个实验台中的两个，没有新增实验台数量，也不通过观看或点按虚增进度。

私有曝光映射加入新课程：wide/wider及thin/thinner的示范能覆盖新增选择、修正与分类任务中的相同目标。看过示范或前题已经揭示答案的目标另记为辅助完成；其他未披露目标继续按实际证据判定。课程、专题和复习共用能力标签，不要求复习只抽到第五单元题目。
