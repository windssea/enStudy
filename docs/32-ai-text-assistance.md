# v0.13 家长自带AI与题后辅助解释

2026-10-17。本阶段仅本地开发与验证，云端仍为v0.8。今天不重试Cloudflare，不开通付费服务；既有跟进安排在北京时间10月18日08:05对最新main尝试发布。

## 已实现的流程

家长在“家长空间 → 家长设置 · AI辅助解释”填写连接昵称、API根地址、准确模型ID、API Key和供应商数据政策链接。敏感操作重新验证当前家长密码；最多保存5个连接。Key默认隐藏，保存后只返回末四位，不能读取明文。成人首次临时密码未更改、儿童授权、guardian或其他家庭都不能管理连接。

先保存，再手动发送一次最小文本协议测试，最后勾选第三方处理说明并为本家庭开启。修改模型、地址、参数或Key后测试失效，孩子开关自动关闭，需要重新测试、开启。仅兼容非流式Chat Completions文本；家长可按服务商文档选择system/developer角色和max_completion_tokens/max_tokens，不自动变换协议重发。测试通过只代表最小文本协议可用，不代表教学质量或语音能力通过。

孩子先独立尝试并保存答案，再点击“请AI换个说法”。上方标准讲解一直可读。AI只解释给定知识点并给一个英文例句及中文意思，不参与判题、奖励、复习调度或掌握判定，不推断未提供的具体错因。例句的“听例句”仍是设备朗读。

换题、失去设备所有权或离开页面时忽略旧响应，可主动停止等待。停止等待不代表供应商没有收到请求或不计费。一次题目/连接版本对应同一个解释请求，超时后保留请求编号，重新读取不会自动创建第二次付费调用。结果可读取期为10分钟，过期或失败后继续使用标准讲解，不自动重发。

## 数据与防护

- 迁移0012已本地应用，新增设置、按北京时间统计的家庭/儿童日预算、请求幂等及原子预留检查。历史迁移不修改。
- API Key使用AES-256-GCM、随机96位IV与家庭/连接/密钥版本作为附加认证数据。主密钥只在服务端Secret/本机忽略文件；不同家庭、连接或篡改密文无法解密。多版本keyring可保留旧密钥，编辑连接时使用当前版本重新加密。主密钥丢失后无法恢复已有Key。
- 默认仅api.openai.com为已允许主机。其他公共HTTPS地址可以保存待验证；部署者审查后才加入精确AI_HOST_ALLOWLIST。禁止IP、本机/内网域名、非443端口、凭据、查询/片段/编码和完整对话端点，固定追加/chat/completions，不接受自定义header，不跟随重定向。
- localhost例外仅供隔离测试：必须同时为local阶段、开发身份开启、精确AI_LOCAL_TEST_ORIGIN匹配。生产阶段不能开启此例外；正常本机页面也不设置该变量。
- 白名单并非完整DNS重绑定防线。部署者应只允许自己确认的可信公共服务；开放任意自定义域名、第三方域名持续审核与受控出站网关仍待实现。
- 出站仅包含年级、题目/情境/标准讲解、规范答案和已保存结果类型；不发送昵称、账号、孩子原始输入或完整历史，不提供工具调用。错误日志只含分类，不输出上游错误正文、密文、Key或提示词。
- 响应限制20秒、32KiB，解释只接受三个有长度限制的纯文本字段，拦截HTML/链接及部分不适合儿童的文字，拒绝供应商回显完整Key。React以文本渲染；过滤不能证明事实正确或全面安全，真实服务与教学内容仍需验证。
- 家庭次数和用量、儿童次数通过D1 batch条件更新及CHECK门闩原子预留；两个孩子争最后一次只能一个调用。测试也计家庭用量，失败次数不退回。删除连接保留当日账本，不能通过删建绕过额度。
- 用量单位是产品的保守预留，不是精确费用或价格承诺。有效usage.total_tokens用于结算；缺少用量、网络未知、取消或上游错误时保留预留。实际用量可能超过预留，后续调用仍受累计额度约束；供应商自身限额应另行设置。已知未出站的本地解密/域名检查失败只保留次数、结算0单位。
- 服务端返回结果前重新检查当前儿童授权、父会话、设备所有权、题目位置、开关及连接版本。家长关闭或任务变化时停止呈现，已出站调用仍可能产生用量。
- 只缓存通过检查的短解释，不保存完整对话或上游原始正文。过期后不再返回，访问家长设置时分批清除过期response_json；当前不是物理10分钟删除保证。请求审计与预算留存、自动清理和家庭删除/导出仍待补齐。

## 本地与后续云端配置

`npm run setup:local`会一次性为忽略的.dev.vars创建AI_KEYRING和AI_ACTIVE_KEY_ID。已有成对配置会保留；缺一项时停止，不悄悄覆盖。单独准备可执行`npm run setup:ai:local`；已运行的Wrangler需要重启才能加载新环境变量。本次已重启本任务本地服务，并通过真实家长接口确认encryptionReady=true，未添加真实供应商Key。

在本机页面的家长设置中输入供应商Key，不放入VITE变量、Git、聊天或命令行参数。默认连接根地址例为https://api.openai.com/v1，模型ID按自己服务商文档填写；没有选择或验证任何真实模型。

Cloudflare尚未配置主密钥，本次没有修改远端Secret。发布后AI默认关闭，其他课程照常运行；缺少主密钥时保存Key和调用均关闭。部署者需在Pages项目Settings → Variables and Secrets分别为Preview、Production设置独立的AI_KEYRING（JSON对象：版本ID映射到32字节随机密钥的Base64）和AI_ACTIVE_KEY_ID（对应版本ID），两项都设为Secret。不要复用本机主密钥，不要删除已有版本；先私下备份，再配置并重新部署让绑定生效。AI_HOST_ALLOWLIST是精确域名逗号列表，可用普通服务端环境变量配置。后续家长在各环境分别保存连接、测试并同意开启；发布不会自动替家长同意或调用付费供应商。

轮换时先保留旧项、增加新项并切换active ID；确认连接逐条重新加密后才能考虑撤去旧项。当前已验证算法兼容旧密文，但尚未提供批量轮换、备份恢复或生产操作演练，不能直接删除旧主密钥。

Cloudflare说明Secret可从Functions的context.env读取，且本地.dev.vars不应提交；Secret需要在部署前配置。[官方绑定文档](https://developers.cloudflare.com/pages/functions/bindings/)。适配器使用的Chat Completions字段与输出限制依据[官方API参考](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)；供应商自己的兼容实现需分别验证。
