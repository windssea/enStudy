# v0.7 专题题库与随机抽取

2026-10-17，落实“每个专题有大量题目随机抽取”。本阶段为全部60个专题各提供60组不同文字题干，每组选择/填写两种变体，共7200个练习变体。题干由受约束句框、真实词形表和情景资料组合生成；同一题的两种形式共享family，不能视为两道独立迁移测验。题量不表示完整教学审核、口语评测、全题型或诊断体系已完成。

## 用户可见行为

- 专题卡片显示实际题量120、题干60组；每轮可选5题、10题或20题，默认10题。
- 服务端随机选题、随机选择变体、随机打乱选择项。多句框专题在一轮中分散使用不同句框，避免连续同型填空。
- 同轮每个family最多出现一次。优先选择当前孩子最近400个已分配题目中未出现的family；分配后未答也计入近期曝光，不依赖完成才避重。
- 未曝光题组不足时，先选更早分配的family，再考虑最近的题组。题库有限，不承诺永久不重复；随机出题也不等同于独立诊断。
- 题目、顺序和选项展示写入D1。刷新、重试和并发创建不重新随机；请求编号不能改变专题或题量。原有提示、幂等、授权及家庭隔离继续适用。
- 阅读题展示完整资料后作答；音形与口语专题明确标为文字准备，当前不评分听音、录音、自由口语或自由写作。

随机源为服务端Web Crypto；使用Fisher–Yates打乱，不用客户端提交的答案、分数或题号决定分配。填写任务按题干规定的词或句框评分，合法地区拼写在相应题目接受。

## 数据与构建

`content/topics-v1.mjs`为源；`scripts/build-topics.mjs`验证所有专题数量、题干与阅读材料组合唯一、正确选项唯一，生成私有`content/topic-release.v1.json`与不可变`0007_topic_bank_v1.sql`。已应用迁移禁止覆写，修订需新release/迁移。`0006_random_topic_assignments.sql`保存分配的展示顺序，旧会话没有展示快照时保留原先顺序。

新release包含7200个新变体，并以成员关系引用原224道课内/启航题，支持复习混合选题。开课必须检查发布状态及release成员。内部60个题库容器满足已有外键，不将专题完成当作课程完成。

题库只进入服务端，未写入public或浏览器JS。Vite阻断题库源和私有JSON；公开API只返回题量及当前分配题目。前端主JS仍约263kB（gzip约83kB），没有把4.18MB私有JSON下载到孩子浏览器。Functions本机编译体约5.79MB，gzip约277kB；线上发布及请求仍须实际核验。

迁移SQL按UTF-8字节分批，每条约70kB以内，低于[D1的100kB语句上限](https://developers.cloudflare.com/d1/platform/limits/)。0007在本机执行76条语句，不引入付费资源。
