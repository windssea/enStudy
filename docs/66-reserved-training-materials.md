# v0.44 专用专题材料与五维小尝试

分步专题不再只能借用普通随机题库。首批18个语法、时态专题各新增60道专用受控文字任务，共1080道；原有60专题、7200变体保留。新增任务不进入普通随机、普通复习或任意单题入口，避免孩子先巩固较多普通题后，计划没有新材料可用。其余42专题继续原分配机制，尚未补齐专用内容，不能把首批覆盖写成全部专题完成。

## 学习内容与证据

每个专题明确五个可观察维度，例如be动词分为单数、复数、I与am、否定和问句。每维12个不同文字情景，按不可变槽位分为小尝试2、巩固4、应用2、回访4。小尝试、应用和每次回访各随机取每维1题；巩固10题优先照顾本次需要提示或答错的维度，补入其他未分配材料。一轮完整计划仍为5+10+5+三次5题，共35组不同材料；不能把排列组合数算成题目数。

材料包含选择与填写，否定形式接受列明的合法缩写。不规则过去式、过去分词使用多个真实词项，避免一个已看过的词形示范耗尽整个维度。五个维度与60个情景是本版本的采样范围，不构成整个专题的完整诊断，也不从一次错答推断唯一原因。

不同阶段保留专用情景，但仍复用受控任务框架，scope明确为controlled-context；不宣称已验证开放情景迁移、自由表达、口语或听辨。五题小尝试没有能力排名或掌握百分比。未见过的某个维度不足时整体停止该次评估，不用其他维度补齐，不把旧题当新题。

避重同时核对题目家族、题干/阅读材料和规范化完整答案句，防止同句换来源或换框架重新当作新材料。示范资格与作答资格使用相同的disclosureCheckKeys；旧版只保存实验台标准句的记录，也会经历史别名匹配到后来新增的词项目标。示范后答对依旧另记，独立成功与当天跨入口晋级规则不变。

## 旧计划与界面

workflow的plan_version仍为1，原有日期、逾期合并、接续和事务规则不改。迁移0042仅给training_cycles追加可空material_release_id与material_adopted_at；已有计划保持NULL，原阶段分配不变。迁移0043追加不可变reserved-training-v1内容。这里的材料版本独立于流程版本。

浏览器抽查发现一处否定题的中文地点与英文书店不符，内容复核还发现频率词句序任务缺少公开选项、部分可接受表达未列全。0043已在本地应用，因此保留原SQL、题目版本和家族，新增0044、reserved-training-v2及373个修订版本。修订仍是原来的1080个家族，不把改措辞算作新题。当前目录合并原版和修订版，计划绑定原始editionId，单次任务保存实际来源与版本；任一所需发布版本撤下时停止新分配，不退回已修订的旧题。

修订明确当前时态与题目指定的词集，选择句序题提供三个公开选项；否定中文地点与英文逐项对应。指定能力表达接受can/is able to，建议接受should/ought to，外部要求接受must/has to/has got to；禁止仍不接受does not have to。结尾为s的人名接受两种列明的所有格风格。依据为[Cambridge能力表达](https://dictionary.cambridge.org/grammar/british-grammar/be-expressions-be-able-to-be-due-to)、[建议表达](https://dictionary.cambridge.org/grammar/british-grammar/ought-to)、[must与义务/禁止区别](https://dictionary.cambridge.org/grammar/british-grammar/must)及[EF所有格说明](https://www.ef.com/wwen/english-resources/english-grammar/forming-possessive/)。这些是限定情景中的等效答案，不把所有语境下的表达视作完全相同；完整教研仍待开展。

新建且受首批覆盖的计划自动绑定专用版本；已存在计划不静默切换。没有未完成阶段时，孩子可明确选择“接下来使用专用材料”。服务端按当前版本CAS更新材料来源与版本号，已完成阶段、会话、题目、回执和日期保持原样。切换与开始阶段竞争时仅一个版本可以成功；重复切换不重复增加版本。已经开始的阶段须先继续完成。

专题页将五点范围放在可展开说明中，不预先展示题目或答案。旧计划的切换说明使用暖黄卡片，常规开始按钮仍是主要操作。沿用现有工作坊粘土伙伴，不额外增加Canvas。完整计划、某维材料耗尽与最终教学审核仍按实际状态说明。

已完成的阶段按实际会话来源标记“原题库材料”或“专用材料”，不将旧结果重新解释成新范围的成绩。旧版题框与新版维度没有可靠对应时，巩固从新材料均衡选取，不自动推断新的维度错因。

原来的辅导GET改为只返回作答事件、维度标题与提示标记。主动展开某条规律时，复用错题小本的POST披露流程，先记录当天示范再显示讲解；历史题修订时明确显示新版讲解。关闭、切档案、卸载会取消等待，延迟结果须符合当前儿童和事件。

## 播放器重载修复

浏览器验收发现旧播放器只恢复回执，没有恢复孩子已选的答案。快照现在追加submittedAnswer，取自当前儿童、家庭和任务的已保存canonical作答；未作答时为NULL。按原来的公开选项恢复大小写、词块、分类、改句和阅读依据，不读取正确答案来替换孩子的原答，不重新评分或修改回执。拼读与标点组句可以从已保存文本恢复公开词块，恢复搜索有上限，不能匹配时不猜测选择。

刷新、显式接续和跨设备快照使用同一恢复路径。有冲突的未提交本地草稿继续提供可读备份；切儿童时不带入前一个儿童的草稿。此处恢复的是服务端规范化后的作答，不声称保留原始大小写、空格与按键过程。新增私有题库JSON、源文件和迁移路径纳入Vite保护，实测均为403。

## 接口、存储与兼容

| 接口 | 行为 |
| --- | --- |
| GET /training/materials/:topicId | 当前儿童可见的发布范围与五维摘要，不包含题目与答案 |
| POST /training/cycles | 继续幂等创建；首批新计划绑定专用材料，旧计划不改 |
| POST /training/cycles/:id/materials | expectedVersion保护的显式材料采用；拒绝未完成阶段、外档案和过期版本 |
| GET /training/cycles及详情 | 保留原进度，新增材料摘要；辅导仅返回记录元数据 |
| POST /sessions | 沿用统一分配；事务复验材料发布、已分配题和示范证据 |

材料切换沿用当前儿童、家庭、grant、成人上下文、密码状态及撤销检查。阶段创建在事务内再次复验所选题目与来源发布状态；撤题与竞争失败回滚旧任务暂停和新任务声明。家庭资料导出仍为25类，training_cycles资料补充两个材料字段；没有另建成绩、复习或奖励账本。

本阶段没有改变任何已应用的0001–0041迁移、管理员凭据或注册策略，没有新增云资源、账户、供应商或自动化。新增迁移只在本地应用，Cloudflare继续免费；以[skip ci]同步GitHub，不将代码提交当成发布。
