# v0.37 写作小工坊与私有草稿

## 实现范围

此前课程中的写作多为受控编辑和纸上活动。本阶段新增独立的真实文本编辑器，孩子可以填写并保存标题、中文提纲和三段文字，在另一台授权设备读取、比较版本并继续。P1可每格一个词或一句配文；P4–P6可完成三段短信、观点或项目短文。不是把纸上作业标成已交付，也不是把内容自动判成正确。

| 年级 | 主题 | 引导结构 |
| --- | --- | --- |
| P1 | 我的图画小册 | 是什么、一个特点、再介绍一点；图画仍可在纸上制作，本页保存文字 |
| P2 | 我的周末图鉴 | 平时日常、角色能力、此刻动作 |
| P3 | 一张纸上邀请卡 | 礼貌邀请、虚构活动时间地点、回复说明；不会实际发送 |
| P4 | 有过去和计划的故事短信 | 过去经历、现在情况、未来计划 |
| P5 | 我的观点小报 | 主题句、理由和有限依据、适度结尾 |
| P6 | 我的英语主题项目 | 主题介绍、两条清楚细节、总结和后续 |

地图右栏和25节相关课程连接写作入口，支持`#writing`及主题深链接，如`#writing=writing.p6.project`。不增加平板同级导航；相关课程的九题仍独立完成。主题句框默认收起，不预填孩子的正文。自查仅记录本人勾选，修改文字后重置，不增加星星、答题、复习或独立证据，不代表语法评分。没有公开发布、真实AI发送或上传图像。

## 保存与冲突

编辑器停止输入约2.5秒后尝试保存，另有明确保存按钮。响应前不宣称同步成功，失败后停止自动重试并保留当前内存文字。重试同一请求使用相同请求ID与内容；回执返回后，期间输入或撤回的文字保留，再保存下一版，不用旧回执替换新输入。

每份草稿有递增版本。两台设备从同一版本保存时，仅一台成功；另一台得到冲突，当前输入保留，可以查看保存版本、明确载入、另存一份或下载文本。比较窗口明确是读取时的版本，不自动覆盖编辑区。失去草稿或授权时也不把失败显示成已保存。

浏览器关闭提醒与应用内路由离开确认用于减少误丢。当前没有自动离线队列或私有本机持久副本；关闭、强制终止、换档案等情况下，未确认文字仍可能丢失。文本下载作为用户主动保留方式，实际浏览器行为待真机验收。

标题80、中文提纲800、每段1200个字符，每个儿童最多32份草稿。仅字符数量限制，不把字数当成绩。字段通过绑定参数保存，前端以普通文字渲染，不解释孩子填写的HTML。空正文不能记自查；改文案后客户端清空旧勾选，服务端即使收到旧勾选也会清空。

## 数据和权限

新增不可变本地迁移0038，`writing_drafts`存当前保存版本与创建时的主题快照；`writing_commands`存小型请求回执而不保留旧正文历史。主题version 1有摘要快照保护，旧作品不因将来主题更新被改写结构。更新和删除必须匹配版本；新建和保存的内容及回执在D1原子batch完成，并再次检查儿童grant、家长会话、成员资格与当前家庭，防止授权检查后切换或撤销的竞态。正文修改和自查保存都属于作品版本，不接入答题lease或记忆调度。

所有接口在`/learning/writing`下，复用儿童授权中间件。每次请求均以当前家庭和儿童限制查询，提交包含明确childId；另一家庭、兄弟姐妹、切档后的排队请求和撤销的家长会话不能访问。删除指定草稿时清理其回执，管理家长删除儿童时由外键级联清理两表。此处不承诺Cloudflare备份中的物理清除或完整成人保留期管理，那仍属后续运营工作。

接口：读取主题、列表、单份草稿；新建；按版本保存；按版本移除。health新增writingProtocol 1。公开注册、指定admin凭据、两套独立D1和免费方案保持不变，本地密钥文件未改动或提交。
