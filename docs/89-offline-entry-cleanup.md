# v0.62.1 撤下儿童离线练习入口

状态：已同步发布Preview、Production和正式域名，完整检查及线上儿童入口验收通过。

“离线练习”原本用于联网预先准备一轮题目，在本机答题后逐题联网确认。这个流程包含额外准备、有效期、设备授权和独立证据边界，不适合作为当前儿童学习的核心入口。根据用户反馈，首页更多练习、复习页和普通答题页不再推广这一功能。

首页更多练习保留写作、对话和互动练习，并调整为三列；复习页保留主任务与错题次操作；普通答题页仅在当前任务确实已有offlinePrepared标记时显示“查看待同步记录”。不增加新说明卡、中文提示音或替代宣传入口。

已有本机题包、加密答案和服务端记录不删除；旧的#offline直接地址、授权和同步校验保留，当前已准备任务仍可访问同步入口。不注销Service Worker、不清理缓存或存储、不更改离线证据和奖励规则。本阶段不等于删除所有离线代码，也不将未核对答案计为已保存的云端成绩。

仍用现有免费资源，注册关闭、默认账号及独立D1配置不变，无新增迁移。本阶段实际验证与发布结果如下。

本地浏览器只读查看原有档案：复习页显示已有5项到期知识，保留开始复习与错题入口，没有离线链接；首页展开更多练习后仅有写作、对话和互动三个入口。没有新增作答、推进日期或修改既有数据。证据在忽略目录artifacts/v0621-local-browser.json。普通答题页的旧题包入口采用既有session.offlinePrepared标记，不新增存储探测或题包准备请求。
