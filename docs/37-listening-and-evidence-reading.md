## 孩子的操作

听音题先隐藏英文题面，由孩子点击播放本机英语合成声音。设备报告结束后，孩子再点击“听到了，可以作答”；结束、停止和超时本身都不会提交答案或发奖励。没听清可重播，设备无合适声音时可点击文字辅助；保存辅助状态后才显示英文并开启答题。

听音组件只选择浏览器标记为localService的英语声音，优先en-GB，再用其他本机英语声。声音尚未准备好时不自动播放，可稍后重试或看文字。该实现没有调用网站的AI、ASR或TTS适配器，也不申请麦克风；它与家长配置的AI语音对话是不同能力。

依据：[MDN localService属性](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesisVoice/localService)描述语音源的本地标记，[MDN end事件](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesisUtterance/end_event)描述话语播放结束。工程上据此选择本机声音并开启确认按钮；这不构成对浏览器网络行为、扬声器音量或孩子实际听觉感知的独立核验。听音状态是设备事件加学习者自我确认，不能宣称为客观听力认证。

播放互斥、离页/后台停止、卸载取消、45秒超时、过期回调与旧声音的所有权保护均已实现；设备报错不算完成。播放时沿用全局语音活动状态暂停3D；扬声器状态有轻量CSS动效，安静模式和系统减少动效关闭动画。新增界面沿用ui-ux-pro-max的主动播放、停止与文字替代原则。

阅读题展示一个有3句原文的小故事，要求先点选支持答案的一句，再选答案，两项一起提交。仅猜对答案但选错依据不计正确；反馈分别说明原文线索与问题答案。以明确文本信息为主，部分高年级因果问题使用原文明示的理由，不把这组短文等同完整阅读能力或自由写作。

新拼句将标点单独成块并显示合并预览，接受已声明的时间短语句首/句尾以及相应逗号变体。只对新标记的题目使用此规范化，旧版本题目及其回执保持原样。

## API、状态与证据

公开Exercise新增listen、evidence类型，passage为带稳定ID的原文句子；listen沿用audioText作为设备合成脚本。设备必须收到脚本才能朗读，隐藏题面不是考试防作弊机制。公开字段不包含正确中文映射、正确依据ID或接受集合。

| 接口/字段 | 实际行为 |
| --- | --- |
| `POST /sessions` | 现有lessonId支持第三单元；wordMode新增listening；选择器仍互斥 |
| `POST /sessions/:id/listening` | 需要当前assignmentId、leaseId和mode=heard/text；仅当前拥有者可记录 |
| `LearningSession.listening` | heard与textSupport两项状态，可重载/跨设备接续 |
| listen作答 | 未记录听音确认或文字辅助时返回409，不能只在答案body中伪造状态 |
| evidence作答 | `[sentenceId, answer]`；缺项、未知句子或选项返回422，完整但不正确则保存incorrect |
| 播放器版本 | 新网页发送`X-EQ-Player-Version: 3`；v2仍可显示分类/修正，遇到listen/evidence明确提示刷新 |

新增迁移0020发布课程，0021创建听音输入状态，0022发布360道听词题。状态属于家庭/孩子/assignment，外键级联清理；不保存孩子录音或重复存储脚本文本。重复确认已保存的状态不增加写入或奖励。辅助状态对本题持久且不可撤回；后续再确认听到也不能洗成独立证据。已交卷后不能补写新的辅助状态。

记录文字辅助与写入教学暴露指纹位于同一D1 batch，并用当前设备、grant、cursor、lease和未交卷条件约束。判题继续使用CAS与暴露检查；若辅助揭示和交卷并发，不能同时留下“已看文字”和“独立成功”。旧设备、兄弟姐妹或其他家庭均不能修改本题状态。

文字辅助答对为hinted，support=transcript，independentEvidence=false；参与奖励不变，不作独立听辨晋级。听辨使用listening-choice，阅读找依据使用reading-evidence，与认词、拼写、语境和语法分别记录。到期卡片走同一复习与内容来源校验。新分配的复习有自己的输入状态，原题的辅助标记不会因刷新或换设备消失。
