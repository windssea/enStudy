# KET 词汇 · v0.58

本阶段增加独立 KET 词库，保留小学18主题、360词条、1620道原题和既有进度。当前为待发布记录，实际发布结果在验证后补记。

## 收录依据与数量

依据 [Cambridge 官方 A2 Key / A2 Key for Schools Vocabulary List](https://www.cambridgeenglish.org/Images/506886-a2-key-2020-vocabulary-list.pdf)，封面版本为 **August 2025**，实际PDF为32页。来源文件的SHA256、字母表实际页码和每行词头/词性保存在 `content/ket/source-2025.v1.json`；不把网址中的2020误当版本年份。

字母表第4–23页共1727行有效词条；coat重复一次，visit分名词、动词两行，按词头合并为1725项。保留design、follow、share、smart等显式分义词头，May/may、it/IT也保留不同ID；不把拼写相同直接当成同一词义。每个来源词头都有且只有一个本站词卡，并保留全部来源页码。

附录1的闭合词集也覆盖：基数1–1000、序数1–31、星期、月份、季节、七洲。one/first/second及星期、月份、季节已在字母表，不重复添加；新增999项基数、29项序数。另有31项国家、国籍、语言与洲名：包含官方列出的八对国家/国籍示例、常见英语国家和English。Australia同时覆盖洲与国家，未重复计数。共新增1059项附录词卡，总计 **2784张词卡**。数字展开是规则训练，不冒充新增999个日常名词。

国家、语言和国籍在官方附录中属于开放集合，不能宣称列尽所有国家。官方也明确说明此词表不穷尽试卷可能出现的全部词语。因此产品名称为“KET词汇 · 2025版”，其范围说明可展开核对，不使用“覆盖考试一切单词”的承诺。

中文释义和英文例句为本站编写；298项复用本站原有原创材料，1427项字母表内容为本阶段编写，数字与序数按规则构造，31项附录地理内容另行编写。没有复制官方例句或整份PDF。来源PDF保留的个别词性/排版问题不照搬教学：chips为炸薯条，不误配biscuit；unfortunately为副词，unhappy为形容词。扩展写法在 `variants.v1.json` 显式维护，包括grey/gray、jewellery/jewelry、英美度量拼写、驾驶执照和yoghurt/yogurt等。

## 学习流程

“单词”入口增加“小学主题 / KET词汇”两个明确选择。KET下有单词与词组、数字、序数、国家与洲四类；字母下拉筛选、跨组中英文搜索和分页避免一次铺满大词库。每页12组，每组29–40词；搜索每页24条，支持按变体找词和直接进入所属练习组。

71组提供认词义、拼写和混合随机练习，每轮5/10/20题，同一轮不重复词条，连续练习优先未抽过的词条。每词2道任务，共 **5568道**，全站词汇目录合计3144词条、7188道任务。原有听力、看图和语境题保留在小学主题；本阶段没有为新词虚构录音或图片，也不把英文例句机械挖空当作已完成的深层语境题库。词卡提供释义、原创例句、显式其他写法与按需英语朗读；不增加中文声音提示。

词卡披露沿用服务端先登记、再返回确认的流程，切换档案或卸载会中止请求。看过词卡后同日答对走辅助证据；只有实际提交作答才进入复习。KET沿用同一复习计划、会话恢复、错题与家庭隔离机制，不把浏览词库记成掌握或课程完成。相同旧词与KET词的示范别名仍通过词形/句子证据相互识别。

## 实现与版本

`scripts/build-ket-vocabulary.mjs`校验来源覆盖、生成紧凑词库、发布清单及追加迁移0050。`packages/domain/ketVocabulary.ts`由构建脚本与Worker共享，按紧凑词库产生题目，避免把重复的大题目JSON塞进Worker；干扰项按固定规则选择并排除同义释义/相同拼写，选项展示沿用服务端洗牌。分组只用于练习，不赋予KET虚构的小学年级。

旧 `vocabularyRelease` 导出保持原内容；实际API和示范记录使用合并目录。新词ID为ket.a/n/o/g系列，题目版本为1，复习技能位于lexeme.word.ket前缀。存储课程表的旧约束要求1–6年级，KET占位lesson存为1；公开词库元数据grade=0表示考试范围，不进入小学课程推荐或完成记录。已应用迁移不得修改，后续修订需新增版本和迁移。

公共搜索是只读、无个人资料的内存索引，查询最长80字符、每页24条，并校验偏移。浏览器只加载UI模块和当前组/搜索结果，不下载整份私有题库。新增任务复用既有题型和离线准备流程；未联网时不能宣称整套KET自动离线可用。
