# v0.39 家庭私有资料导出

在家长空间新增折叠的“家庭数据 · 导出学习资料”。管理家长核对当前家庭及所有儿童范围、重新验证自己的当前密码后，生成固定快照，并下载JSONL分卷。此功能补齐F08中的数据导出入口；它不等于完整账户生命周期、备份恢复或隐私运营验收已经完成。

## 范围和文件

包含25类已保存资料：家庭、家长与角色、儿童、伙伴选择、学习轮次、题目与展示版本、作答与回执、完成记录、复习卡、奖励、专题计划及步骤、示范与听音、写作作品、AI/语音设置、无密钥连接说明、用量与预算计数、早期专题、邀请及成员变更记录。邀请仅含状态等元数据，不含邀请码或其哈希。没有把资料条数当成答题数或掌握程度。

字段逐项列出，不使用SELECT *导出新列。题目使用已发布的公共内容与冻结展示，标准答案私有列不复制；已经给过本人的作答反馈保留。密码、密码哈希、密钥和加密密钥、登录/设备令牌、内部事务检查不进入文件；短期AI对话、转写与合成音频也不导出。写作标题、中文提纲、段落、自查及版本原样保存，JSON按数据处理，不作为HTML执行。

每份快照按25行保存片段，单片正文最多512KiB；客户端按约8MiB正文分卷，一次只准备一个分卷。每卷首行包含清单、范围、卷号与总卷数，后续每行包含一个片段及记录数组。清单计数、片段连续性、身份与行数核对失败时不生成文件。没有按固定总条数截断；如数据库限制或单片上限导致创建失败，事务回滚并明确未确认生成，不返回半份成功。

文件用于个人留存与后续整理，当前没有一键导入或灾难恢复能力。题库媒体仅保留公共引用，不重新打包所有公共GLB/WAV。下载得到浏览器Blob并交付保存，不代表已经验证磁盘文件；用户需要保管、核对和删除本机副本。

## 身份、快照与重试

`/family/exports/*`要求当前家庭owner、非临时密码的成人会话，儿童grant或站点管理员身份本身不能绕过家庭成员关系。生成使用现有密码复验和限流；整个复制事务再次检查会话、当前家庭和context版本、凭据版本及刚验证的密码哈希。每个包只属于创建它的当前登录会话；同一成人在另一设备需要重新验证并生成自己的包。包ID不是可公开分享的下载令牌。

新增0040的commands、exports、parts三表。命令号与本次build号约束创建，25类查询在同一个D1 batch事务中复制，再将包置为ready；一条复制失败会回滚整个事务。该事务特性依据[Cloudflare D1 batch文档](https://developers.cloudflare.com/d1/worker-api/d1-database/#batch)，本地另有故障注入验证。快照反映事务执行时的数据，此后的作答和正文修改不改变已生成内容。

每个当前登录/家庭最多一个包。相同请求号返回原快照，不重新复制、不延长有效期；两个同时创建只有一份结果，不同请求号竞争也不能重复占用。回执保留24小时，已移除的包在此保留期内不能靠重放旧请求复活。回执只有请求和作用域元数据，不保留作品正文。

默认10分钟后拒绝目录及片段读取。每次读取重新检查有效登录、owner角色、家庭上下文、凭据版本与期限；分卷全部取回后再做一次授权读取。生成或读取包不修改孩子的答案、奖励、复习或课程状态。

## 删除、失效与保留边界

删除儿童或写作作品、移除AI连接会使该家庭已有包全部失效并清理片段；移除家庭成员也清理该家庭旧包。退出/撤销登录或切换家庭会清理该登录的包，改密/停用会清理该成人的包，owner降级清理其包。删除快照本身不删除原学习记录。下载中删除儿童会让后续片段或最终授权失败，不把残缺内容交给浏览器。

到期判断不依赖清理成功。过期资料和24小时命令通过导出访问时的后台维护尽力清理；Pages入口已补充传递waitUntil和执行上下文。没有新增Cron、Queues、R2或收费服务，也没有承诺无访问时立即物理清理。免费写入额度不足时清理可能延后，但过期或无权限的数据仍不能通过这些接口读取。完整独立清理调度、备份保留、删除账本恢复与供应商数据生命周期仍属待完成的运营范围。

## 接口

| 方法与路径 | 用途 |
| --- | --- |
| GET `/family/exports/list` | 只列出本次登录可读取的包和期限 |
| POST `/family/exports/create` | 作用域确认、当前密码与请求号，原子生成或恢复同一结果 |
| GET `/family/exports/:id` | 私有清单及各类计数 |
| GET `/family/exports/:id/parts/:section/:part` | 授权读取固定片段 |
| POST `/family/exports/:id/remove` | 移除该登录的快照，保留原学习资料 |

所有响应沿用private, no-store；没有写入公共目录、可分享长链或浏览器持久缓存。health增加exportProtocol 1，家长组件按需加载。未来部署检查仅验证模块、匿名拒绝和已登录空列表，不自动生成真实家庭的资料副本。
