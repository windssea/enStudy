# 时态拖动小游戏

2026-10-23：在时态专题与课程规律实验的“同一个动作，时态怎么变？”入口加入“玩时态小游戏”。拖动吃苹果人物经过过去、现在、未来，实时更新动词、英文例句、翻译与含义；支持鼠标、触屏、方向键、Home/End和点击三个时间按钮。

默认展示进行视角，可切换一般、进行、完成、完成进行，共复用12条已有例句。现在固定为今天15:00，过去和将来分别是昨天、明天15:00。一般现在时表达习惯，将来明确为设想，完成与完成进行展示具体语境。人物姿势仅作时间标记；不将示意位置视为真实时长或已发生事实。探索三个时间只记录组件内状态，不加分或增加掌握证据。

有儿童档案时，打开前使用现有`/learning/tense-comparison/view`的`all`范围登记整组示范，成功才展示；之后的拖动不请求接口。登记失败、待定请求、旧档案响应均不会泄露示范。原对比表和12种表达总览保留，例句内容与comparisonVersion未变化。

两张素材由内置imagegen生成，PNG原件保存于`design-system/english-quest/art-source/`，WebP在`public/art/concepts/sports-v1/`，登记于`learning-art.v1.json`并进入现有离线壳。人物99596字节、1024×1536，alpha 0–254；时间轴50168字节、2106×162，alpha 0–255。时间轴仅裁去透明外边距，最终提示与裁切记录见[素材记录](../design-system/english-quest/ART_PROMPTS.md)。

浏览器使用独立验收页面和模拟示范接口，未访问真实儿童记录。42项检查覆盖12种动词、拖动中即时切换、触屏、键盘、减少动效、登记失败/等待/切档案竞态及重试；1280桌面、768×1024平板、1024×768横屏与375px窄屏无横向溢出，时间和视角按钮至少52px。证据保存在忽略目录`artifacts/tense-game/`。真实平板硬件与屏幕阅读器尚未实测。
