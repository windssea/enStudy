# 内容生产与朗文教材映射

课程质量决定产品能否长期使用。所有基础课程采用原创讲解、题目和合法媒体；AI 只辅助起草和变式，不自动发布整套六年级内容。

## 内容契约

每课包括 stable ID、版本、年级建议、先修、主要目标、已知与目标词、教学输入、练习、迁移任务、提示、标准答案、错因、音频、审核记录和权利来源。题目按类型验证，不将所有问题强塞为选择题。

| 类型 | 判定方法 | 必备替代与边界 |
| --- | --- | --- |
| 图片/文字选择 | option ID 比较 | 图片 alt 不提前泄露听辨答案；另有同等可达任务 |
| 听音选词 | 音频存在且 option ID 比较 | 音频失败不计听辨错，转文字练习 |
| 拼写 | 标准词形、大小写/标点规则明确 | 接受的英美变体在题目列出 |
| 排序拼句 | token ID 序列或明确等价序列 | 多个合法答案都接受；允许点击与键盘 |
| 纠错填空 | 错误位置与有限正确集合 | 不能用过窄答案误判语法正确表达 |
| 阅读理解 | 先覆盖封闭式与证据定位 | 开放表达只给 rubric 建议 |
| 引导说写 | 模板目标与人工制定 rubric | ASR 不充当标准发音评分 |

每道题只有一个明确主要考点。干扰项必须对应可解释错因，不能靠超纲词、含糊图片或逻辑陷阱增加难度。词汇按 lemma 与词形关联，去重后统计规模，避免把复数和过去式重复当作新单词完成指标。

## 发布流程

```mermaid
flowchart LR
  A[目标与词汇分级] --> B[原创脚本与题目]
  B --> C[结构和确定性校验]
  C --> D[英语教研复核]
  D --> E[音频与视觉制作]
  E --> F[儿童试用与可访问检查]
  F --> G[版本发布]
  G --> H[缺陷反馈与撤回]
  H --> B
```

首发可使用 Git + JSON/CSV + CI，不强制开发复杂 CMS。编辑者与审核者不同；答案变更发布新版本，不能覆盖历史题。阻断型内容缺陷可即时撤回 item，活动会话使用安全替代题，历史记录标注“此题不计能力评估”，重新计算受影响投影。

## 全年级质量门槛

72 单元均有 4 微课与独立练习；288 课均经过语言审核；基础2,832题加专题新增至少480题，合计至少3,312题逐题检查答案和标签；每学期均完成听说读写覆盖。60个专题各有至少24条题目引用，且诊断/结测的题目家族分离。72条固定句式各有语境、槽位、合法变体和应用证据；不能只完成列表而没有可练内容。所有关键标准音频均有校对文本、可追溯权利和试听复核。

每个年级至少邀请 3–5 名目标儿童进行观察，需监护人许可，重点看题意、触控、声音和挫败点。这是小样本可用性研究，不能宣称证明教学效果；延迟测验另行收集。

## 朗文映射策略

小学朗文系列存在不同系列与版次。Pearson 的 Primary Longman Elect 电子教材页面提供小学系列信息；另有 Second Edition 教师资源入口，需要按实际系列与版次核对。[Pearson 小学产品页](https://www.pearson.com.hk/en_GB/learning-and-teaching-resources/e-learning/primary-longman-elect-e-textbook.html)、[Second Edition 资源入口](https://plet2e-eng-pri.pearson.com.hk/6a/)

不能将 Longman English Elect (2nd Edition) 的样章页自动等同于 Primary Longman Elect (Second Edition)。用户尚未指定版次，因此配套 [mapping 模板](examples/textbook-mapping.csv) 的状态为 pending，不填虚构单元名。

映射步骤：登记系列/版次/ISBN或官方标识→核对合法可用的目录和教学进度→建立 skill/lexeme 关系→教研复核→发布带版本的映射→每年检查改版和勘误。由家长选“跟教材”或“自主路线”，同一学习证据复用，不因换教材清空掌握。

产品提供原创同能力练习和进度索引，默认不发布教材扫描页、课文、音频、插图和商业答案；精确使用教材受保护内容需要相应授权。首发不做私自抓取登录后教师资源或整本教材上传到第三方 AI。

## 媒体与内容登记

每项资产记录 source、owner、license、用途、地域与期限、attribution、校对者和 checksum。品牌角色、音效、字体、AI 生成图及音频均入册；未知权利素材不能进入生产包。儿童照片不作为默认插图。

## 示例资料的用途

示范课 JSON 用于明确结构、正确答案、提示层次与学习目标；72 行 CSV 用于覆盖和排期。它们不等于 288 节已完成课件，实施报告需分别统计“已规划 / 已编写 / 已审核 / 已发布”，不能混用。
