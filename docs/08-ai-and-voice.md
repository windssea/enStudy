# 用户自带 AI 与语音服务设计

实现状态（2026-10-19）：六场景短对话、规范WAV录音/识别、MP3合成和独立环境BYOK加密配置已随阶段同步发布；v0.50新增[阿里原生ASR](73-aliyun-native-asr.md)，v0.51新增[qwen3.8-flash文字预设](74-qwen-text-profile.md)，完整CI与两站检查通过。这里的发布与协议测试不等于真实供应商质量已验收；真实Key、原生实时语音、生成题审核和Pad实机仍待完成。接口、保留策略见[轮流对话](35-ai-dialogue-and-voice.md)，下文仍包含完整目标设计。

v0.18另补了[本机听句/听词和文字辅助](37-listening-and-evidence-reading.md)，不调用BYOK音频适配器；这与AI轮流对话能力分开记录，也不能用模拟播放事件代替真实设备验收。

## 设计原则

家长可配置自己的服务 baseURL、密钥和模型，并给孩子开启具体能力。文本生成、语音识别、语音合成和实时对话分别定义能力与供应商；同一个服务支持文字不代表支持音频。基础课程和复习完全独立于 AI。

首发实现一个经测试的 OpenAI-compatible 文本协议适配器（协议兼容类型，不预设具体 OpenAI 产品或模型），以及可扩展的 ASR/TTS 适配接口。供应商特有协议以明确 adapter 接入，不能仅替换 baseURL 就声称兼容所有服务。具体模型名在连接时由家长填写和测试。

## 设置数据与连接测试

每个家庭可拥有多条连接：label、adapter、baseURL、model、encryptedKey、能力配置、供应商数据政策链接、每日 token/次数预算、音频时长预算、启用状态。文本、ASR、TTS 可分别选择连接。每个能力记录 `unknown/supported/unsupported/error`、测试时间与配置版本；换模型或地址后重新测试。

界面按明确连接类型展示配置。OpenAI兼容填写API根地址；阿里文字预设填写`/compatible-mode/v1`根地址，适配器拼接`/chat/completions`，采用system、max_tokens和显式关闭思考。阿里原生ASR填写以`/api/v1/services/aigc/multimodal-generation/generation`结尾的完整端点，不再拼接OpenAI音频路径。不能混用两种约定或重复添加`/v1`。只接受公共HTTPS域名与443端口，不接受URL用户名密码、片段、查询参数或任意请求头模板，真实出站仍须精确主机审批。

保存连接先校验格式和目标，并提供只验证站内加解密的“检查密钥保存”。文本连接主动发送最小协议测试；ASR和TTS分别主动测试，原生ASR不需要也不允许文字测试。向供应商测试会产生调用并可能收费，不自动执行或重发。模型列表接口可能不存在，不能以列表失败认定整个服务不支持，不给儿童暴露供应商错误原文与Key。

## 密钥处理

浏览器经 HTTPS 把 key 发送到同源成人 API，服务端以 Web Crypto AES-GCM 加密，随机 96-bit IV，每条密文绑定 `household_id + connection_id + key_version` 作为 AAD；主密钥仅保存在 Cloudflare Secret，D1 保存 ciphertext、IV 和 key id。支持轮换主密钥和连接密钥，删除连接即失效。

列表只返回 `hasKey` 和末四位。密钥不放 localStorage、IndexedDB、日志、URL、错误上报、前端环境变量、Service Worker cache 或 AI prompt。服务器发往供应商时临时解密。主密钥可解密租户密钥，因此运营方与供应商的信任边界需在家长设置中明确说明。

## 自定义地址与出站安全

多租户服务器上的任意 URL 请求会形成 SSRF 和付费代理风险。首发仍允许家长填写 baseURL，但仅已审查的公共 HTTPS 主机可立即启用；新自定义域名保存为“待接入验证”，由部署者加入精确主机白名单并验证后启用。这是首发兼容范围限制，应在设置页明确，不能显示“支持任意地址”。自托管运营者可自行扩充名单。

服务端规范化 URL；拒绝 IP 字面量、localhost、内网/链路本地/保留地址、非常用端口和重定向；限制固定 API 路径、响应类型、响应体大小和超时。不得将授权头转发到不同主机；不允许客户端传任意路径或 headers。静态 DNS 检查无法保证连接时 DNS 不变，不把它当成 DNS 重绑定的完整防护。

R2 的开放自定义服务接入需先完成出站代理技术验证：在受控出站网关完成解析、校验实际连接 IP、固定解析结果、保持正确 TLS 主机校验并禁止重定向，验证 IPv4/IPv6、CNAME、重绑定和服务商变更。该能力可能引入额外出站服务与运维；未完成前保持白名单模式。浏览器直连用户密钥不作为默认绕过方案。

## AI 能做什么

| 用途 | 约束与校验 | 失败回退 |
| --- | --- | --- |
| 错因解释 | 仅目标知识点、标准答案与该题错误；短中文加英文例句 | 原创标准讲解 |
| 同技能变式 | 结构化 schema、词汇白名单、长度、唯一解与规则校验 | 已审核题库 |
| 情景对话 | 当前主题、已学词、有限轮次、无外部工具 | 预设对话卡 |
| 引导写作 | 给 1–2 条可执行修改，不代写全部任务 | 教学 rubric |
| 个性化建议 | 基于汇总错因建议练习，不自行改课程或权限 | 规则推荐 |

AI 生成→schema 校验→词汇/内容过滤→确定性可解性校验→少量高风险人工复核→使用。纯粹“让另一个模型再看一遍”不足以证明答案正确。无法确定唯一答案的题型只提供练习建议，不产生掌握晋级。共享题库必须编辑审核，私人生成题不跨家庭直接共享。

提示词与内容数据分离，孩子输入和教材映射均作为不可信资料；模型没有数据库、URL 抓取、执行代码、购买或发消息工具。只发送随机会话别名、技能和必要题目片段，不发送姓名、学校、完整学习历史和密钥。对话上限默认 6 轮；超出主题温和引导回任务。

## 语音接入层次

| 级别 | 链路 | 发布位置 |
| --- | --- | --- |
| A 标准音频 | 原创授权录音/预生成音频→重听与跟读 | R1 所有年级 |
| B 浏览器朗读 | `speechSynthesis` 可选声音 | R1 降级辅助，声音与设备有关，不保证口音一致 |
| C 轮流语音 | 麦克风→ASR→转写确认→受限文本对话→TTS | R1 可选 BYOK 能力 |
| D 原生实时 | 浏览器 WebRTC 或受控 WebSocket→供应商实时会话 | R2，按供应商逐个验证 |

轮流语音状态机：idle→requestingPermission→recording→uploading→transcribing→confirming→thinking→speaking→idle；所有阶段可取消。录音格式用 `MediaRecorder.isTypeSupported` 运行时协商，不能假设 Safari 与 Chromium 均产出 webm；服务端只接受 adapter 明确支持的容器。Worker 不做重量级转码，必要时选择兼容格式或专用转码服务。[MDN 音频格式探测](https://developer.mozilla.org/en-US/docs/Web/API/MediaRecorder/isTypeSupported_static)

麦克风需要安全上下文与用户授权；iPad 播放和设备权限应在手势触发后验证。拒绝权限、无麦克风、锁屏、蓝牙中断、弱网均提供打字或跳过，不能判为语言错误。[MDN getUserMedia](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)

ASR 转写与真实发音质量不是同一回事。未接入并验证专用发音评估前，只能反馈“识别到的句子”和表达建议，不显示虚构的发音百分制。允许孩子确认或修改转写。

实时方案优先供应商短期凭证，浏览器只持有限时、限用途的会话 token，长期 key 留在服务端；若供应商不支持受限临时凭证，则使用具备上游鉴权、配额和取消能力的专用 Worker/DO 代理。不能为了方便把长期 key 放 URL 查询参数或浏览器 WebSocket。服务端不能随意改写 WebRTC 加密媒体，因此需审查供应商端儿童保护能力；不满足时保留轮流语音。

## 配额与故障

首发默认每孩子每天 10 次文本解释、6 轮对话、3 分钟语音，家长可调；这些是产品限额，不是供应商价格。每日家庭总额覆盖多个孩子，先原子预留最大 token/音频预算，再请求，再结算。供应商未返回 usage 时使用保守估计并标记，避免显示虚假精确金额。

设置端允许录入已知模型单价用于估算，未知价格显示“仅统计 token/时长”。每次 token 上限、单请求 20 秒超时、单轮录音 20 秒、供应商熔断、双击幂等共同控费。未知上游结果先保留预算，不以取消请求为理由假设供应商未收费。
