# 专题特训产品与教学设计

专题特训纳入完整首发，与课程学习、间隔复习并列。孩子可按需要集中练习一个难点，家长也可从错因报告进入对应专题；训练仍使用同一份知识图谱、题库和掌握证据。

## 专题组织

首发规划8类、60个专题，完整清单见 [专题矩阵](curriculum/topic-training-scope.csv)。其中新增12个固定句式主题与72条常用表达，详见 [固定句式体系](18-sentence-patterns.md)。每个专题有建议年级、先修条件、错误标签与适合的互动方式；年级仅作推荐，不阻止补基础。语法为上位分类，时态和词形有独立入口，但引用同一底层知识点，避免重复建模与重复计数。

| 类别 | 专题范围 | 主要训练方式 |
| --- | --- | --- |
| 语法特训 | 代词、be、冠词、可数性、数量词、介词、情态动词、there be、物主关系、频率副词 | 情景选句、图片摆放、分类、错误定位、积木构句 |
| 时态特训 | 一般现在、现在进行、二者对比、一般过去、过去进行、过去二者对比、将来表达、现在完成入门 | 时间线、场景变化、动词与助动词联动、时态对比、同一事件改写 |
| 单词变形 | 名词复数、第三人称单数、-ing、规则过去式、不规则过去式、过去分词、比较级/最高级、构词法 | 规则分拣、词形搭建、双写/去e定位、变形输入、回到句子使用 |
| 句型特训 | 肯否转换、疑问、词序、连接词、综合纠错，以及12个固定句式主题 | 句框替换、问答衔接、固定搭配、易混对比、改写与情景应用 |
| 词汇特训 | 听音识义、拼写、搭配、语境选词 | 听辨、图词提取、缺字补全、搭配配对、换情景提取 |
| 拼读特训 | CVC、辅音组合、长元音、多音节/词形策略 | 声音与字母对应、分音拼合、词族对照，逐步过渡词义策略 |
| 阅读特训 | 细节定位、顺序因果、指代推断、多资料整合 | 标记证据、排列事件、连接代词与人物、信息交叉核对 |
| 表达特训 | 扩句、引导口语、段落写作、自主修订 | 句子阶梯、角色卡、结构提示、按rubric修改；开放表达为形成性反馈 |

小学时态训练按现有P1–P6课程目标分级：先建立时间意义，再练形式与对比。现在完成等进阶内容要求先修与教研审核，不强制所有年级学习成人式“十二时态大全”。

## 一次特训的流程

1. 选专题：显示“练什么、为什么推荐、约几分钟”，可从家长推荐、课程错题或孩子自主选择进入。
2. 小诊断：3–5题覆盖不同错因；遇到明显先修缺口先推荐补基础。诊断跳过不等于已会。
3. 有针对性的示范：只解释当前错因，用对比例子和简短演示；演示中看到的答案标记为已暴露。
4. 分层训练：基础识别→受控产出→易混对比→新场景迁移；不是所有孩子都从第一关开始。
5. 当轮回顾：显示独立正确、提示后正确、需要巩固的区别，不只给总分。
6. 延迟复测：第1/3/7天可发起专题复测检查点，具体记忆调度仍由共享复习引擎决定；遇到已有到期任务则合并，不另建三份复习。

默认特训一轮8–12题、约5–10分钟，可退出续练；诊断另计约3分钟。可选择专项练习或综合挑战，计时挑战默认关闭，不以操作速度判断学习能力。

## 时态训练实例

以一般过去时为例，训练包含三个不同判断：事件发生在何时、句子需要哪种结构、动词应该用什么形式。场景分别使用过去时间线、肯定与否定对比、疑问回答；不能只抓到 yesterday 就机械选过去式。

- `Mia went to the park yesterday.`：过去的完整事件。
- `Mia did not go to the park yesterday.`：did已承担过去信息，后面的go用原形。
- `Did Mia go to the park yesterday?`：助动词前移，原动词保持原形。

错因分别记为时间理解、助动词选择、词形、语序；如果孩子会选时态但把went写成goed，推荐不规则动词词形训练，而不是把整个过去时从头再学。

一般现在/现在进行、一般过去/过去进行和will/going to均有对比任务。需要上下文才能判定的题必须给足情景，存在多个合法解释的表达不做唯一答案题。

## 单词变形训练实例

| 范围 | 示例 | 要区分的错误 |
| --- | --- | --- |
| 名词复数 | cat→cats、bus→buses、baby→babies、child→children | 规则、不规则与辅音+y；不可数名词不强行加s |
| 三单 | play→plays、watch→watches、study→studies | 主语触发条件与拼写规则分开 |
| -ing | play→playing、make→making、run→running | 直接加、去不发音e、常见双写条件；不泛化为所有CVC都双写 |
| 过去式 | play→played、study→studied、stop→stopped、go→went | 规则词尾与不规则映射 |
| 过去分词 | go→gone、eat→eaten | 与过去式区分，绑定适当句型和先修 |
| 比较形式 | tall→taller/tallest、big→bigger/biggest、good→better/best | 词形、more/most策略、合理不规则项 |
| 构词 | happy→unhappy、teach→teacher | 词义与词性变化，不与单纯屈折变形混为一个评分维度 |

每个词形关联lemma、目标form、可接受拼写变体、适用条件、反例、音频及例句。英美变体如travelled/traveled由内容库列入接受集合，不能由简单后缀拼接推断。输入→规则识别→句中应用至少两个维度分别评估。

## 推荐、掌握与防重复

专题报告聚合底层技能，显示“时态意义已稳、否定句动词还需巩固”等具体结论。训练完成、当轮表现、延迟复测、长期掌握分开展示，不生成虚假的专题百分比能力概率。

课程、特训与复习共享`child + skill/lexeme + modality`，同一天跨入口最多一次成功晋级。同一题或同一模板家族的紧邻变式不能重复充当独立迁移证据；诊断与结测使用不同题目家族。复测只是选题入口，不能单独推进第二套记忆状态。

今日10题任务可将原4道新学中的2–4道替换为已选专题，保持总时间预算；专题不会自动叠加成每日额外必做负担。纯专题模式也保留到期提醒，家长可暂时调整主线进度但不清空课程证据。

## 页面和交互

`/learn/training`显示8类入口、建议年级、三个优先弱项；`/learn/training/:topicId`显示目标、诊断、训练层级与历史；实际练习使用统一播放器。家长报告支持“练这个专题”，生成可取消的建议，不强制孩子完成额外份额。

语法采用句子工坊/场景摆放，时态采用可点击时间线与事件切换，词形采用规则分拣和变形工厂，阅读采用证据卡。每类交互都有DOM、键盘和单击替代，3D只强化意义，不代替题目本身。AI可按错因解释和生成候选变式，仍须通过现有内容校验。

概念稿“专题特训”页演示语法判断、时间线切换、词形输入和固定句框辨析。示例不等于完整60专题或72条句式已生产。

## 数据与API增量

- `training_topics`：专题ID、分类、建议年级、版本、目标与先修、状态。
- `topic_skills`：同一技能可被多个专题复用，指定主要或辅助目标。
- `topic_items`：引用不可变题目版本、phase、level、item_family；不复制题目答案。
- `training_runs`：家庭与孩子范围、topic版本、phase、关联学习会话、诊断摘要和状态；不另建review_cards。
- `word_forms`：lemma、form类型、接受表面形式、变体、音形条件和例句；生僻条件由词条审核，不靠全局正则硬推。

`GET /training/topics`支持类别、年级筛选；`GET /training/topics/:id`返回公开目标、先修和可用层级；`POST /training/runs`创建诊断/训练/复测；`GET /training/runs/:id`恢复；`GET /reports/:childId/training`聚合表现。创建操作需幂等requestId，phase由服务器推进，答题继续调用`POST /attempts`，不得重复记分。

## 内容规模和验收

60专题每个至少24条经过审核的可用题目引用，共1,440条映射；其中每个专题至少8道新增独立练习，新增480道，其余可复用合适的课程题，复用只增加映射不增加独立题数。总生产目标由2,832增至至少3,312道，不以AI即时生成凑数。诊断、训练、迁移与延迟复测的题目家族必须足够分离；不满足时补题后才能通过该专题验收。

首发验收还包括：三个重点入口齐全、不同专题使用适合的题型、先修缺口有补课、错因能推荐到对应子专题、语法与词形分维度、跨入口无重复晋级、延迟复测不复用已展示答案、家长看得到具体改善与残留问题。
