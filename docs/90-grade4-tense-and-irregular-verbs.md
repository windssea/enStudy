## 专题与实际题量

60个常见动词分成常用30词、进阶30词；讲解按三形相同、过去式等于过去分词、原形等于过去分词、三形不同分类。表格每页10词，常用页只显示常用30词，进阶页只显示另30词，did和三形拓展页覆盖60词。read特别说明拼写相同而读音变化；get以英式got展示，完成式位置也接受美式gotten，过去式位置不接受gotten。

| 新专题 | 事实组 | 选择/输入变体 |
| --- | ---: | ---: |
| 不规则过去式·常用30词 | 90 | 180 |
| 不规则过去式·进阶30词 | 90 | 180 |
| did / didn't后用原形 | 120 | 240 |
| 过去式还是过去分词·拓展 | 120 | 240 |
| 合计 | 420 | 840 |

420组含词形提取、肯定句填空与还原、问句和否定、过去式与完成结构的对比。每组选择与输入是同一family的两个变体，不能把840说成840种不同场景。沿用5/10/20题随机抽取、组内不重复、优先抽未见题族；普通随机练习不因复习日期限制进入。原有60专题和7200题不重写，当前合并目录为64专题。

过去分词是词形，不是另一种独立时态。did规则用于这里的一般过去时实义动词问句/否定；be另用was/were，不生成Did you be之类错误句。新词形表只在讲解区显示三形与三句核心对照，不添加朗读、音频帮助、角色或引导层。
