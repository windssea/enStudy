# v0.41 自带AI的单段写作建议

写作小工坊增加可选的单段点评。管理家长使用已测试的文本连接，单独同意处理范围并复验当前密码；孩子核对本段与服务来源后主动请求。标准写作、保存、预览、句框与自查继续独立可用，不需要AI。点评不自动改正文，不给分或排名，不增加星星、课程完成和复习晋级。

## 教学与交互

每段下方提供“看看这一段的AI小建议（可选）”，一次只展开一个点评区。未保存的改动、保存中或冲突时不发送，并收起旧建议。保存后需要重新核对当前版本，确认框默认未选。界面展示连接名称、服务主机、将交出的本段全文和费用说明；默认没有自动请求或定时轮询。

结果包含简短中文鼓励、最多两处“原句 → 一种英文改法 → 中文理由”及一个下一小步。原句必须逐字出自对应段落，不自动将修改示例插入作品。修改与保存后旧结果收起。AI提供的英文修改示例按现有规则写入当天示范哈希，后续相同句子不能据此冒充独立回忆；不将一次建议当作教学正确性或掌握证明。

孩子可以停止本页等待、继续输入，或手动读取同一次结果。关闭和取消等待不能撤回已发给服务商的资料或费用。额度用完时提供只读取已有点评的路径；服务器readOnly模式找不到结果时不会创建预留、出站或收费重试。家长设置区有明确重新读取入口，未知保存结果不被当作已开启。

沿用现有编辑区与蓝色软卡片，按钮至少52px，正文18px、修改示例20px，确认框整行可点。保留原生输入、焦点及可换行的长文字，不在打字时新增持续3D运动。修正了P4“计划”正文与中文提纲共用writing-plan ID的问题，正文使用writing-paragraph-*独立标识。

## 数据范围与授权

请求发送草稿ID、版本、段号和请求号，服务端重新读取已保存内容。服务商只收到该段正文、所选主题的年级、本段任务名和公开提示。作品标题、中文提纲、其他段落、儿童昵称、家庭/儿童/草稿ID及凭据不进入模型消息。基础筛查拒绝明显联系方式、网址、执行标记与部分不适宜文字，但不能保证识别所有个人信息；仍需采用虚构内容并核对所选服务政策。

家长的答题解释或语音同意不能代替作品点评同意。ai_writing_settings独立记录连接、连接版本、同意时间与设置版本；仅当前家庭owner且使用非临时密码的成人可管理。保存再次检查密码版本、家庭上下文和被测试的连接版本。修改连接配置后旧设置不再准备就绪，需要重新测试并确认。开启作品点评不会自动开启答题解释或语音。

儿童接口复用真实grant、家长登录、当前家庭与儿童隔离。请求与返回再次校验草稿版本、设置版本、连接版本和授权；正文编辑、删除、关开关、连接变化或登录撤销期间返回的旧结果不展示。兄弟姐妹或另一家庭即使携带自己的合法儿童ID也不能点评他人作品。

## 预算、重试与临时结果

复用ai_daily_budget和ai_child_budget，与答题解释共享家长设定的次数和用量单位上限；语音自身的细分额度继续保留。预留、权限检查、请求行与writing_ai_links在同一个D1 batch中完成，任何一步失败整体回滚。aiBudget新增可选的事务后置语句和结果存储授权条件，原有调用保持原路径。

同一grant、草稿版本、段号、连接和设置版本只派发一次。相同或不同UI请求号返回同一待处理/已完成结果；请求号不能换用于另一份作品。无usage或未知出站结果保守保留预留，不能承诺免费或自动退款。到期及失败结果不自动再次出站；修改并保存后才形成新的点评版本。

点评返回仅使用有长度边界的结构化数据，拒绝多余评分字段、虚构原文引用、重复引用、链接/联系方式、部分不适宜文字和密钥回显。该检查不能证明模型建议正确。输出按普通文字渲染，没有模型工具调用或HTML执行。

结果使用现有AES-GCM密钥环加密，绑定家庭和请求上下文，默认10分钟后不能读取。保存密文时在SQL中再次检查授权；删除、改版或修改点评设置会清除相关旧密文，晚到的供应商响应不能重新存入。过期内容在后续访问时尽力清理，没有新增Cron或承诺无访问时立刻物理清理。请求/预算及关联元数据不等于正文短存，仍遵守现有账户和草稿生命周期；完整运营保留与备份删除门槛另验。

家庭导出仍为25类：安全的作品点评开关与同意元数据并入AI设置，临时点评输出、密钥与加密值不进入资料包。0041仅本地应用并加摘要保护，已应用的0040和更早迁移未改动。
