# 原始需求与验收追踪

| 用户需求 | 设计位置 | 可评审资料 | 首发验收 |
| --- | --- | --- | --- |
| 小学生英语语法、单词学习 | 课程与PRD | 72单元矩阵、示范课 | P1–P6全能力覆盖、语言审核 |
| 活泼、互动与强动效 | 设计系统与体验 | 可点击地图、句子工坊、反馈 | 触控可用、安静模式、任务中不干扰 |
| React+Three.js | 技术架构 | DOM与3D边界、资源预算 | 真机样片、2D回退 |
| Cloudflare Pages与轻量数据库 | 架构与数据 | D1 SQL草案、部署分工 | 预览/生产隔离，远程D1测试 |
| 复习策略 | 复习文档 | 参考算法、事件与到期状态 | 延迟变式、幂等、积压保护 |
| 语法、时态、单词变形等专题特训 | 专题设计与PRD | 8类60专题矩阵、独立入口、不同交互、错因推荐 | 诊断/分层/迁移/复测闭环，跨入口不重复记证据 |
| 语法包含大量固定句式 | 固定句式体系 | 12主题72条表达，句框/槽位/情景/变体 | 替换、对比、问答、迁移与延迟复测，不靠死记单句 |
| 自带baseURL/key | AI与安全 | 连接结构、掩码、预算 | 已验证主机可用；未审查自定义域明确限制 |
| 支持语音服务接入 | AI与语音 | 四级能力、状态机、适配界限 | 首发轮流语音，实时R2逐供应商验证 |
| 对接香港朗文进度 | 教材运营 | 版次化映射模板 | 不虚构目录；精确映射需版次核实 |
| 自主教学体系 | 全学段课程 | 图谱、分级、阶段评估 | 脱离AI和教材也能正常学习 |
| PC与Pad | 页面和设计 | 响应式概念稿 | 横竖屏、Safari、触控与键盘 |
| 多用户保存进度 | 数据、API、安全 | 家庭/儿童模型与同步规则 | 多家庭隔离、双设备冲突、恢复 |
| 首发小学所有内容 | PRD与计划 | 六年级十二学期生产目标 | 不是目录即完成，288课和题库审核后才发布 |
| 前期所有文档与评估方案 | 全文档包 | 方案、需求、课程、UI、架构、数据、API、AI、安全、内容、排期与测试 | 文件引用可用、概念稿可开、约束和待决项明确 |

这里的“首发”指将来产品公开首发。本次交付完成的是前期设计与概念稿，内容生产数量为实施目标。
