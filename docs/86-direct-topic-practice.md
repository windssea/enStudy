# v0.60 专题直接练习

状态：本地实现、578项单元测试及隔离浏览器验收通过，等待同步发布。

## 行为

专题准备页改成“每轮题量 + 开始练习”。默认10题，可选5/10/20题，调用既有普通随机题库接口；不创建分步计划，不受旧计划复测日期、读取等待或读取失败影响。

删除日期等待、五维范围、学习记录解释、阶段路径、计划刷新、辅导折叠卡，以及折叠在底部的普通练习绕行入口。时态对比与实际知识示例保留在操作入口下方，移除示例组件外层“先玩一玩”的折叠。示范登记和题目披露边界保持。

既有计划的未完成会话可以接续，继续原答案与回执；已到期复习及未完成阶段提供一行次操作。未到期计划不显示等待卡，也不挡普通练习。旧共享计划在服务端允许切换、且未开始新阶段时，接续操作采用专用材料，历史成绩与已分配任务保持原样。

复习页只推荐已经到期的专题，家长仍可查看全部历史记录。普通练习沿用既有复习与证据策略，不能把当天多轮练习记成隔天回访。服务端间隔测评语义、材料隔离、权限和判分均未改动；没有新增或修改数据库迁移。

## 验证

578项单元测试/71文件、格式检查及前端/Worker构建通过。新增5项回归覆盖：记录未加载时直接开始、未来日期不形成儿童等待入口、已开始会话仍可接续、到期/完成状态，以及儿童到期推荐与家长全记录的区别。

隔离内存D1应用0001–0050。浏览器使用本地测试管理员；专题计划接口分别模拟明日回访与503读取故障，其余接口使用真实测试数据库。明日回访时直接开始20道随机题，作答do后收到正确判分和“已保存”；记录故障时仍可开始5题。模拟计划不冒充真实回访结果，未在云端儿童档案作答。

1280px桌面、768px平板及375px窄屏检查，无横向溢出。负句专题没有任何指导折叠区，主按钮正常可用。截图与状态记录在忽略目录`artifacts/v060-topic-*.png`、`v060-topic-ui.json`、`v060-direct-answer.json`。浏览器尺寸检查不代表真实平板或儿童试用。
