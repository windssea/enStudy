# v0.22 家长近7天与近30天报告

本阶段补齐跨入口的连续学习报告，入口在本地家长空间，选择儿童档案后显示。仍为本地开发，注册关闭，默认管理员不变；课程仍为96/288节，不因新增报告宣称全产品完成。提交使用`[skip ci]`，沿用10月18日08:05免费重试云端发布的安排。

## 家长能看到什么

- 近7个或30个自然日的作答、独立答对、辅助后答对、有记录的天数；无记录的日期明确为零。
- 已完成回合与不同微课数量，和未完成但已保存的作答分开；重复练习的题目家族另作去重计数。
- 每日静态堆叠图及可展开的数字表；七种学习入口、七种题型分别汇总。
- 最多8组有答错或辅助记录的知识点及练习能力，展示原始计数，不推断错误成因或宣称掌握率。
- 当前到期和未来7×24小时内将到期的记忆卡数量，可进入复习花园；复习卡按知识点与能力计数，不等于单词数。

报告以当前儿童档案为单位。旧的累计完成和最近十轮记录保留在折叠区，AI设置、账号设置继续各自展开。家长可主动刷新报告；报告不估算学习时长，不做排行榜，不把当次独立答对当作长期掌握。

## 数据口径

只统计窗口内已写入`attempts`的观察，使用服务端`received_at`。独立答对需在线证据、正确结果和独立标记同时成立；提示、同日示范或文字辅助后答对归为辅助，早期`course-foundations-v1`课程因展示过答案而保守归入辅助。未确认离线、AI观察与未计分结果单列，不抬高独立计数。现有AI对话不写题目成绩，不进入这些统计。

窗口包括今天，从孩子时区的首日午夜起，截至本次生成时刻，采用毫秒边界，拒绝未来记录；无效时区显式回退`Asia/Shanghai`。日期区间通过实际时区午夜计算，可处理已验证的纽约夏令时23/25小时日期，而不是将每个自然日都视为固定24小时。未来复习提醒采用接下来168小时，与历史自然日窗口不同。

相同事件重放不产生第二条`attempts`，报告因此只计一次。读取只做查询，不推进卡片、不发星星、不切换学习档案或任务。内容元数据按`item_id + item_version`连接，不改用当前最新版本；辅助证据的历史保守修正不改写原始回执。完成回合按完成时间计入窗口，与作答日期分别统计；一轮跨窗口时两类计数可以不同。

## 已实现接口

`GET /api/v1/family/children/:id/report?days=7`，`days`仅接受7或30，默认7，重复参数或其他值返回422。返回类型为`LearningReport`，含儿童标识、窗口、总计、逐日、入口、题型、需再练记录和即时复习数量。不是旧概念API中的通用报表或导出接口。

需要有效成人会话，并完成临时密码修改；儿童grant或本机开发身份不能读取。成人只读自己家庭的孩子，即使是站点管理员也不跨家庭读取，未知和外家庭档案同为404。使用绑定参数与`private, no-store`；不返回答案、原始回执、会话权限、密钥或AI对话。报告不能替代成人重新验证、邀请或完整数据导出功能。

查询复用现有索引和表，本次无需迁移。读取使用7条批量查询；30日查询94个绑定参数在本地D1已实际通过，未以本地结果宣称云端额度或性能达标。前端按账号/档案重新挂载，切换周期与离开页面取消旧请求，响应必须匹配档案及周期才展示。
