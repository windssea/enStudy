# v0.31 家庭邀请、成员权限与上下文

本阶段补上同家庭多位成人的共同陪伴，不开放自助注册。站点管理员继续预先创建账号，受邀家长须先修改临时密码；邀请只绑定已有的指定账号。课程仍216/288、17实验台54示范，原皮卡丘与小狐狸伙伴保持可用。

## 使用流程

家长空间显示当前家庭与“管理家长 / 协助家长”。展开“家庭与共同陪伴”可主动选择已加入家庭。切换只撤销该设备的儿童授权，保存过的作答、当前轮次与复习记录保留，重新选档案后沿用原显式续学和设备接管规则。

管理家长填写对方已有账号、选择权限并验证本人密码，得到一次显示的256位随机邀请码，24小时有效。服务器只保存SHA-256摘要；列表、审计与日志不返回原码，前端不放URL或本地存储，也不自动向他人发消息。收件人先核对邀请账号、家庭和权限，再验证自己的密码接受；原家庭不合并、不移动儿童记录，不自动切换到新家庭。

协助家长可以选儿童、学习与看报告，不能创建/编辑/删除档案、管理成员或读取AI设置。管理家长可更改成员角色、移除、撤销邀请；成员可主动退出。角色调整或移除会撤销该账号的全部登录与儿童授权，重新登录后按新权限访问。没有任何家庭的成人仍能登录、改密、核对并接受新邀请，再主动选择家庭。

每个家庭最多6名成人、同时最多6个有效待接受邀请，每个账号最多加入6个家庭。退出或降级时必须保留另一位未停用且已完成改密的管理家长；默认admin在初始家庭的管理权限不可移除。家庭角色不能授予站点管理员权限。

## 数据与并发

0032追加会话当前家庭、上下文版本、切换命令ID，以及家庭权限版本、邀请和最小审计三张表。本地已执行8条命令，不重写既有迁移。0033另加成人到家庭的查询索引，实际EXPLAIN确认使用覆盖索引，不在每次认证或人数检查时全表扫描。家庭变更使用D1 batch事务、全家庭版本CAS和事务内随机许可；列表与权限版本也在同一只读batch中获取，避免版本与成员状态不一致。邀请接受、撤销和角色修改不会只写半套数据。

邀请码同时绑定家庭、接收成人、邀请人和权限；接受时重新核对有效期、邀请人仍有管理权限、接收账号有效和人数上限。相同接受命令重复或并发只建立一次成员关系；移除后旧邀请码不会恢复成员。邀请人被降级或移除后，其未接受邀请撤销。两个管理家长同时降级不能让家庭失去最后一位可用管理家长。

家庭切换更新会话上下文版本并撤销当前设备的旧儿童grant；不结束或重写已保存学习会话。旧、新设备仍通过既有lease接管。页面为家长请求附带家庭ID与上下文版本，旧页、另一标签页及切走再切回的ABA旧版本不能误操作当前家庭。切换后缺少上下文信息的旧客户端也被拒绝，需刷新页面。`/me`能读真实身份以恢复正确界面。

现有儿童档案写入和AI配置事务也校验当前会话家庭及上下文版本，防止权限检查后又发生家庭切换的在途写入。家庭切换、账号变动或过期时锁定离线队列；不把家庭偏好写进公共静态缓存。旧登录会话先固定当前家庭；空家庭会话也固定为空，避免接受邀请后被min(id)排序悄悄换到另一家庭。

注册接口保持403，指定默认管理员凭据与初始管理权限保持不变。成人账户删除、保留期任务、恢复和备份删除重放仍未完成，本阶段的成员移除不会冒充账户删除或儿童数据抹除。

## 发布分两步

1. 准备版本先迁移0032并发布所有家庭上下文、权限和旧客户端保护，远程邀请与切换暂不开放。此时原家庭的学习、档案与AI设置继续可用。
2. 核验Preview与Production兼容后端后，再启用`platformFeatures.householdSharingEnabled`；两站仍同步同一构建。旧准备版也已理解会话家庭，因此新旧兼容版本交替只会暂时拒绝新协作操作，不会按旧的第一家庭规则落库。

启用之后如需回退，只能回到兼容准备版本或向前修复；不得直接回退v0.30并继续使用多家庭数据。准备开关由服务端构建配置控制，客户端不能自行开启；本机local阶段允许完整验证。
