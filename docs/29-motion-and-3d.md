## 可体验的变化

| 页面 | 3D 与交互 |
| --- | --- |
| 探险地图 | 加大视窗，加入戴帽子的探险伙伴、传送门、ABC 标牌、木桥与 Hello 词卡。点击打招呼时伙伴挥手、热气球回应；完成旗帜继续读取真实课程记录。 |
| 单词特训 | 真实 Three.js 伙伴、立体 Aa 词卡和苹果替换静态 CSS 图案；按钮触发打招呼。 |
| 专题、固定句式 | I / like / cats. 三块词语积木，点击后依次拼成一排，文字说明同步呈现。 |
| 微课 | 伙伴与立体打开的书本、主动击掌互动；教学例句和朗读按钮仍是原生 DOM。 |
| 复习花园 | 立体花盆与小芽，点击浇水出现水滴和短暂舒展；互动不更新学习记录。 |
| 作答 | 思考时静止。收到保存后的独立答对回执时，伙伴短暂跃起并出现彩纸；提示与错误采用较轻回应，错误不出现彩纸。 |

页面入场 320ms、前六张卡片最多错开 200ms、按钮按压 120ms、词块落位 240ms、反馈入场 280ms。词卡展开有短过渡；卡片浮起仅用于支持精确指针的设备，触摸使用按压与原生控件。

这些是学习场景与轻互动，尚未实现自由操纵角色、物理碰撞、3D 课程寻路或任意拖动搭句。积木是固定示例，不代替真实作答。

## 状态、可访问性与性能

- 顶部全站 2D/3D 切换沿用本地持久化设置。手动安静与系统减少动效共同生效；保留立体静帧或 2D 图案以及反馈文字。
- Three.js/R3F 按需加载，每个页面最多一个 Canvas，共用模型与运行时；未进入视口前用 SVG 固定尺寸占位。离屏后保留已创建的场景并暂停，不反复创建上下文。
- DPR 为 1–1.5；活动场景用 requestAnimationFrame 驱动按需渲染，目标上限约 30fps。没有实时阴影、后处理、外部模型或字体下载，使用参数化几何体。上限设置不等于实测帧率。
- 空闲仅伙伴与一个道具运动；地图为伙伴与热气球。作答关闭持续运动，答对彩纸最多 850ms，反馈窗口 900ms，不阻止下一步。
- 离屏、标签页隐藏或设备朗读时停止活动循环。反馈只响应新回执；切回页面、重新滚入视口或关闭安静模式不会重播旧回执。朗读结束、取消、错误、超时解除占用；旧回调和无关词卡卸载不能抢停当前声音。
- WebGL 初始化错误或上下文丢失显示 SVG 2D 场景。Canvas 与 SVG 都是装饰；DOM 按钮、真实课表、例句、题干与状态文字可独立使用。
- 动画只消费 UI 状态，不增加积分、不改复习算法、不写数据库。浇水和打招呼不产生掌握证据。

主要代码：`SceneStage.tsx` 管理活动与降级，`SceneCanvas.tsx` 管理画面与相机，`SceneModels.tsx` 共用伙伴和道具，`SceneRuntime.tsx` 控制循环，`CourseIslandMap.tsx` / `CourseMapCanvas.tsx` / `FlatMap.tsx` 提供地图，`speechActivity.ts` 管理朗读占用；动效样式在 `styles.css`。
