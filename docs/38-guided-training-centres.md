# v0.19：专题与句式的分步入口

日期：2026-10-17。依据用户“颜色不够活泼、引导混乱”的反馈，接续v0.18.1。当前为本地版本，今天保持Cloudflare免费计划、不发布；注册关闭、指定管理员账号与密码保持原样。

## 孩子看到的变化

- 专题先呈现8类入口，再进入该类的小专题；固定句式先呈现12个表达场景，再选择句式。原有60专题和72句式全部保留，不通过减少可练内容简化界面。
- 保留关键词搜索和建议年级。尚未选类别时搜索所有组，进入某组后在组内查找；年级筛选允许回补基础。无匹配时能清除筛选并回到搜索框。
- 列表卡片只有“看看怎么练”这一种动作。专题准备页突出当前一步；句式准备页默认5题，其他题量、例句和记录说明按需展开。保留随机5/10/20题与原抽题、近期避重、快照、跨设备及复习逻辑。
- 句框的29类英文槽位说明改为中文空位，如“动作（原形）”“人或事物”“比较的对象”。英文句子成分保留，空位可换词的说明可读。
- 专题新计划点击“开始5题小尝试”后保存计划并进入第一步；若服务器返回已有计划，接着原有任务或保留等待状态，不另开一轮。旧记录读取失败时先重试读取。
- 未来步骤和较长的教学证据说明折叠。当前任务、提示与独立答对、既有足迹和第1/3/7天回访仍保留，不把简化界面当成取消教学策略。

## 导航、焦点与场景

专题继续使用`#training=<topicId>`，句式新增`#pattern=<patternId>`，刷新和浏览器历史可恢复入口。无效编码、空ID、控制字符和过长ID退回对应目录；未知合法ID不能落到别的练习银行。组件中输入与文本仍用React文本节点显示。

目录的组别、搜索、年级与返回目标保存在当前App会话，进入练习后仍保留。准备页显示期间目录以原生hidden保留筛选；目录3D场景卸载，只保留准备页一个场景。返回时恢复原条目焦点，直达链接或原条目不存在时回到目录标题。列表跳转不再被父级的下一帧主区聚焦覆盖。

新目录使用v0.18.1的四组色块、深色文字、SVG图标和有文字的返回层级。PC四/三/两列按宽度调整，窄屏单列；保留52px以上操作区域、焦点轮廓、安静模式、减少动效及全站2D替代。家长页仍保持较低装饰密度。

实际浏览器连接本阶段再次返回Tabbit退出69。焦点恢复、返回滚动、放大、触控与WebGL显示仅有实现和静态证据，尚未标记真机通过。

## 修正例句与练习重叠的证据

核查发现，目录示例与58道组句任务的可接受标准句按现有sentenceKey规则相同，另有2道仅多了用于排版的对话破折号；部分还对应同一家族的选择和填写任务。查看示例同时记录原句和去掉对话分隔符的句子键，不把排版差异当成未见材料。新准备页必须先记录示范，再揭示例句，避免随后答对同一句被当作独立提取。

新增`POST /api/v1/learning/patterns/:id/view`，请求空对象，返回`{ saved: true, example }`。服务端从已有公开目录查找权威示例，客户端不能提交自定义示例；未知ID返回404。沿用现有登录、儿童上下文、Origin与授权检查。

示例句及同句家族映射到现有`teaching_exposures`，D1只存SHA-256证据键。写入后再核对当天记录和有效授权，成功才返回示例；无确认或接口失败时儿童准备页不把示例放入DOM，可主动重试。游客可预览，选择档案后重新进入时按该孩子记录。公开目录本身仍包含示例，系统不是监考或防作弊产品。

同日再遇到该句/家族，原有作答管线返回`support=example`、`outcome=hinted`、`independentEvidence=false`。新句仍可独立答对，过去日期的示范不封锁后续提取；后来查看示例不回写已经确认的回执。示范保存与作答继续依赖原有CAS和曝光条件，不新增第二套记忆表、不修改已应用迁移。

专题创建和读取增加组件代次保护，离开或更换孩子后迟到响应不继续启动任务。创建请求继续复用幂等ID，并避免同组件的重复提交。这些客户端竞态分支尚待真实浏览器交互验收；已有服务端生命周期检查仍是主要持久化证据。
