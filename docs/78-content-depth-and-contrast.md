# 题型与内容深度整改

## 源码审计

2026-10-19实际清点：普通专题题库7200道，覆盖60个专题，但只有240组结构模板，题型仅选择与填空。专用分阶段材料1560道，覆盖26专题、130个维度模板，题型同样仅选择与填空。模板中的名字、地点或物品变化不能当作新的认知要求；部分阶段通过同一模板的不同索引分配，不能据此声称已完成迁移能力教学。这解释了题量很多、体验仍浅且混乱的问题。

“句子积木”是专题类别，不是题型；底下混有选择与填写。本阶段改名为句型与句子，并按每一道题的真实控件显示题型。选择题用于辨别含义或形式；填空用于无选项提取；排序用于组织结构；改错用于定位并修正；阅读依据要求将语义答案与支持文本关联。不能把这些任务只看作同一种游戏外观。

## 第一组可执行示范

新增三年级起的“be与行为动词辨析”，在专题列表的“辨析与应用”中进入。12道原创情境分别处理职业、习惯、状态问句、行为动词问句、两种简短回答、主谓一致、does后的原形、状态否定、职业信息阅读依据、地点问句排序，以及新情境中的回答匹配。不是替换姓名生成的十二个变体。

4道选择、3道填空、3道改错、1道阅读依据、1道排序；一轮按题型分散抽取、不重复题族。请求20题时只有12个独立题族可用，返回12题，界面据实际题库显示题数。每道题有语境、明确作答要求、受约束的答案、提示与解释；解释指出错误选项或错误结构为什么不合适，而不是单纯显示正确答案。否定改错接受isn't和is not，阅读题必须同时选对依据与答案。

本组沿用保存、幂等回执、进度恢复、证据与间隔复习，不建立第二套分数。只有当前12题的控制性练习完成记录，不能声称自由表达、长期掌握或全套课程已重构。语法说明明确范围为一般现在时，不把“动作动词都不能用be”作为跨时态规则。

发布追加0048及独立内容版本；0001–0047、旧题版本、历史会话和成绩保持。答案与教研字段不进入publicExercise或公开目录，客户端只得到当前题面，解释按既有提交/提示路径披露。

## 后续内容门槛

停止以换名、换词和组合数量作为深度验收。其余专题按以下顺序重写：先明确一个能力目标与先修要求；给有意义的例子和反例；检查含义理解；练目标形式；辨析相邻易混结构；在新语境组织或修正表达；隔日用未见材料再检验。固定句式还要说明适用场景、语气和不适用边界，词形变化要放回词义和句子使用中。

每个单元必须记录目标、先修、认知要求、干扰项对应的具体混淆、可接受答案、提示影响及复测材料。先完成基础be/行为动词、一般现在/现在进行、一般过去/现在完成、名词与动词词形四组高频混淆，再扩展其余专题。没有明确证据的题保持待审核；自动测试只能检查内容约束和判题，不能替代教师与儿童试用。

设计依据：[British Council概念理解检查](https://www.teachingenglish.org.uk/professional-development/teachers/managing-lesson/checking-understanding)强调在情景中检查含义与功能，避免仅以练习形式正确代替理解；[LearnEnglish Kids的be动词参考](https://learnenglishkids.britishcouncil.org/grammar-vocabulary/grammar-practice/present-simple-verb-be)用于核对基础范围。题目与解释为本项目原创，不复制其题库。上述顺序是本项目采用的设计方案，尚未经正式教研认证。
