# v0.23 本机离线练习与联网确认

本阶段增加当前一轮的离线题包、加密本机草稿/队列和逐题联网确认。普通课程、单词、句式、随机专题、工坊及普通复习可准备；分步诊断、应用与延迟测验仍要求联网，以保留独立评估边界。AI服务不离线运行。课程仍为96/288节，完整目标未完成。

## 如何使用

1. 在联网状态选好儿童档案，开始一轮普通练习；当前题已提交时先进入下一题。
2. 从答题页或复习花园进入“本机离线练习”，主动准备当前这一轮。
3. 页面资源和题包全部准备成功后，可断网作答。支持现有七种题型，答案只显示本机暂存，不判题、不发星星、不冒充云端保存。
4. 联网后主动点同步。按原事件编号逐题取得判题回执并推进原任务；有冲突时停止并保留本机答案。

本地完整页面缓存使用[8788预览版](http://127.0.0.1:8788/#offline)。5173开发页跳转到预览版，不缓存编译中的开发模块。浏览器IndexedDB和CacheStorage按来源隔离，两端后台共用本地D1；登录Cookie在同一主机的端口间共享，实际部署仍是同源Pages和Functions。

题包最多20道当前尚未作答的任务，保留原题目版本和本轮顺序，有效期7天。没有正确答案、提示讲解或私有判题表。只带走当前已分配的一轮，不承诺离线浏览全站课程或无限重新抽题。

## 本机保存与身份

题目、答案、回执和学习会话权限用AES-GCM加密后保存到IndexedDB；每个家庭/孩子一条记录，随机IV，AAD绑定家庭及孩子，CryptoKey不允许导出。密钥也在该站点的IndexedDB中，因此这是站点内的设备缓存保护，不能抵御同源脚本被攻破或有权控制设备的攻击者。AI长期密钥和成人凭据不进入题包或缓存。

只有经过`/me`确认的儿童档案会解锁本机记录，localStorage仅记当前家庭/儿童标识。退出、换档案、密码操作和已知权限失效会锁定显示，不删除加密答案；联网进入原档案后可恢复。身份持久化失败时关闭读取，不能沿用旧孩子。已离线的设备不能即时得知远程撤销，联网后必须重新核验会话与设备权限。

草稿写入串行化，每次本机事务完成后才显示已保存。关闭页面时若输入还在写入，会请求浏览器保留离开确认；浏览器可能不展示该提示，不能以此替代已完成的存储事务。跨标签写入使用IndexedDB读写事务中的版本比较，冲突拒绝覆盖。排队后答案与事件编号固定，不能把旧题输入误存到下一题。

准备新题包不覆盖待同步队列或已保存草稿；清除必须明确确认，且只删除当前档案这轮本机记录。浏览器清理或存储紧张可能删除缓存和答案，仍需及时同步；本阶段不宣称设备持久存储已经实测达标。

## 同步与重新授权

同步先检查原家庭/儿童、服务端`offlineProtocol=1`能力和会话快照，之后每条请求继续受现有grant、lease、游标、版本和幂等约束。服务回滚到不支持离线证据的版本时停止提交，保留本机答案。没有自动接管。登录或设备改变时，可显式重新授权当前仍有效的原任务，再更新题包中的设备权限；已有不同答案会停止同步，不覆盖云端记录。已被新任务替换的会话不强行恢复。

先写回执到本机，再请求下一题，再确认本机推进标记。提交响应丢失时重发相同事件；下一题响应丢失时，现有幂等推进协议返回当前状态，不重复计分。云端已完成的会话可通过原回执确认最终状态，无需重新接管已结束的任务。身份或权限冲突、过期和网络未知结果均保留本机答案，不转移到别的孩子或新任务。

`POST /api/v1/sessions/:id/offline-pack`要求当前设备拥有当前任务，body为`assignmentId, leaseId`，返回`OfflinePack`，旧播放器或分步评估会拒绝。接口不写成绩，API使用`private, no-store`。

同步复用`POST /attempts`，显式传`evidenceSource=offline_unverified`及整数`clientOccurredAt`。服务端仍盲判答案，但不接收客户端指定可信在线证据；重试不能改答案、来源或离线发生时间。准备题包时服务端标记分配记录，省略客户端标记也按离线证据处理；评分事务比较该标记，避免准备和正常提交并发时误计独立证据。页面缓存失败也不撤销已做的准备标记，界面事先明确这一规则。成绩报告使用服务端接收时间，不用客户端日期回填独立证据。

离线正确回执为`hinted`，错误为`incorrect`，均有`support=offline`、零星星、零独立证据，报告单列未计分观察。复习只提前安排后续在线练习，不改变已有独立阶段、成功次数或lapse；首次在线独立确认从阶段0开始，之后的到期独立提取才可晋级。原始判题结果和完成回合仍保存，完成练习不等于掌握。新记录标明`rules-v3-offline`，不改写旧回执；新增0025迁移，只追加分配记录的准备时间和包标识，不复制题库。

## 页面资源缓存

准备成功才标记整套公共页面资源可用。构建生成带散列的manifest；worker只接受同源消息，序列化准备过程，最多100资源/8MiB，校验响应类型。只缓存根HTML和声明的JS/CSS，下载省略Cookie，不缓存API、家长报告、密钥或内容私有文件。部分失败保留上一份完整页面资源；导航网络超过3秒或失败时回退公共页面，哈希资源使用缓存。

实现依据：[Service Worker消息事件](https://developer.mozilla.org/en-US/docs/Web/API/ServiceWorkerGlobalScope/message_event)、[CacheStorage](https://developer.mozilla.org/en-US/docs/Web/API/CacheStorage)。这些浏览器API的可用性不能替代本项目的设备实测。
