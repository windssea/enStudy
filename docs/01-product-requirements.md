# 英语学习网站产品需求

## 用户与目标

主要学习者为小学一至六年级儿童，管理者为家长。首发服务多个家庭，每个家庭可有多个孩子和受邀监护人。教师与学校班级、收费订阅、儿童社交不纳入首发。

目标是让孩子每天在约 10–15 分钟内完成可结束的任务，并在以后独立用出学过的英语。复习是否有效看延迟测验表现，不把在线时长、完成动画或游戏星星等同于掌握。

| 用户 | 需要完成的任务 | 成功表现 |
| --- | --- | --- |
| 低年级孩子 | 听懂指令、认词、拼读、模仿短句 | 无家长持续操作也能完成一轮 |
| 高年级孩子 | 阅读短文、理解语法、表达完整意思 | 在新情景中完成迁移题 |
| 家长 | 配教材、查看弱项、管理时间和 AI | 了解下次练什么、为什么练 |
| 内容编辑 | 创作、审核、发布、撤回 | 可追溯版本和答案依据 |
| 运营者 | 管理服务和内容质量 | 查到错误类型和资源成本，不查看儿童私密对话 |

## 行为要求

每日任务默认由 4 道复习、4 道当前课练习、2 道迁移或应用构成，按剩余时间和积压调整。家长可改为 5/10/15/20 分钟；未完成可随时退出，不扣已获得奖励。孩子可以选择继续，但到约定时长先显示休息建议。

每次新学先给例子与演示，再练习，最后通过稍后出现的新题检验。答错后先提示一个线索；仍不会可看讲解。看过答案的同一道题不能计为独立掌握证据。

专题特训是一条独立学习路线，可从专题中心或家长弱项报告进入。时态采用时间线和情景对比，词形采用规则分拣和输入，语法采用构句和纠错。每日专题可替换原任务中的新学份额，不强制额外加量；同日跨入口不重复推进掌握。完整规格见 [专题特训](17-topic-training.md)。

多儿童切换后清空上一人的题目和进度缓存作用域，取消正在录音和未完成 AI 请求。儿童模式只能访问当前档案；进入家长区必须成人重新验证，头像选择或四位便捷码不赋予成人权限。

## 非功能目标

以下是验收目标，需在指定设备与网络下测量：

- 首次答题不依赖加载 3D；75 分位 LCP ≤2.5 秒、INP ≤200 毫秒、CLS ≤0.1。
- 中档平板场景目标 ≥30 fps，桌面目标 60 fps；性能不足自动降低 DPR、粒子和动画，允许永久 2D。
- 首屏基础代码 gzip 目标 ≤250 KB，3D 路由 chunk 单独测量，首张地图资源目标 ≤2 MB；超预算需说明与优化。
- 在线确定性答题保存成功率目标 ≥99.5%；重复上传不重复计星、复习和报告。
- 关键学习服务月可用性内部目标 99.5%；AI 故障单独显示，不算成做题失败。
- 不依赖浏览器语音识别 API 的跨平台一致性；真实 iPad Safari 必须纳入验收。

## 结果指标

| 指标 | 定义 | 用途 |
| --- | --- | --- |
| 首轮独立完成率 | 在已获家长授权者中，无持续成人介入完成首轮的人数占比 | 可用性 |
| 7/30 天延迟正确率 | 到期的未见过变式题中无提示正确占比 | 教学效果 |
| 到期复习负担 | 每个孩子的到期项数与预计分钟数 | 防止积压 |
| 提示依赖率 | 首次作答前用提示的题数占比 | 难度调节 |
| 内容缺陷率 | 被确认答案或表达有错的发布题目占比 | 内容质量 |
| 跨设备丢失事件 | 已确认保存后无法恢复的独立答题数 | 数据可靠性 |

初期收集基线，避免未经验证就承诺提高考试分数。统计按最少数据原则采集，不接广告追踪 SDK。
