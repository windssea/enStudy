# v0.36 最后一单元核心练习与后续复习

## 实现范围

新增P1–P6下学期第六单元，每年级4课、每课9个任务，共24课216任务。当前72单元均有4节核心练习，累计288课、2592任务。这个数量只证明核心练习覆盖，不等于完整课程、自然拼读、媒体、真实口语或自由写作已交付，也不是掌握证明。香港朗文具体版次仍未绑定。

| 年级 | 单元 | 复习内容与边界 |
| --- | --- | --- |
| P1 | 我们的英语小展览 | 单复数介绍、明示代词与物主词、There is/are和能力；不凭名字或颜色猜身份，不以文字代替声学拼读 |
| P2 | 我的周末图鉴 | 日常与此刻、can/cannot、do/does问句、时间地点配文；不用角色能力给真实孩子排名 |
| P3 | 给朋友的邀请 | 活动/时间/地点、礼貌邀请、接受或拒绝、准备问句和遗漏信息；使用虚构场景，不发消息或收集家庭地址，沉默不等于同意 |
| P4 | 我的故事展 | 过去经历、当前镜头、未来计划、因果与短信时间线；计划不冒充已完成记录 |
| P5 | 我的观点小报 | 主题句、相关理由、对照、有限依据和结尾；不从小调查推广到所有人，不把建议或无回复当决定 |
| P6 | 走向新的旅程 | 现在完成与具体过去时间、双条件方案、词缀/上下文策略和可调整的复习计划；不把一次成功、提示后完成或核心课练完当毕业认证 |

24课都有单独编写的中文家庭活动、72个与练习句分开的示范例句；11课接入既有3D实验入口，共13条关联，关闭时不加载。本轮没有新建角色模型，继续使用此前尚未发布的v2皮卡丘、狐狸及贴面闭眼。正文避免直接拼出所需英文答案，保留中文情景；提示另由提示协议记录。填词明确接纳缩写及语境成立的部分表达变体，如参观visit/tour、观点think/believe/feel、原因because/since/as、收集collect/gather/get、将来will/shall、使用use/reuse；这些变体逐题定义，不全局放宽判题。

## 学期练完后的交互

沿用ui-ux-pro-max现有MASTER及小讲堂规范。完成当前年级B学期的所有已发布课后，地图显示“这学期的核心练习都做过了”，主操作变成“看看复习安排”，打开既有复习页，不自动创建会话或跳题。“再看一节课”保留为次操作，伙伴打招呼与转身仍可使用。

有到期记录时显示真实条数，不称为固定题数；无到期记录时说明可以休息。文案明确提示/示范与独立回忆分开，完成练习不等于掌握全部内容。新区域使用16px正文、14px辅助文字、52px按钮、可换行布局与现有焦点样式，不新增循环庆祝、震动或强制连续打卡。

技能检索“learning completion next steps”无匹配，收窄为“success feedback”命中Interaction/Success Feedback，适用于这里明确确认练过的状态。未采用另一个移动端震动结果，也不把这次搜索当作未经验证的整页设计。没有浏览器实测，不能由源码或静态HTML声称PC/iPad布局、焦点、200%缩放或GPU通过。
