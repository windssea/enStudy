# 一年级看图词汇素材 v1

2026-10-19 用内置 imagegen 生成两张原创粘土插画图集，分别为20种动物和20件校园物品/场景；原始 PNG 已按 SHA256 前24位命名复制到 public/pictures/words，保留生成像素，不依赖工作区外的图片路径。颜色及形状另用精确 SVG，共60个词义。它们是二维插画，不宣称增加了40个可旋转3D模型；原有具名伙伴和六种交互粘土物保留。

画风要求：超轻粘土、圆润哑光、轻微颗粒、柔和棚灯与接触阴影、白底、无标签文字、五列四行。同一行依次对应 picture-word-media.source.v1.json 中的原词条顺序。动物分别保留长耳、长颈、硬壳、鳞片、条纹等可识别特征；校园物品区分木铅笔、钢笔、蜡笔，以及书、活页纸、螺旋本。全图已逐格观察；铅笔单元曾混入相邻书脊，现用逐张人工定义的 viewBox 显示范围避开，不以固定均分格盲切。

public/content/picture-words.v1.json 保留完整图集摘要、大小、顺序、裁切坐标与录音摘要。坐标使用1254单位的正方形参考空间，SVG image 按同一空间缩放；不是宣称原PNG固定为1254像素。图卡仅显示单个对应对象，图画仍需儿童识图研究和正式教研审核。

英语整词声使用现有本地 Piper 1.3.0、固定 en_GB-cori-high 模型。旧145词声源中已有的词先按原哈希复用，其余词在本机生成，再打包为48kbps单声道MP3；60段共274244字节。固定模型、配置与MODEL_CARD均按既有provenance校验；模型和工具环境不发布。公开目录包含原NOTICE与MODEL_CARD副本。数值非静音和格式检查不等于声学听审或口语评测。

生产脚本：scripts/render-picture-words.py 使用忽略目录内已有的Piper环境和模型；scripts/render-picture-guide.ps1 只合成新增的中文图片玩法提示。二者检测已有版本清单后拒绝覆盖。后续修订须新建版本并明确迁移引用，不重新写已发布v1。旧phonics WAV和child-guides.v1均保持原样。
